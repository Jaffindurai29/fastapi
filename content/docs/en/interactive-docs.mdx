## Swagger UI

Every FastAPI app gets a live, interactive API explorer for free at `/docs`:

```bash
uvicorn main:app --reload
```

Open [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs). You'll see
every path operation you defined, grouped and documented, with a **"Try it
out"** button that lets you send real requests from the browser.

This page is powered by [Swagger UI](https://github.com/swagger-api/swagger-ui)
and built from the OpenAPI schema FastAPI generates automatically from your
code — your type hints, `response_model`s, and docstrings all feed into it.

## ReDoc

An alternative, more document-like view is available at `/redoc`:

[http://127.0.0.1:8000/redoc](http://127.0.0.1:8000/redoc)

It's generated from the exact same OpenAPI schema, just rendered by
[ReDoc](https://github.com/Redocly/redoc) instead of Swagger UI.

## The raw OpenAPI schema

Both pages read from a single JSON document, also served automatically:

[http://127.0.0.1:8000/openapi.json](http://127.0.0.1:8000/openapi.json)

You can feed this schema into other tools — client code generators, API
gateways, or testing tools — without writing any documentation by hand.

## Improving the docs with docstrings and metadata

FastAPI picks up more than just types. Add a docstring and a `summary` to
enrich the generated docs:

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/items/{item_id}", summary="Get one item")
def read_item(item_id: int):
    """
    Fetch a single item by its ID.

    - **item_id**: the numeric ID of the item to look up.
    """
    return {"item_id": item_id}
```

That's the core loop: write a normal Python function with type hints, and
FastAPI handles validation, serialization, and documentation for you.

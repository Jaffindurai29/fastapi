## The simplest FastAPI app

Create a file named `main.py`:

```python title="main.py"
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def read_root():
    return {"message": "Hello, FastAPI!"}
```

Line by line:

- `from fastapi import FastAPI` — imports the `FastAPI` class.
- `app = FastAPI()` — creates an "application" instance. This is the main
  object your ASGI server talks to, and the one you attach routes to.
- `@app.get("/")` — a **decorator** that tells FastAPI: "the function right
  below handles `GET` requests to the path `/`". This is called a **path
  operation**.
- `def read_root(): ...` — the **path operation function**. FastAPI calls
  this whenever a matching request comes in, and uses whatever it returns as
  the response.

## Run the server

```bash
uvicorn main:app --reload
```

- `main` — the file `main.py` (the Python "module").
- `app` — the object created inside `main.py` with `app = FastAPI()`.
- `--reload` — restarts the server automatically when you change your code.
  Only use this in development.

Open [http://127.0.0.1:8000](http://127.0.0.1:8000) and you should see:

```json
{ "message": "Hello, FastAPI!" }
```

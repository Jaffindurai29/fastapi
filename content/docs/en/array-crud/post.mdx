---
title: "2. POST"
description: Adding a new item to the end of the array.
---

## The code

```python title="main.py"
from fastapi import FastAPI

app = FastAPI()

data = ["first", "second"]

@app.post("/items")
def create_item(value: str):
    data.append(value)
    return {"index": len(data) - 1, "value": value}
```

## Line by line

1. `def create_item(value: str)` — since `value` isn't a Pydantic model
   or a path parameter, FastAPI treats it as a query parameter, read
   from the URL (`?value=third`) instead of a JSON body.
2. `data.append(value)` — adds the new value onto the end of the
   shared array.
3. `return {"index": len(data) - 1, "value": value}` — tells the
   caller exactly where the new item landed, so a follow-up
   [GET](/en/docs/array-crud/get), [PUT](/en/docs/array-crud/put), or
   [DELETE](/en/docs/array-crud/delete) knows which index to use.

## Try it

```bash
curl -i -X POST "http://127.0.0.1:8000/items?value=third"
```

Expected: `200 OK`, `{"index": 2, "value": "third"}`.

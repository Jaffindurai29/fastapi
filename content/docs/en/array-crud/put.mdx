---
title: "3. PUT"
description: Replacing the item at a given index entirely.
---

## The code

```python title="main.py"
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

data = ["first", "second"]

class ItemRequest(BaseModel):
    value: str

@app.put("/items/{item_index}")
def replace_item(item_index: int, item: ItemRequest):
    if item_index < 0 or item_index >= len(data):
        raise HTTPException(status_code=404, detail="Item not found")
    data[item_index] = item.value
    return {"index": item_index, "value": data[item_index]}
```

## Line by line

1. **Check the index exists first** — same bounds check as
   [GET](/en/docs/array-crud/get), so an out-of-range `PUT` returns a
   clean `404` instead of crashing.
2. **`data[item_index] = item.value`** — overwrites that slot entirely.
   `PUT` means "here is the complete new representation of this
   resource" — the client sends the whole value, not just the part that
   changed.

## Try it

```bash
curl -X PUT http://127.0.0.1:8000/items/0 -H "Content-Type: application/json" -d "{\"value\": \"replaced\"}"
```

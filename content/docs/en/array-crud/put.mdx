## The code

```python title="main.py"
from fastapi import FastAPI, HTTPException

app = FastAPI()

data = ["first", "second"]

@app.put("/items/{item_index}")
def replace_item(item_index: int, value: str):
    if item_index < 0 or item_index >= len(data):
        raise HTTPException(status_code=404, detail="Item not found")
    data[item_index] = value
    return {"index": item_index, "value": data[item_index]}
```

## Line by line

1. **Check the index exists first** — same bounds check as
   [GET](/en/docs/array-crud/get):
   - `item_index < 0` blocks negative numbers, so `/items/-1` can't
     quietly hit Python's negative-indexing behavior and overwrite the
     last item by accident.
   - `item_index >= len(data)` blocks anything past the end of the
     array.
   - Either case raises `HTTPException(404)` before `data[item_index]`
     ever runs, so an out-of-range `PUT` returns a clean `404 Not
     Found` instead of crashing with an `IndexError` (which would
     surface as a `500`).
2. **`data[item_index] = value`** — overwrites that slot entirely.
   `PUT` means "here is the complete new representation of this
   resource" — the client sends the whole value, not just the part that
   changed. `value` is a query parameter here (same style as
   [POST](/en/docs/array-crud/post)), not a JSON body.

## Try it

```bash
curl -X PUT "http://127.0.0.1:8000/items/0?value=replaced"
curl -i -X PUT "http://127.0.0.1:8000/items/9?value=x"  # 404
```

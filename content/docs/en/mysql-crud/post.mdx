## The code

```python title="main.py"
import os

from fastapi import Depends, FastAPI, status
from pydantic import BaseModel
from sqlalchemy import Column, Integer, String, create_engine
from sqlalchemy.orm import Session, declarative_base, sessionmaker

MYSQL_HOST = os.getenv("MYSQL_HOST", "127.0.0.1")
MYSQL_PORT = os.getenv("MYSQL_PORT", "3306")
MYSQL_USER = os.getenv("MYSQL_USER", "root")
MYSQL_PASSWORD = os.getenv("MYSQL_PASSWORD", "")
MYSQL_DB = os.getenv("MYSQL_DB", "fastapi_learn")

DATABASE_URL = os.getenv(
    "DATABASE_URL",
    f"mysql+pymysql://{MYSQL_USER}:{MYSQL_PASSWORD}@{MYSQL_HOST}:{MYSQL_PORT}/{MYSQL_DB}",
)

engine = create_engine(DATABASE_URL, pool_pre_ping=True)
SessionLocal = sessionmaker(autocommit=False, autoflush=False, bind=engine)
Base = declarative_base()


class ItemModel(Base):
    __tablename__ = "crud_post_items"
    id = Column(Integer, primary_key=True, autoincrement=True)
    value = Column(String(255), nullable=False)


Base.metadata.create_all(bind=engine)

with SessionLocal() as db:
    if db.query(ItemModel).count() == 0:
        db.add_all([ItemModel(value="first"), ItemModel(value="second")])
        db.commit()

app = FastAPI()


def get_db():
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()


class ItemRequest(BaseModel):
    value: str


@app.post("/items", status_code=status.HTTP_201_CREATED)
def create_item(item: ItemRequest, db: Session = Depends(get_db)):
    row = ItemModel(value=item.value)
    db.add(row)
    db.commit()
    db.refresh(row)
    return {"id": row.id, "value": row.value}
```

## Line by line

The `MYSQL_*`/`DATABASE_URL` setup, `engine`/`SessionLocal`/`Base`, the
`ItemModel` table, `Base.metadata.create_all(...)`, and the seed block above
are the same shared pieces every page in this topic uses — see the
[index page](/en/docs/mysql-crud) for those explained line by line. Below
covers what's specific to this page.

1. `db: Session = Depends(get_db)` — same dependency injection as
   [GET](/en/docs/mysql-crud/get): FastAPI runs `get_db()` up to its
   `yield` before this route body executes, hands over the freshly
   created session as `db`, and closes that session automatically once
   this route finishes, success or failure.
2. `row = ItemModel(value=item.value)` — builds a new ORM object in
   memory; nothing is written to the database yet.
3. `db.add(row)` — only stages the new object in the session's pending
   state; nothing is sent to MySQL yet.
4. `db.commit()` — flushes that pending `INSERT` and commits the
   transaction. This is the moment MySQL actually assigns the
   auto-increment `id`.
5. `db.refresh(row)` — re-queries `row` from the database so `row.id`
   reflects the real generated value. Skip it and `row.id` could still
   be stale or `None`, since SQLAlchemy doesn't know the
   database-generated value without asking for it back.

## Backend

**`database.py`** and **`models.py`** — same connection, session, and
`ItemModel` table as [GET](/en/docs/mysql-react/get), unchanged here.

**`schemas.py`** — `ItemRequest`, the same request body
[POST](/en/docs/mysql-react/post) already validates against; PUT reuses
it, since replacing a row's value needs the same shape as creating one.

**`crud.py`** — the replace function:

```python title="crud.py"
def replace_item(db: Session, item_id: int, item: ItemRequest) -> ItemModel | None:
    row = get_item(db, item_id)
    if row is None:
        return None
    row.value = item.value
    db.commit()
    db.refresh(row)
    return row
```

**`main.py`** — the route:

```python title="main.py"
@app.put("/items/{item_id}")
def replace_item(item_id: int, item: ItemRequest, db: Session = Depends(get_db)):
    row = crud.replace_item(db, item_id, item)
    if row is None:
        raise HTTPException(status_code=404, detail="Item not found")
    return {"id": row.id, "value": row.value}
```

## Line by line

`database.py`'s connection/`get_db()` and `models.py`'s `ItemModel` are
shared setup, explained once on the [index page](/en/docs/mysql-react).
Below covers what's new on this page: `crud.py`'s `replace_item`, and
the route in `main.py` that calls it.

1. `db: Session = Depends(get_db)` — same dependency injection as
   [GET](/en/docs/mysql-react/get): FastAPI opens a fresh session via
   `get_db()` before this route runs and closes it automatically
   afterward, whether the route succeeds or raises.
2. **`replace_item` looks the row up first** — `get_item(db, item_id)`
   is `crud.py`'s own `db.get(ItemModel, item_id)` wrapper: it returns
   the `ItemModel` object if that ID exists, or `None` if it doesn't,
   without raising an exception either way.
   - Back in `main.py`, `if row is None: raise
     HTTPException(status_code=404, ...)` turns that `None` into a
     clean `404` before anything else runs.
   - If `crud.replace_item` itself skipped that check and jumped
     straight to `row.value = item.value` when `row` is `None`, Python
     would raise `AttributeError: 'NoneType' object has no attribute
     'value'` — which FastAPI turns into a generic `500 Internal Server
     Error` instead of a clean `404`.
3. **`row.value = item.value`** looks like a plain attribute assignment
   because it is one — but since `row` came from `get_item(...)`
   earlier in this same session, SQLAlchemy's "unit of work" is already
   tracking that object, so the change is picked up automatically.
   - Nothing needs to be re-added to the session (no `db.add(row)`
     here) — that's the real difference from `create_item`, where `row`
     is a brand-new object the session doesn't know about yet.
4. **`db.commit()`** is what turns that tracked in-memory change into
   an actual `UPDATE ... SET value = ... WHERE id = ...` statement sent
   to MySQL — nothing reaches the database before this line runs.
5. **`db.refresh(row)`** re-queries `row` from the database afterward,
   so the `{"id": row.id, "value": row.value}` `main.py` returns
   reflects exactly what MySQL now has, rather than just echoing back
   the input the client already sent.

## Entering edit mode, by ID

```jsx
function startEditing(id, currentValue) {
  setEditingId(id);
  setEditValue(currentValue);
}
```

**Difference from [React's PUT](/en/docs/react/put):**
`setEditingIndex` → `setEditingId` — the same rename as on the
[index page](/en/docs/mysql-react).

## Saving with PUT

```jsx
async function saveEdit(id, method) {
  const response = await fetch(`${API_URL}/items/${id}`, {
    method: method, // "PUT" or "PATCH"
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ value: editValue }),
  });

  if (!response.ok) {
    setError(`Failed to update item (status ${response.status})`);
    return;
  }

  setEditingId(null);
  await loadItems();
}
```

```jsx
<button onClick={() => saveEdit(item.id, "PUT")}>Save (PUT)</button>
```

Same function, same idea as the array version — `index` renamed to
`id` throughout, nothing else.

## Line by line

1. `startEditing(id, currentValue)` — `setEditingIndex` renamed to
   `setEditingId`, storing a database id instead of a position.
2. `saveEdit(id, method)` — same function shape as the array version,
   just addressed by `id` instead of `index`.
3. The **"Save (PUT)"** button now calls `saveEdit(item.id, "PUT")` —
   reading `id` off the item object instead of a loop index.

Next: [PATCH](/en/docs/mysql-react/patch) — the same function, called
with a different verb.

```python title="database.py"
import os

from dotenv import load_dotenv
from sqlalchemy import create_engine
from sqlalchemy.orm import Session, declarative_base, sessionmaker

load_dotenv()

MYSQL_HOST = os.getenv("MYSQL_HOST", "127.0.0.1")
MYSQL_PORT = os.getenv("MYSQL_PORT", "3306")
MYSQL_USER = os.getenv("MYSQL_USER", "root")
MYSQL_PASSWORD = os.getenv("MYSQL_PASSWORD", "")
MYSQL_DB = os.getenv("MYSQL_DB", "fastapi_learn")

DATABASE_URL = os.getenv(
    "DATABASE_URL",
    f"mysql+pymysql://{MYSQL_USER}:{MYSQL_PASSWORD}@{MYSQL_HOST}:{MYSQL_PORT}/{MYSQL_DB}",
)

engine = create_engine(DATABASE_URL, pool_pre_ping=True)
SessionLocal = sessionmaker(autocommit=False, autoflush=False, bind=engine)
Base = declarative_base()


def get_db():
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()
```

from database import Base


class ItemModel(Base):

class ItemRequest(BaseModel):

```python title="crud.py"
from sqlalchemy.orm import Session

from models import ItemModel
from schemas import ItemRequest


def get_items(db: Session) -> list[ItemModel]:
    return db.query(ItemModel).order_by(ItemModel.id).all()


def get_item(db: Session, item_id: int) -> ItemModel | None:
    return db.get(ItemModel, item_id)


def create_item(db: Session, item: ItemRequest) -> ItemModel:
    row = ItemModel(value=item.value)
    db.add(row)
    db.commit()
    db.refresh(row)
    return row


def replace_item(db: Session, item_id: int, item: ItemRequest) -> ItemModel | None:
    row = get_item(db, item_id)
    if row is None:
        return None
    row.value = item.value
    db.commit()
    db.refresh(row)
    return row
```

```python title="main.py"
from fastapi import Depends, FastAPI, HTTPException, status
from fastapi.middleware.cors import CORSMiddleware
from sqlalchemy.orm import Session

import crud
from database import Base, SessionLocal, engine, get_db
from schemas import ItemRequest

Base.metadata.create_all(bind=engine)

with SessionLocal() as db:
    crud.seed_items(db)

app = FastAPI()

app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:5173", "http://127.0.0.1:5173"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)


@app.get("/items")
def list_items(db: Session = Depends(get_db)):
    return [{"id": row.id, "value": row.value} for row in crud.get_items(db)]


@app.get("/items/{item_id}")
def get_item(item_id: int, db: Session = Depends(get_db)):
    row = crud.get_item(db, item_id)
    if row is None:
        raise HTTPException(status_code=404, detail="Item not found")
    return {"id": row.id, "value": row.value}


@app.post("/items", status_code=status.HTTP_201_CREATED)
def create_item(item: ItemRequest, db: Session = Depends(get_db)):
    row = crud.create_item(db, item)
    return {"id": row.id, "value": row.value}


@app.put("/items/{item_id}")
def replace_item(item_id: int, item: ItemRequest, db: Session = Depends(get_db)):
    row = crud.replace_item(db, item_id, item)
    if row is None:
        raise HTTPException(status_code=404, detail="Item not found")
    return {"id": row.id, "value": row.value}
```

**Frontend** — `example/7/react/src/App.jsx`, up to PUT:

```jsx title="example/7/react/src/App.jsx"
import { useEffect, useState } from "react";

const API_URL = "http://127.0.0.1:8000";

export default function App() {
  const [items, setItems] = useState([]);
  const [value, setValue] = useState("");
  const [reached, setReached] = useState(null);
  const [error, setError] = useState(null);

  const [editingId, setEditingId] = useState(null);
  const [editValue, setEditValue] = useState("");

  useEffect(() => {
    loadItems();
  }, []);

  async function loadItems() {
    try {
      const response = await fetch(`${API_URL}/items`);
      if (!response.ok) {
        throw new Error(`Failed to load items (status ${response.status})`);
      }
      setItems(await response.json());
      setError(null);
    } catch (err) {
      setError(err.message);
    }
  }

  async function addItem(event) {
    event.preventDefault();
    if (value.trim() === "") return;

    const response = await fetch(`${API_URL}/items`, {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ value: value }),
    });

    if (!response.ok) {
      setError(`Failed to add item (status ${response.status})`);
      return;
    }

    setValue("");
    await loadItems();
  }

  async function reachItem(id) {
    const response = await fetch(`${API_URL}/items/${id}`);
    if (!response.ok) {
      setError(`Failed to reach id ${id} (status ${response.status})`);
      setReached(null);
      return;
    }
    setReached(await response.json());
    setError(null);
  }

  function startEditing(id, currentValue) {
    setEditingId(id);
    setEditValue(currentValue);
  }

  async function saveEdit(id, method) {
    const response = await fetch(`${API_URL}/items/${id}`, {
      method: method,
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ value: editValue }),
    });

    if (!response.ok) {
      setError(`Failed to update item (status ${response.status})`);
      return;
    }

    setEditingId(null);
    await loadItems();
  }

  return (
    <main style={{ maxWidth: 560, margin: "3rem auto", fontFamily: "sans-serif" }}>
      <h1>MySQL Store</h1>

      {error && <p style={{ color: "crimson" }}>{error}</p>}

      <form onSubmit={addItem} style={{ display: "flex", gap: "0.5rem" }}>
        <input
          value={value}
          onChange={(event) => setValue(event.target.value)}
          placeholder="Add a value"
          style={{ flex: 1, padding: "0.5rem" }}
        />
        <button type="submit">Add</button>
      </form>

      <ul style={{ listStyle: "none", padding: 0, marginTop: "1.5rem" }}>
        {items.map((item) =>
          editingId === item.id ? (
            <li
              key={item.id}
              style={{ display: "flex", alignItems: "center", gap: "0.5rem", padding: "0.25rem 0" }}
            >
              <span style={{ color: "#888", width: "2rem" }}>#{item.id}</span>
              <input
                value={editValue}
                onChange={(event) => setEditValue(event.target.value)}
                style={{ flex: 1, padding: "0.25rem" }}
              />
              <button onClick={() => saveEdit(item.id, "PUT")}>Save (PUT)</button>
              <button onClick={() => setEditingId(null)}>Cancel</button>
            </li>
          ) : (
            <li
              key={item.id}
              style={{ display: "flex", alignItems: "center", gap: "0.5rem", padding: "0.25rem 0" }}
            >
              <span style={{ color: "#888", width: "2rem" }}>#{item.id}</span>
              <span style={{ flex: 1 }}>{item.value}</span>
              <button onClick={() => reachItem(item.id)}>Reach</button>
              <button onClick={() => startEditing(item.id, item.value)}>Edit</button>
            </li>
          ),
        )}
      </ul>

      {reached && (
        <p style={{ marginTop: "1rem" }}>
          Reached id <strong>#{reached.id}</strong>: <strong>{reached.value}</strong>
        </p>
      )}
    </main>
  );
}
```

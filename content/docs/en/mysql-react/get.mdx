[POST](/en/docs/mysql-react/post) could only add rows and show a
message. This page adds the two GET routes, so the page can list every
row and reach one by its ID.

## Backend

**`database.py`**, **`models.py`** and **`schemas.py`** — same
connection, session, `ItemModel` table and `ItemRequest` as
[POST](/en/docs/mysql-react/post), unchanged here.

**`crud.py`** — the two read functions, kept HTTP-agnostic:

```python title="crud.py"
def get_items(db: Session) -> list[ItemModel]:
    return db.query(ItemModel).order_by(ItemModel.id).all()


def get_item(db: Session, item_id: int) -> ItemModel | None:
    return db.get(ItemModel, item_id)
```

**`main.py`** — the two routes, calling into `crud.py`:

```python title="main.py"
@app.get("/items")
def list_items(db: Session = Depends(get_db)):
    return [{"id": row.id, "value": row.value} for row in crud.get_items(db)]


@app.get("/items/{item_id}")
def get_item(item_id: int, db: Session = Depends(get_db)):
    row = crud.get_item(db, item_id)
    if row is None:
        raise HTTPException(status_code=404, detail="Item not found")
    return {"id": row.id, "value": row.value}
```

## Line by line

`database.py`'s connection settings and `get_db()` dependency, and
`models.py`'s `ItemModel` table, are the same on every page in this
topic — see the [index page](/en/docs/mysql-react) for those explained
line by line. Below covers what's specific to this page: `crud.py`'s
two read functions, and the routes in `main.py` that call them.

1. `db: Session = Depends(get_db)` — same dependency injection as
   [POST](/en/docs/mysql-react/post): FastAPI opens a fresh session via
   `get_db()` before the route body runs, and closes it once the route
   finishes, success or failure.
2. `crud.get_items(db)` runs
   `db.query(ItemModel).order_by(ItemModel.id).all()` — three chained
   steps, and nothing reaches MySQL until the last one:
   - `db.query(ItemModel)` builds a SELECT scoped to whatever table
     `ItemModel` maps to.
   - `.order_by(ItemModel.id)` adds `ORDER BY id`, so rows come back in
     a stable, predictable order — skip it and MySQL is free to return
     rows in any order it likes, which could shuffle between requests.
   - `.all()` is what actually executes the query and loads every
     matching row into memory as a list of `ItemModel` objects.
   - Back in `main.py`, the `{"id": row.id, "value": row.value}`
     comprehension around `crud.get_items(db)` converts each ORM object
     into a plain dict — FastAPI's JSON encoder can serialize plain
     Python types, not an `ItemModel` instance directly. That reshaping
     lives in `main.py`, not `crud.py`, so `crud.py` stays
     HTTP/JSON-agnostic and only ever hands back ORM objects.
3. `crud.get_item(db, item_id)` runs `db.get(ItemModel, item_id)` —
   SQLAlchemy's shortcut for "fetch by primary key." It returns the
   matching `ItemModel` object if a row with that ID exists, or plain
   `None` if it doesn't — it does **not** raise an exception on a miss.
   - Back in `main.py`, `if row is None: raise
     HTTPException(status_code=404, ...)` is what turns that `None`
     into an actual HTTP `404 Not Found` response — the same
     `404`-if-missing pattern from every earlier topic.
   - Skip that check and go straight to `row.value` when `row` is
     `None`, and Python raises `AttributeError: 'NoneType' object has
     no attribute 'value'` instead — which FastAPI turns into a generic
     `500 Internal Server Error`, not the clean `404` a missing ID
     deserves.
4. `GET /items` uses the same path as POST, with a different method.
   FastAPI matches **method + path** — which is why, on the POST page, a
   GET to `/items` gave `405 Method Not Allowed` (the path existed, the
   method didn't) rather than `404`.

## Test it with Thunder Client

Restart isn't needed if `uvicorn --reload` is running — saving
`main.py` reloads it.

**Request 1 — GET every row:**

1. ⚡ → **New Request**, method **GET**, URL `http://127.0.0.1:8000/items`.
2. No body — leave the Body tab empty.
3. **Send** → `200 OK`, every row so far — for example the `first` you
   added on the POST page, plus one more:

   ```json
   [
     { "id": 1, "value": "first" },
     { "id": 2, "value": "second" }
   ]
   ```

**Request 2 — GET one row by ID:**

1. **New Request**, **GET**, `http://127.0.0.1:8000/items/1`.
2. **Send** → `200 OK`, `{"id": 1, "value": "first"}`.
3. Change the URL to an ID that doesn't exist, e.g. `/items/999` →
   `404 Not Found`, `{"detail": "Item not found"}`.

**Tip:** Thunder Client → **Collections** → **New Collection** (e.g.
`mysql-react`) → save the POST and GET requests into it, so you can
re-run each with one click.

## Frontend

## Load and reach, by ID

```jsx
async function loadItems() {
  const response = await axios.get(`${API_URL}/items`);
  // ...identical to the array version
  setItems(response.data);
}

async function reachItem(id) {
  const response = await axios.get(`${API_URL}/items/${id}`);
  // ...same as the array version, just named `id` instead of `index`
  setReached(response.data);
}
```

`addItem` from [POST](/en/docs/mysql-react/post) changes too: now that
there's a GET to call, it refetches the list instead of showing a
message, so the new row appears in the list with its `id`:

```jsx
try {
  await axios.post(`${API_URL}/items`, { value: value });
} catch (err) {
  setError(errorMessage("add item", err));
  return;
}

setValue("");
await loadItems();
```

**Difference from [React's GET](/en/docs/react/get):** the URL is still
`/items/<something>` — only what that something *means* changed. Before,
it was "the 3rd item in the array." Here, it's "the row whose database
ID is this number," regardless of where it currently sits in the list.
`loadItems` itself doesn't change at all — the backend returns objects
instead of plain strings, but this function just stores whatever JSON
comes back either way.

## Line by line

1. `loadItems()` runs once when the page opens (via `useEffect(..., [])`)
   and stores whatever JSON comes back — `{ id, value }` objects here.
2. `addItem` now ends with `await loadItems()` instead of
   `setMessage(...)` — the new row's `id` arrives through this refetch,
   alongside every other row.
3. `reachItem(id)` is the array version's `reachItem(index)`, with
   `index` renamed to `id` everywhere — the URL, the error message, and
   the parameter itself.
4. The URL pattern `/items/<something>` doesn't change; only what that
   `<something>` identifies does — a database ID instead of an array
   position.

## Code so far

**Backend** — `example/7/a`, up to GET:

```python title="database.py"
import os

from dotenv import load_dotenv
from sqlalchemy import URL, create_engine
from sqlalchemy.orm import Session, declarative_base, sessionmaker

load_dotenv()

# URL.create escapes special characters (like "@") in the password.
# Set DATABASE_URL to override it (e.g. "sqlite:///./test.db").
DATABASE_URL = os.getenv("DATABASE_URL") or URL.create(
    "mysql+pymysql",
    username=os.getenv("MYSQL_USER", "root"),
    password=os.getenv("MYSQL_PASSWORD", ""),
    host=os.getenv("MYSQL_HOST", "127.0.0.1"),
    port=int(os.getenv("MYSQL_PORT", "3306")),
    database=os.getenv("MYSQL_DB", "fastapi_learn"),
)

engine = create_engine(DATABASE_URL, pool_pre_ping=True)
SessionLocal = sessionmaker(autocommit=False, autoflush=False, bind=engine)
Base = declarative_base()


def get_db():
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()
```

```python title="models.py"
from sqlalchemy import Column, Integer, String

from database import Base


class ItemModel(Base):
    __tablename__ = "crud_react_items"

    id = Column(Integer, primary_key=True, autoincrement=True)
    value = Column(String(255), nullable=False)
```

```python title="schemas.py"
from pydantic import BaseModel


class ItemRequest(BaseModel):
    value: str
```

```python title="crud.py"
from sqlalchemy.orm import Session

from models import ItemModel
from schemas import ItemRequest


def get_items(db: Session) -> list[ItemModel]:
    return db.query(ItemModel).order_by(ItemModel.id).all()


def get_item(db: Session, item_id: int) -> ItemModel | None:
    return db.get(ItemModel, item_id)


def create_item(db: Session, item: ItemRequest) -> ItemModel:
    row = ItemModel(value=item.value)
    db.add(row)
    db.commit()
    db.refresh(row)
    return row


def seed_items(db: Session) -> None:
    if db.query(ItemModel).count() == 0:
        db.add_all([ItemModel(value="first"), ItemModel(value="second")])
        db.commit()
```

```python title="main.py"
from fastapi import Depends, FastAPI, HTTPException, status
from fastapi.middleware.cors import CORSMiddleware
from sqlalchemy.orm import Session

import crud
from database import Base, SessionLocal, engine, get_db
from schemas import ItemRequest

Base.metadata.create_all(bind=engine)

with SessionLocal() as db:
    crud.seed_items(db)

app = FastAPI()

app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:5173", "http://127.0.0.1:5173", "http://localhost:3000"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)


@app.get("/items")
def list_items(db: Session = Depends(get_db)):
    return [{"id": row.id, "value": row.value} for row in crud.get_items(db)]


@app.get("/items/{item_id}")
def get_item(item_id: int, db: Session = Depends(get_db)):
    row = crud.get_item(db, item_id)
    if row is None:
        raise HTTPException(status_code=404, detail="Item not found")
    return {"id": row.id, "value": row.value}


@app.post("/items", status_code=status.HTTP_201_CREATED)
def create_item(item: ItemRequest, db: Session = Depends(get_db)):
    row = crud.create_item(db, item)
    return {"id": row.id, "value": row.value}
```

`seed_items` arrives with GET: if the table is empty on startup it adds
two starter rows, so the list isn't blank the first time you open the
page. If you already added rows on the POST page, it does nothing.

**Frontend** — `example/7/react/src/App.jsx`, up to GET:

```jsx title="example/7/react/src/App.jsx"
import { useEffect, useState } from "react";
import axios from "axios";

const API_URL = "http://127.0.0.1:8000";

function errorMessage(action, err) {
  const status = err.response?.status;
  return status ? `Failed to ${action} (status ${status})` : `Failed to ${action}: ${err.message}`;
}

export default function App() {
  const [items, setItems] = useState([]);
  const [value, setValue] = useState("");
  const [reached, setReached] = useState(null);
  const [error, setError] = useState(null);

  useEffect(() => {
    loadItems();
  }, []);

  async function loadItems() {
    try {
      const response = await axios.get(`${API_URL}/items`);
      setItems(response.data);
      setError(null);
    } catch (err) {
      setError(errorMessage("load items", err));
    }
  }

  async function addItem(event) {
    event.preventDefault();
    if (value.trim() === "") return;

    try {
      await axios.post(`${API_URL}/items`, { value: value });
    } catch (err) {
      setError(errorMessage("add item", err));
      return;
    }

    setValue("");
    await loadItems();
  }

  async function reachItem(id) {
    try {
      const response = await axios.get(`${API_URL}/items/${id}`);
      setReached(response.data);
      setError(null);
    } catch (err) {
      setError(errorMessage(`reach id ${id}`, err));
      setReached(null);
    }
  }

  return (
    <main style={{ maxWidth: 560, margin: "3rem auto", fontFamily: "sans-serif" }}>
      <h1>MySQL Store</h1>

      {error && <p style={{ color: "crimson" }}>{error}</p>}

      <form onSubmit={addItem} style={{ display: "flex", gap: "0.5rem" }}>
        <input
          value={value}
          onChange={(event) => setValue(event.target.value)}
          placeholder="Add a value"
          style={{ flex: 1, padding: "0.5rem" }}
        />
        <button type="submit">Add</button>
      </form>

      <ul style={{ listStyle: "none", padding: 0, marginTop: "1.5rem" }}>
        {items.map((item) => (
          <li
            key={item.id}
            style={{ display: "flex", alignItems: "center", gap: "0.5rem", padding: "0.25rem 0" }}
          >
            <span style={{ color: "#888", width: "2rem" }}>#{item.id}</span>
            <span style={{ flex: 1 }}>{item.value}</span>
            <button onClick={() => reachItem(item.id)}>Reach</button>
          </li>
        ))}
      </ul>

      {reached && (
        <p style={{ marginTop: "1rem" }}>
          Reached id <strong>#{reached.id}</strong>: <strong>{reached.value}</strong>
        </p>
      )}
    </main>
  );
}
```

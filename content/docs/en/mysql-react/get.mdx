## Backend

**`database.py`** — connection settings and the `get_db()` dependency, unchanged on every page in this topic:

```python title="database.py"
import os

from dotenv import load_dotenv
from sqlalchemy import create_engine
from sqlalchemy.orm import Session, declarative_base, sessionmaker

load_dotenv()

MYSQL_HOST = os.getenv("MYSQL_HOST", "127.0.0.1")
MYSQL_PORT = os.getenv("MYSQL_PORT", "3306")
MYSQL_USER = os.getenv("MYSQL_USER", "root")
MYSQL_PASSWORD = os.getenv("MYSQL_PASSWORD", "")
MYSQL_DB = os.getenv("MYSQL_DB", "fastapi_learn")

DATABASE_URL = os.getenv(
    "DATABASE_URL",
    f"mysql+pymysql://{MYSQL_USER}:{MYSQL_PASSWORD}@{MYSQL_HOST}:{MYSQL_PORT}/{MYSQL_DB}",
)

engine = create_engine(DATABASE_URL, pool_pre_ping=True)
SessionLocal = sessionmaker(autocommit=False, autoflush=False, bind=engine)
Base = declarative_base()


def get_db():
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()
```

**`models.py`** — the `ItemModel` table:

```python title="models.py"
from sqlalchemy import Column, Integer, String

from database import Base


class ItemModel(Base):
    __tablename__ = "crud_react_items"

    id = Column(Integer, primary_key=True, autoincrement=True)
    value = Column(String(255), nullable=False)
```

**`crud.py`** — the two read functions, kept HTTP-agnostic:

```python title="crud.py"
def get_items(db: Session) -> list[ItemModel]:
    return db.query(ItemModel).order_by(ItemModel.id).all()


def get_item(db: Session, item_id: int) -> ItemModel | None:
    return db.get(ItemModel, item_id)
```

**`main.py`** — the two routes, calling into `crud.py`:

```python title="main.py"
@app.get("/items")
def list_items(db: Session = Depends(get_db)):
    return [{"id": row.id, "value": row.value} for row in crud.get_items(db)]


@app.get("/items/{item_id}")
def get_item(item_id: int, db: Session = Depends(get_db)):
    row = crud.get_item(db, item_id)
    if row is None:
        raise HTTPException(status_code=404, detail="Item not found")
    return {"id": row.id, "value": row.value}
```

## Line by line

`database.py`'s connection settings and `get_db()` dependency, and
`models.py`'s `ItemModel` table, are the same on every page in this
topic — see the [index page](/en/docs/mysql-react) for those explained
line by line. Below covers what's specific to this page: `crud.py`'s
two read functions, and the routes in `main.py` that call them.

1. `db: Session = Depends(get_db)` — this is FastAPI's dependency
   injection at work: FastAPI calls `get_db()` itself before the route
   body runs.
   - `get_db` is a generator function — notice the `yield` inside it —
     so FastAPI runs it up to that `yield`, and the value it yields (a
     fresh `SessionLocal()` instance) becomes whatever gets bound to
     the `db` parameter here.
   - Once the route returns (or raises), FastAPI resumes `get_db()`
     right after the `yield`, running its `finally: db.close()` — so
     the session always gets closed, success or failure, without this
     route needing its own `try`/`finally`.
   - Without `Depends`, every route would have to open and remember to
     close its own session by hand — and a forgotten `close()` after an
     exception quietly leaks a database connection.
2. `crud.get_items(db)` runs
   `db.query(ItemModel).order_by(ItemModel.id).all()` — three chained
   steps, and nothing reaches MySQL until the last one:
   - `db.query(ItemModel)` builds a SELECT scoped to whatever table
     `ItemModel` maps to.
   - `.order_by(ItemModel.id)` adds `ORDER BY id`, so rows come back in
     a stable, predictable order — skip it and MySQL is free to return
     rows in any order it likes, which could shuffle between requests.
   - `.all()` is what actually executes the query and loads every
     matching row into memory as a list of `ItemModel` objects.
   - Back in `main.py`, the `{"id": row.id, "value": row.value}`
     comprehension around `crud.get_items(db)` converts each ORM object
     into a plain dict — FastAPI's JSON encoder can serialize plain
     Python types, not an `ItemModel` instance directly. That reshaping
     lives in `main.py`, not `crud.py`, so `crud.py` stays
     HTTP/JSON-agnostic and only ever hands back ORM objects.
3. `crud.get_item(db, item_id)` runs `db.get(ItemModel, item_id)` —
   SQLAlchemy's shortcut for "fetch by primary key." It returns the
   matching `ItemModel` object if a row with that ID exists, or plain
   `None` if it doesn't — it does **not** raise an exception on a miss.
   - Back in `main.py`, `if row is None: raise
     HTTPException(status_code=404, ...)` is what turns that `None`
     into an actual HTTP `404 Not Found` response — the same
     `404`-if-missing pattern from every earlier topic.
   - Skip that check and go straight to `row.value` when `row` is
     `None`, and Python raises `AttributeError: 'NoneType' object has
     no attribute 'value'` instead — which FastAPI turns into a generic
     `500 Internal Server Error`, not the clean `404` a missing ID
     deserves.

## Frontend

## Load and reach, by ID

```jsx
async function loadItems() {
  const response = await fetch(`${API_URL}/items`);
  // ...identical to the array version
  setItems(await response.json());
}

async function reachItem(id) {
  const response = await fetch(`${API_URL}/items/${id}`);
  // ...same as the array version, just named `id` instead of `index`
  setReached(await response.json());
}
```

**Difference from [React's GET](/en/docs/react/get):** the URL is still
`/items/<something>` — only what that something *means* changed. Before,
it was "the 3rd item in the array." Here, it's "the row whose database
ID is this number," regardless of where it currently sits in the list.
`loadItems` itself doesn't change at all — the backend returns objects
instead of plain strings, but this function just stores whatever JSON
comes back either way.

## Line by line

1. `reachItem(id)` is the array version's `reachItem(index)`, with
   `index` renamed to `id` everywhere — the URL, the error message, and
   the parameter itself.
2. `loadItems()` is untouched — it just stores whatever JSON comes
   back, whether that's plain strings or `{ id, value }` objects.
3. The URL pattern `/items/<something>` doesn't change; only what that
   `<something>` identifies does — a database ID instead of an array
   position.

```python title="main.py"
from fastapi import Depends, FastAPI, HTTPException
from fastapi.middleware.cors import CORSMiddleware
from sqlalchemy.orm import Session

import crud
from database import Base, SessionLocal, engine, get_db

Base.metadata.create_all(bind=engine)

with SessionLocal() as db:
    crud.seed_items(db)

app = FastAPI()

app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:5173", "http://127.0.0.1:5173"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)


@app.get("/items")
def list_items(db: Session = Depends(get_db)):
```

**Frontend** — `example/7/react/src/App.jsx`, up to GET:

```jsx title="example/7/react/src/App.jsx"
import { useEffect, useState } from "react";

const API_URL = "http://127.0.0.1:8000";

export default function App() {
  const [items, setItems] = useState([]);
  const [reached, setReached] = useState(null);
  const [error, setError] = useState(null);

  useEffect(() => {
    loadItems();
  }, []);

  async function loadItems() {
    try {
      const response = await fetch(`${API_URL}/items`);
      if (!response.ok) {
        throw new Error(`Failed to load items (status ${response.status})`);
      }
      setItems(await response.json());
      setError(null);
    } catch (err) {
      setError(err.message);
    }
  }

  async function reachItem(id) {
    const response = await fetch(`${API_URL}/items/${id}`);
    if (!response.ok) {
      setError(`Failed to reach id ${id} (status ${response.status})`);
      setReached(null);
      return;
    }
    setReached(await response.json());
    setError(null);
  }

  return (
    <main style={{ maxWidth: 560, margin: "3rem auto", fontFamily: "sans-serif" }}>
      <h1>MySQL Store</h1>

      {error && <p style={{ color: "crimson" }}>{error}</p>}

      <ul style={{ listStyle: "none", padding: 0, marginTop: "1.5rem" }}>
        {items.map((item) => (
          <li
            key={item.id}
            style={{ display: "flex", alignItems: "center", gap: "0.5rem", padding: "0.25rem 0" }}
          >
            <span style={{ color: "#888", width: "2rem" }}>#{item.id}</span>
            <span style={{ flex: 1 }}>{item.value}</span>
            <button onClick={() => reachItem(item.id)}>Reach</button>
          </li>
        ))}
      </ul>

      {reached && (
        <p style={{ marginTop: "1rem" }}>
          Reached id <strong>#{reached.id}</strong>: <strong>{reached.value}</strong>
        </p>
      )}
    </main>
  );
}
```

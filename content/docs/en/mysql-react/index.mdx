## Files

Same layered structure as [MySQL + CRUD](/en/docs/mysql-crud) —
`database.py`/`models.py`/`schemas.py`/`crud.py`/`main.py` instead of
one file:

| File | Responsibility |
|---|---|
| `database.py` | env vars, `engine`, `SessionLocal`, `Base`, `get_db()` |
| `models.py` | `ItemModel` — the SQLAlchemy table, this topic's own `crud_react_items` |
| `schemas.py` | `ItemRequest` and `ItemPatch` — this app needs both, one per body-taking verb |
| `crud.py` | all six database functions — one per verb, plus `seed_items` |
| `main.py` | the `FastAPI()` app, `CORSMiddleware`, and all five routes |

This topic's table is its own `crud_react_items`, separate from
[MySQL + CRUD](/en/docs/mysql-crud)'s shared `items` table — running
this topic never touches that topic's data, or vice versa.

## The shared setup

**Connection, from environment variables** — same idea as
[MySQL + CRUD](/en/docs/mysql-crud), plus `load_dotenv()` so a local
`.env` (copied from `.env.example`) is picked up automatically if you
created one:

```python title="database.py"
import os

from dotenv import load_dotenv
from sqlalchemy import create_engine
from sqlalchemy.orm import Session, declarative_base, sessionmaker

load_dotenv()

MYSQL_HOST = os.getenv("MYSQL_HOST", "127.0.0.1")
MYSQL_PORT = os.getenv("MYSQL_PORT", "3306")
MYSQL_USER = os.getenv("MYSQL_USER", "root")
MYSQL_PASSWORD = os.getenv("MYSQL_PASSWORD", "")
MYSQL_DB = os.getenv("MYSQL_DB", "fastapi_learn")

# Set DATABASE_URL directly to override everything above (e.g. to point
# at SQLite for a quick local test with no MySQL server at all).
DATABASE_URL = os.getenv(
    "DATABASE_URL",
    f"mysql+pymysql://{MYSQL_USER}:{MYSQL_PASSWORD}@{MYSQL_HOST}:{MYSQL_PORT}/{MYSQL_DB}",
)

engine = create_engine(DATABASE_URL, pool_pre_ping=True)
SessionLocal = sessionmaker(autocommit=False, autoflush=False, bind=engine)
Base = declarative_base()


def get_db():
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()
```

## Line by line: the connection

1. `load_dotenv()` — loads a local `.env` file (copied from
   `.env.example`) into the environment, if one exists, before any
   `os.getenv(...)` call below runs. Skip creating a `.env` entirely
   and every variable below still falls back to its default.
2. `os.getenv("DATABASE_URL", f"mysql+pymysql://...")` — reads the
   `DATABASE_URL` environment variable if it's set (e.g. a SQLite
   override), otherwise builds a MySQL connection string from the
   individual `MYSQL_*` variables. `mysql+pymysql://` tells SQLAlchemy
   which driver — `pymysql` — to actually speak to MySQL with.
3. `create_engine(DATABASE_URL, pool_pre_ping=True)` — the `engine` is
   SQLAlchemy's connection factory for this database; it doesn't open a
   connection immediately, only once a session actually needs one.
   `pool_pre_ping=True` makes it test a pooled connection with a
   lightweight ping before reusing it, so a connection MySQL silently
   dropped (after sitting idle, for example) gets replaced instead of
   failing with a confusing error later.
4. `sessionmaker(autocommit=False, autoflush=False, bind=engine)` — a
   factory for creating `Session` objects bound to this engine.
   `autocommit=False` means nothing is written to the database until
   you explicitly call `db.commit()`; `autoflush=False` means pending
   changes aren't silently sent to the database before every query,
   only when you flush or commit — together they give every route full
   control over exactly when SQL actually runs.
5. `get_db()` — a dependency that opens one session per request, via
   `yield`, and always closes it afterward in `finally: db.close()`,
   even if the route raises. Every route in this topic declares
   `db: Session = Depends(get_db)` to get one — see any verb page's
   line-by-line section for that in action.

**The table, as a Python class** — with a real, stable,
auto-incrementing `id`, unlike the array topic's position-based index:

```python title="models.py"
from sqlalchemy import Column, Integer, String

from database import Base


class ItemModel(Base):
    __tablename__ = "crud_react_items"

    id = Column(Integer, primary_key=True, autoincrement=True)
    value = Column(String(255), nullable=False)
```

## Line by line: the table

1. `class ItemModel(Base):` — declares an ORM model. Inheriting from
   `Base` (imported from `database.py`) is what makes this class map to
   a real database table instead of being a plain Python class.
2. `__tablename__ = "crud_react_items"` — this topic's own table, kept
   separate from [MySQL + CRUD](/en/docs/mysql-crud)'s shared `items`
   table, so running this topic never collides with that one's data.
3. `id = Column(Integer, primary_key=True, autoincrement=True)` — a
   real, stable, auto-incrementing integer primary key, assigned by
   MySQL itself on every insert.
4. `value = Column(String(255), nullable=False)` — a required
   `VARCHAR(255)` column; `nullable=False` means MySQL rejects any
   insert that leaves it out.
5. `main.py` calls `Base.metadata.create_all(bind=engine)` once at
   startup, creating the table if it doesn't already exist — safe to
   call every time the app starts, a no-op once the table is already
   there.

## The backend

[MySQL + CRUD](/en/docs/mysql-crud)'s five routes, combined into
one running app — same as how [Array + CRUD](/en/docs/array-crud)'s
routes were combined for [React + Array + CRUD](/en/docs/react) — plus the same
`CORSMiddleware` from that topic, registered in `main.py` right after
creating `app`:

```python title="main.py"
app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:5173", "http://127.0.0.1:5173"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

## Line by line

1. `app.add_middleware(CORSMiddleware, ...)` — registers middleware
   that runs on every request/response, adding the HTTP headers
   browsers require before letting JavaScript on one origin read a
   response from another.
2. `allow_origins=[...]` — the only two origins allowed to make
   cross-origin requests to this API: the Vite dev server on
   `localhost`/`127.0.0.1`, port `5173`. Anything else is blocked by
   the browser itself before the request even reaches this backend.
3. `allow_credentials=True` — permits cookies/auth headers to be sent
   cross-origin. Not used by this example, but required if you later
   add authentication.
4. `allow_methods=["*"]` / `allow_headers=["*"]` — allow every HTTP
   method and header, instead of listing `GET`, `POST`,
   `Content-Type`, etc. individually.

Nothing else changes — CORS doesn't care what's behind the routes it's
protecting.

## Same frontend, one renamed piece of state

This is the exact same app as [React + Array + CRUD](/en/docs/react), pointed at the
MySQL backend above instead of the array backend. Every page in this
section is a direct comparison — the diff is always the same one
change: **index → id**.

```jsx
const [items, setItems] = useState([]);          // rows from the database, each { id, value }
const [editingId, setEditingId] = useState(null); // which row's id is being edited
```

`editingIndex` → `editingId`. Same idea, renamed to match what it
actually holds now — a database ID, not a position in an array. `items`
also changed shape: each entry is `{ id, value }` instead of a plain
string.

## Line by line

1. `const [items, setItems] = useState([]);` — same state as the array
   version, but now holding `{ id, value }` objects instead of plain
   strings, since that's the shape every MySQL-backed route returns.
2. `const [editingId, setEditingId] = useState(null);` — the array
   version's `editingIndex`/`setEditingIndex`, renamed throughout this
   topic to `editingId`/`setEditingId` to match what it stores: a
   database ID rather than a position in the array.
3. Every place the array version compared `editingIndex === index` or
   passed a `.map()` loop index around, this topic instead compares
   `editingId === item.id` and passes `item.id` — reading the
   identifier off the row object itself, not off its position in the
   list.

## Running this topic

Needs the same database setup as [MySQL + CRUD](/en/docs/mysql-crud),
plus both backend and frontend running at once:

1. **One-time database setup** (skip if already done for that topic):

   ```bash
   pip install sqlalchemy pymysql python-dotenv
   ```

   ```sql
   CREATE DATABASE fastapi_learn;
   ```

   ```bash
   export MYSQL_HOST=127.0.0.1
   export MYSQL_PORT=3306
   export MYSQL_USER=root
   export MYSQL_PASSWORD=your-password
   export MYSQL_DB=fastapi_learn
   ```

   ...or `cp example/7/a/.env.example example/7/a/.env` and edit that
   instead — `database.py` loads it automatically. Skipping both is
   also fine; the defaults above are already baked in.

   No MySQL handy? `export DATABASE_URL="sqlite:///./test.db"` instead.

2. **Terminal 1 — backend:**

   ```bash
   cd example/7/a
   uvicorn main:app --reload
   ```

3. **Terminal 2 — frontend:**

   ```bash
   cd example/7/react
   npm install
   npm run dev
   ```

4. Open the URL Vite prints (usually
   [http://localhost:5173](http://localhost:5173)).

The full frontend code lives in `example/7/react` in this repo (see its
`README.md` and `STEPS.md`).

class ItemRequest(BaseModel):

    value: Optional[str] = None

```python title="crud.py"
from sqlalchemy.orm import Session

from models import ItemModel
from schemas import ItemPatch, ItemRequest


def get_items(db: Session) -> list[ItemModel]:
    return db.query(ItemModel).order_by(ItemModel.id).all()


def get_item(db: Session, item_id: int) -> ItemModel | None:
    return db.get(ItemModel, item_id)


def create_item(db: Session, item: ItemRequest) -> ItemModel:
    row = ItemModel(value=item.value)
    db.add(row)
    db.commit()
    db.refresh(row)
    return row


def replace_item(db: Session, item_id: int, item: ItemRequest) -> ItemModel | None:
    row = get_item(db, item_id)
    if row is None:
        return None
    row.value = item.value
    db.commit()
    db.refresh(row)
    return row


def update_item(db: Session, item_id: int, patch: ItemPatch) -> ItemModel | None:
    row = get_item(db, item_id)
    if row is None:
        return None
    if patch.value is not None:
        row.value = patch.value
    db.commit()
    db.refresh(row)
    return row


def delete_item(db: Session, item_id: int) -> bool:
    row = get_item(db, item_id)
    if row is None:
        return False
    db.delete(row)
    db.commit()
    return True


def seed_items(db: Session) -> None:
    if db.query(ItemModel).count() == 0:
        db.add_all([ItemModel(value="first"), ItemModel(value="second")])
        db.commit()
```

```python title="main.py"
from fastapi import Depends, FastAPI, HTTPException, status
from fastapi.middleware.cors import CORSMiddleware
from sqlalchemy.orm import Session

import crud
from database import Base, SessionLocal, engine, get_db
from schemas import ItemPatch, ItemRequest

Base.metadata.create_all(bind=engine)

with SessionLocal() as db:
    crud.seed_items(db)

app = FastAPI()

# The React dev server (Vite) runs on a different origin/port than this
# API, so the browser needs explicit permission to read the response.
app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:5173", "http://127.0.0.1:5173"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)


@app.get("/items")
def list_items(db: Session = Depends(get_db)):
    return [{"id": row.id, "value": row.value} for row in crud.get_items(db)]


@app.get("/items/{item_id}")
def get_item(item_id: int, db: Session = Depends(get_db)):
    row = crud.get_item(db, item_id)
    if row is None:
        raise HTTPException(status_code=404, detail="Item not found")
    return {"id": row.id, "value": row.value}


@app.post("/items", status_code=status.HTTP_201_CREATED)
def create_item(item: ItemRequest, db: Session = Depends(get_db)):
    row = crud.create_item(db, item)
    return {"id": row.id, "value": row.value}


@app.put("/items/{item_id}")
def replace_item(item_id: int, item: ItemRequest, db: Session = Depends(get_db)):
    row = crud.replace_item(db, item_id, item)
    if row is None:
        raise HTTPException(status_code=404, detail="Item not found")
    return {"id": row.id, "value": row.value}


@app.patch("/items/{item_id}")
def update_item(item_id: int, patch: ItemPatch, db: Session = Depends(get_db)):
    row = crud.update_item(db, item_id, patch)
    if row is None:
        raise HTTPException(status_code=404, detail="Item not found")
    return {"id": row.id, "value": row.value}


@app.delete("/items/{item_id}", status_code=status.HTTP_204_NO_CONTENT)
def delete_item(item_id: int, db: Session = Depends(get_db)):
    deleted = crud.delete_item(db, item_id)
    if not deleted:
        raise HTTPException(status_code=404, detail="Item not found")
```

**Frontend** — `example/7/react/src/App.jsx`, the whole UI:

```jsx title="example/7/react/src/App.jsx"
import { useEffect, useState } from "react";

// Where the FastAPI backend is running.
const API_URL = "http://127.0.0.1:8000";

export default function App() {
  const [items, setItems] = useState([]); // rows from the database, each { id, value }
  const [value, setValue] = useState(""); // what's typed in the "add" box
  const [reached, setReached] = useState(null); // result of "reach by id"
  const [error, setError] = useState(null);

  const [editingId, setEditingId] = useState(null); // which row's id is being edited
  const [editValue, setEditValue] = useState(""); // that row's in-progress text

  // Load every row once when the page opens.
  useEffect(() => {
    loadItems();
  }, []);

  // READ — GET /items, every row.
  async function loadItems() {
    try {
      const response = await fetch(`${API_URL}/items`);
      if (!response.ok) {
        throw new Error(`Failed to load items (status ${response.status})`);
      }
      setItems(await response.json());
      setError(null);
    } catch (err) {
      setError(err.message);
    }
  }

  // CREATE — POST /items, inserts a new row. The database assigns the id.
  async function addItem(event) {
    event.preventDefault();
    if (value.trim() === "") return;

    const response = await fetch(`${API_URL}/items`, {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ value: value }),
    });

    if (!response.ok) {
      setError(`Failed to add item (status ${response.status})`);
      return;
    }

    setValue("");
    await loadItems();
  }

  // REACH — GET /items/{id}, one specific row by its real database id
  // (not its position in the list — deleting a row never renumbers
  // anyone else's id, unlike the plain-array version of this topic).
  async function reachItem(id) {
    const response = await fetch(`${API_URL}/items/${id}`);
    if (!response.ok) {
      setError(`Failed to reach id ${id} (status ${response.status})`);
      setReached(null);
      return;
    }
    setReached(await response.json());
    setError(null);
  }

  function startEditing(id, currentValue) {
    setEditingId(id);
    setEditValue(currentValue);
  }

  // UPDATE — PUT or PATCH /items/{id}, depending which button was
  // clicked. Both send the same body here (this row only has one
  // field), but the HTTP method itself is what differs.
  async function saveEdit(id, method) {
    const response = await fetch(`${API_URL}/items/${id}`, {
      method: method, // "PUT" or "PATCH"
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ value: editValue }),
    });

    if (!response.ok) {
      setError(`Failed to update item (status ${response.status})`);
      return;
    }

    setEditingId(null);
    await loadItems();
  }

  // DELETE — DELETE /items/{id}, removes that row.
  async function deleteItem(id) {
    const response = await fetch(`${API_URL}/items/${id}`, {
      method: "DELETE",
    });

    if (!response.ok) {
      setError(`Failed to delete item (status ${response.status})`);
      return;
    }

    await loadItems();
  }

  return (
    <main style={{ maxWidth: 560, margin: "3rem auto", fontFamily: "sans-serif" }}>
      <h1>MySQL Store</h1>

      {error && <p style={{ color: "crimson" }}>{error}</p>}

      {/* CREATE form */}
      <form onSubmit={addItem} style={{ display: "flex", gap: "0.5rem" }}>
        <input
          value={value}
          onChange={(event) => setValue(event.target.value)}
          placeholder="Add a value"
          style={{ flex: 1, padding: "0.5rem" }}
        />
        <button type="submit">Add</button>
      </form>

      {/* READ: every row, one <li> per row via .map() */}
      <ul style={{ listStyle: "none", padding: 0, marginTop: "1.5rem" }}>
        {items.map((item) =>
          editingId === item.id ? (
            <li
              key={item.id}
              style={{ display: "flex", alignItems: "center", gap: "0.5rem", padding: "0.25rem 0" }}
            >
              <span style={{ color: "#888", width: "2rem" }}>#{item.id}</span>
              <input
                value={editValue}
                onChange={(event) => setEditValue(event.target.value)}
                style={{ flex: 1, padding: "0.25rem" }}
              />
              <button onClick={() => saveEdit(item.id, "PUT")}>Save (PUT)</button>
              <button onClick={() => saveEdit(item.id, "PATCH")}>Save (PATCH)</button>
              <button onClick={() => setEditingId(null)}>Cancel</button>
            </li>
          ) : (
            <li
              key={item.id}
              style={{ display: "flex", alignItems: "center", gap: "0.5rem", padding: "0.25rem 0" }}
            >
              <span style={{ color: "#888", width: "2rem" }}>#{item.id}</span>
              <span style={{ flex: 1 }}>{item.value}</span>
              {/* REACH: fetches this one id directly from the backend,
                  instead of just reading it from what's already in state */}
              <button onClick={() => reachItem(item.id)}>Reach</button>
              <button onClick={() => startEditing(item.id, item.value)}>Edit</button>
              <button onClick={() => deleteItem(item.id)}>Delete</button>
            </li>
          ),
        )}
      </ul>

      {items.length === 0 && !error && <p>No rows yet — add something above.</p>}

      {reached && (
        <p style={{ marginTop: "1rem" }}>
          Reached id <strong>#{reached.id}</strong>: <strong>{reached.value}</strong>
        </p>
      )}
    </main>
  );
}
```

## The backend

[MySQL + CRUD](/en/docs/mysql-crud)'s five routes, combined into
one running app — same as how [Array + CRUD](/en/docs/array-crud)'s
routes were combined for [React + Array + CRUD](/en/docs/react) — plus the same
`CORSMiddleware` from that topic:

```python
app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:5173", "http://127.0.0.1:5173"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

Nothing else changes — CORS doesn't care what's behind the routes it's
protecting.

## Same frontend, one renamed piece of state

This is the exact same app as [React + Array + CRUD](/en/docs/react), pointed at the
MySQL backend above instead of the array backend. Every page in this
section is a direct comparison — the diff is always the same one
change: **index → id**.

```jsx
const [items, setItems] = useState([]);          // rows from the database, each { id, value }
const [editingId, setEditingId] = useState(null); // which row's id is being edited
```

`editingIndex` → `editingId`. Same idea, renamed to match what it
actually holds now — a database ID, not a position in an array. `items`
also changed shape: each entry is `{ id, value }` instead of a plain
string.

1. [GET](/en/docs/mysql-react/get) — loading rows, and reaching one by ID.
2. [POST](/en/docs/mysql-react/post) — the add form (unchanged).
3. [PUT](/en/docs/mysql-react/put) — the "Save (PUT)" button, addressed by ID.
4. [PATCH](/en/docs/mysql-react/patch) — the "Save (PATCH)" button, addressed by ID.
5. [DELETE](/en/docs/mysql-react/delete) — deleting a row, and why IDs don't shift.

## Running this topic

Needs the same database setup as [MySQL + CRUD](/en/docs/mysql-crud),
plus both backend and frontend running at once:

1. **One-time database setup** (skip if already done for that topic):

   ```bash
   pip install sqlalchemy pymysql
   ```

   ```sql
   CREATE DATABASE fastapi_learn;
   ```

   ```bash
   export MYSQL_HOST=127.0.0.1
   export MYSQL_PORT=3306
   export MYSQL_USER=root
   export MYSQL_PASSWORD=your-password
   export MYSQL_DB=fastapi_learn
   ```

   No MySQL handy? `export DATABASE_URL="sqlite:///./test.db"` instead.

2. **Terminal 1 — backend:**

   ```bash
   cd example/7/a
   uvicorn main:app --reload
   ```

3. **Terminal 2 — frontend:**

   ```bash
   cd example/7/react
   npm install
   npm run dev
   ```

4. Open the URL Vite prints (usually
   [http://localhost:5173](http://localhost:5173)).

The full frontend code lives in `example/7/react` in this repo (see its
`README.md` and `STEPS.md`).

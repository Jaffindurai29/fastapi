## Backend

**`database.py`** and **`models.py`** — same connection, session, and
`ItemModel` table as [GET](/en/docs/mysql-react/get), unchanged here.

**`schemas.py`** — the request body this route validates against:

```python title="schemas.py"
class ItemRequest(BaseModel):
    value: str
```

**`crud.py`** — the insert function:

```python title="crud.py"
def create_item(db: Session, item: ItemRequest) -> ItemModel:
    row = ItemModel(value=item.value)
    db.add(row)
    db.commit()
    db.refresh(row)
    return row
```

**`main.py`** — the route:

```python title="main.py"
@app.post("/items", status_code=status.HTTP_201_CREATED)
def create_item(item: ItemRequest, db: Session = Depends(get_db)):
    row = crud.create_item(db, item)
    return {"id": row.id, "value": row.value}
```

## Line by line

`database.py`'s connection/`get_db()` and `models.py`'s `ItemModel` are
shared setup, explained once on the [index page](/en/docs/mysql-react).
Below covers what's new on this page: `schemas.py`'s `ItemRequest`,
`crud.py`'s `create_item`, and the route in `main.py` that calls it.

1. `class ItemRequest(BaseModel):` — a Pydantic model FastAPI uses to
   validate the incoming JSON body; a request missing `value`, or
   sending the wrong type, is rejected with a `422` before this route's
   body ever runs.
2. `db: Session = Depends(get_db)` — same dependency injection as
   [GET](/en/docs/mysql-react/get): FastAPI runs `get_db()` up to its
   `yield` before this route body executes, hands over the freshly
   created session as `db`, and closes that session automatically once
   this route finishes, success or failure.
3. `row = ItemModel(value=item.value)` — builds a new ORM object in
   memory; nothing is written to the database yet.
4. `db.add(row)` — only stages the new object in the session's pending
   state; nothing is sent to MySQL yet.
5. `db.commit()` — flushes that pending `INSERT` and commits the
   transaction. This is the moment MySQL actually assigns the
   auto-increment `id`.
6. `db.refresh(row)` — re-queries `row` from the database so `row.id`
   reflects the real generated value. Skip it and `row.id` could still
   be stale or `None`, since SQLAlchemy doesn't know the
   database-generated value without asking for it back.
7. Back in `main.py`, `crud.create_item(db, item)` returns the whole
   `ItemModel` object; the route itself reshapes just `row.id` and
   `row.value` into the plain dict FastAPI serializes to JSON — the
   same split between "database logic" and "HTTP response shape" as
   every route in this topic.

## Frontend

## No difference here

```jsx
async function addItem(event) {
  event.preventDefault();
  if (value.trim() === "") return;

  const response = await fetch(`${API_URL}/items`, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ value: value }),
  });

  if (!response.ok) {
    setError(`Failed to add item (status ${response.status})`);
    return;
  }

  setValue("");
  await loadItems();
}
```

Identical to [React's POST](/en/docs/react/post) — the request body is
the same `{ value }` shape either way. **The one thing that changed
happened on the backend, not here:** the database now assigns a real
`id` to the new row, instead of the frontend assuming it landed at
`items.length`.

## Line by line

1. `addItem` is byte-for-byte identical to the array version's
   function — same `event.preventDefault()`, same empty-value guard,
   same `fetch` call and body shape. None of this code deals with item
   identity (`index` vs `id`) at all, which is exactly why nothing here
   needed to change.
2. `event.preventDefault()` still stops the browser's default
   full-page reload on submit — unrelated to MySQL, unaffected by
   swapping the backend.
3. `if (value.trim() === "") return;` still skips the request entirely
   for an empty or whitespace-only input.
4. On success, `setValue("")` clears the input, then `await
   loadItems()` refetches the full list from the backend — this is
   actually where the new row's `id` shows up on the frontend: it
   arrives through this refetch, not from anything the frontend
   computed. Contrast with the array version, where the frontend could
   already guess the new item's index would be `items.length`.
5. The one real change lives entirely on the backend: MySQL assigns a
   real auto-incrementing `id` to the new row, instead of the frontend
   assuming a computed array position.

```python title="database.py"
import os

from dotenv import load_dotenv
from sqlalchemy import create_engine
from sqlalchemy.orm import Session, declarative_base, sessionmaker

load_dotenv()

MYSQL_HOST = os.getenv("MYSQL_HOST", "127.0.0.1")
MYSQL_PORT = os.getenv("MYSQL_PORT", "3306")
MYSQL_USER = os.getenv("MYSQL_USER", "root")
MYSQL_PASSWORD = os.getenv("MYSQL_PASSWORD", "")
MYSQL_DB = os.getenv("MYSQL_DB", "fastapi_learn")

DATABASE_URL = os.getenv(
    "DATABASE_URL",
    f"mysql+pymysql://{MYSQL_USER}:{MYSQL_PASSWORD}@{MYSQL_HOST}:{MYSQL_PORT}/{MYSQL_DB}",
)

engine = create_engine(DATABASE_URL, pool_pre_ping=True)
SessionLocal = sessionmaker(autocommit=False, autoflush=False, bind=engine)
Base = declarative_base()


def get_db():
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()
```

```python title="crud.py"
from sqlalchemy.orm import Session

from models import ItemModel
from schemas import ItemRequest


def get_items(db: Session) -> list[ItemModel]:
    return db.query(ItemModel).order_by(ItemModel.id).all()


def get_item(db: Session, item_id: int) -> ItemModel | None:
    return db.get(ItemModel, item_id)


def create_item(db: Session, item: ItemRequest) -> ItemModel:
    row = ItemModel(value=item.value)
    db.add(row)
    db.commit()
    db.refresh(row)
    return row
```

```python title="main.py"
from fastapi import Depends, FastAPI, HTTPException, status
from fastapi.middleware.cors import CORSMiddleware
from sqlalchemy.orm import Session

import crud
from database import Base, SessionLocal, engine, get_db
from schemas import ItemRequest

Base.metadata.create_all(bind=engine)

with SessionLocal() as db:
    crud.seed_items(db)

app = FastAPI()

app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:5173", "http://127.0.0.1:5173"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)


@app.get("/items")
def list_items(db: Session = Depends(get_db)):
    return [{"id": row.id, "value": row.value} for row in crud.get_items(db)]


@app.get("/items/{item_id}")
def get_item(item_id: int, db: Session = Depends(get_db)):
    row = crud.get_item(db, item_id)
    if row is None:
        raise HTTPException(status_code=404, detail="Item not found")
    return {"id": row.id, "value": row.value}


@app.post("/items", status_code=status.HTTP_201_CREATED)
def create_item(item: ItemRequest, db: Session = Depends(get_db)):
    row = crud.create_item(db, item)
    return {"id": row.id, "value": row.value}
```

**Frontend** — `example/7/react/src/App.jsx`, up to POST:

```jsx title="example/7/react/src/App.jsx"
import { useEffect, useState } from "react";

const API_URL = "http://127.0.0.1:8000";

export default function App() {
  const [items, setItems] = useState([]);
  const [value, setValue] = useState("");
  const [reached, setReached] = useState(null);
  const [error, setError] = useState(null);

  useEffect(() => {
    loadItems();
  }, []);

  async function loadItems() {
    try {
      const response = await fetch(`${API_URL}/items`);
      if (!response.ok) {
        throw new Error(`Failed to load items (status ${response.status})`);
      }
      setItems(await response.json());
      setError(null);
    } catch (err) {
      setError(err.message);
    }
  }

  async function addItem(event) {
    event.preventDefault();
    if (value.trim() === "") return;

    const response = await fetch(`${API_URL}/items`, {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ value: value }),
    });

    if (!response.ok) {
      setError(`Failed to add item (status ${response.status})`);
      return;
    }

    setValue("");
    await loadItems();
  }

  async function reachItem(id) {
    const response = await fetch(`${API_URL}/items/${id}`);
    if (!response.ok) {
      setError(`Failed to reach id ${id} (status ${response.status})`);
      setReached(null);
      return;
    }
    setReached(await response.json());
    setError(null);
  }

  return (
    <main style={{ maxWidth: 560, margin: "3rem auto", fontFamily: "sans-serif" }}>
      <h1>MySQL Store</h1>

      {error && <p style={{ color: "crimson" }}>{error}</p>}

      <form onSubmit={addItem} style={{ display: "flex", gap: "0.5rem" }}>
        <input
          value={value}
          onChange={(event) => setValue(event.target.value)}
          placeholder="Add a value"
          style={{ flex: 1, padding: "0.5rem" }}
        />
        <button type="submit">Add</button>
      </form>

      <ul style={{ listStyle: "none", padding: 0, marginTop: "1.5rem" }}>
        {items.map((item) => (
          <li
            key={item.id}
            style={{ display: "flex", alignItems: "center", gap: "0.5rem", padding: "0.25rem 0" }}
          >
            <span style={{ color: "#888", width: "2rem" }}>#{item.id}</span>
            <span style={{ flex: 1 }}>{item.value}</span>
            <button onClick={() => reachItem(item.id)}>Reach</button>
          </li>
        ))}
      </ul>

      {reached && (
        <p style={{ marginTop: "1rem" }}>
          Reached id <strong>#{reached.id}</strong>: <strong>{reached.value}</strong>
        </p>
      )}
    </main>
  );
}
```

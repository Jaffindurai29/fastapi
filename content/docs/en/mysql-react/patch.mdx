## Backend

**`database.py`** and **`models.py`** — same connection, session, and
`ItemModel` table as [GET](/en/docs/mysql-react/get), unchanged here.

**`schemas.py`** — `ItemPatch`, alongside [PUT](/en/docs/mysql-react/put)'s
`ItemRequest`:

```python title="schemas.py"
class ItemPatch(BaseModel):
    value: Optional[str] = None
```

**`crud.py`** — the partial-update function:

```python title="crud.py"
def update_item(db: Session, item_id: int, patch: ItemPatch) -> ItemModel | None:
    row = get_item(db, item_id)
    if row is None:
        return None
    if patch.value is not None:
        row.value = patch.value
    db.commit()
    db.refresh(row)
    return row
```

**`main.py`** — the route:

```python title="main.py"
@app.patch("/items/{item_id}")
def update_item(item_id: int, patch: ItemPatch, db: Session = Depends(get_db)):
    row = crud.update_item(db, item_id, patch)
    if row is None:
        raise HTTPException(status_code=404, detail="Item not found")
    return {"id": row.id, "value": row.value}
```

## Line by line

`database.py`'s connection/`get_db()` and `models.py`'s `ItemModel` are
shared setup, explained once on the [index page](/en/docs/mysql-react).
Below covers what's new on this page: `schemas.py`'s `ItemPatch`,
`crud.py`'s `update_item`, and the route in `main.py` that calls it.

1. `db: Session = Depends(get_db)` — same session-per-request pattern
   as every other route in this topic: FastAPI supplies it via
   `get_db()` before the function runs and closes it automatically once
   the function is done, even on an error.
2. **`update_item` checks the row exists first** — `get_item(db,
   item_id)` returns the `ItemModel` object if that ID exists, or
   `None` if it doesn't.
   - Back in `main.py`, `if row is None: raise
     HTTPException(status_code=404, ...)` sends back a clean `404`
     before the response ever mentions `row`.
   - If `crud.update_item` skipped that check, the later
     `row.value = patch.value` line would raise `AttributeError:
     'NoneType' object has no attribute 'value'` on a missing ID —
     FastAPI turns that into a generic `500 Internal Server Error`
     instead of a proper `404`.
3. **`ItemPatch.value` is optional** — unlike PUT's `ItemRequest`,
   where `value` is required.
4. **`if patch.value is not None: row.value = patch.value`** — only
   updates the row if the client actually sent a value. Just like in
   [PUT](/en/docs/mysql-react/put)'s `replace_item`, that plain
   assignment alone is enough for SQLAlchemy to notice: `row` came from
   `get_item(...)` earlier in this same session, so its "unit of work"
   is already tracking it, and no `db.add(row)` is needed to register
   the change.
5. **`db.commit()`** flushes that tracked change (if any) as an
   `UPDATE` statement and commits the transaction. If the client sent
   `{}` and `patch.value` stayed `None`, nothing was ever assigned, so
   this commit has nothing new to write — a harmless no-op.
6. **`db.refresh(row)`** re-queries `row` from the database afterward,
   so the `{"id": row.id, "value": row.value}` `main.py` returns
   reflects exactly what's in MySQL right now, whether or not this
   particular request actually changed anything.

## Frontend

## Same story as the array version

```jsx
<button onClick={() => saveEdit(item.id, "PATCH")}>Save (PATCH)</button>
```

Compared to [PUT](/en/docs/mysql-react/put)'s button:

```jsx
<button onClick={() => saveEdit(item.id, "PUT")}>Save (PUT)</button>
```

Exactly the same relationship as [React's PATCH](/en/docs/react/patch)
— one shared `saveEdit` function, one string argument that decides the
HTTP method. The only thing different here versus the array version is
`item.id` instead of `index` as the first argument.

## Line by line

1. No separate `savePatch` function exists here either — `saveEdit`
   already takes `method` as a parameter, exactly like the array
   version.
2. The **"Save (PATCH)"** button calls `saveEdit(item.id, "PATCH")` —
   same function, same request body, only the HTTP method string
   differs. The one difference from the array version is reading
   `item.id` straight off the row object, instead of passing a
   `.map()` loop index.
3. That one string (`"PUT"` vs `"PATCH"`) is still the only real
   difference between the two buttons — the component, the request
   body, and the `fetch` call inside `saveEdit` are identical either
   way.
4. Both buttons sit side by side in edit mode, next to a **"Cancel"**
   button that just sets `editingId` back to `null` without saving —
   same layout as the array version, `editingIndex` renamed to
   `editingId`.

```python title="database.py"
import os

from dotenv import load_dotenv
from sqlalchemy import create_engine
from sqlalchemy.orm import Session, declarative_base, sessionmaker

load_dotenv()

MYSQL_HOST = os.getenv("MYSQL_HOST", "127.0.0.1")
MYSQL_PORT = os.getenv("MYSQL_PORT", "3306")
MYSQL_USER = os.getenv("MYSQL_USER", "root")
MYSQL_PASSWORD = os.getenv("MYSQL_PASSWORD", "")
MYSQL_DB = os.getenv("MYSQL_DB", "fastapi_learn")

DATABASE_URL = os.getenv(
    "DATABASE_URL",
    f"mysql+pymysql://{MYSQL_USER}:{MYSQL_PASSWORD}@{MYSQL_HOST}:{MYSQL_PORT}/{MYSQL_DB}",
)

engine = create_engine(DATABASE_URL, pool_pre_ping=True)
SessionLocal = sessionmaker(autocommit=False, autoflush=False, bind=engine)
Base = declarative_base()


def get_db():
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()
```

```python title="schemas.py"
from pydantic import BaseModel


class ItemRequest(BaseModel):
    value: str


class ItemPatch(BaseModel):
    value: Optional[str] = None
```

```python title="crud.py"
from sqlalchemy.orm import Session

from models import ItemModel
from schemas import ItemPatch, ItemRequest


def get_items(db: Session) -> list[ItemModel]:
    return db.query(ItemModel).order_by(ItemModel.id).all()


def get_item(db: Session, item_id: int) -> ItemModel | None:
    return db.get(ItemModel, item_id)


def create_item(db: Session, item: ItemRequest) -> ItemModel:
    row = ItemModel(value=item.value)
    db.add(row)
    db.commit()
    db.refresh(row)
    return row


def replace_item(db: Session, item_id: int, item: ItemRequest) -> ItemModel | None:
    row = get_item(db, item_id)
    if row is None:
        return None
    row.value = item.value
    db.commit()
    db.refresh(row)
    return row


def update_item(db: Session, item_id: int, patch: ItemPatch) -> ItemModel | None:
    row = get_item(db, item_id)
    if row is None:
        return None
    if patch.value is not None:
        row.value = patch.value
    db.commit()
    db.refresh(row)
    return row
```

```python title="main.py"
from fastapi import Depends, FastAPI, HTTPException, status
from fastapi.middleware.cors import CORSMiddleware
from sqlalchemy.orm import Session

import crud
from database import Base, SessionLocal, engine, get_db
from schemas import ItemPatch, ItemRequest

Base.metadata.create_all(bind=engine)

with SessionLocal() as db:
    crud.seed_items(db)

app = FastAPI()

app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:5173", "http://127.0.0.1:5173"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)


@app.get("/items")
def list_items(db: Session = Depends(get_db)):
    return [{"id": row.id, "value": row.value} for row in crud.get_items(db)]


@app.get("/items/{item_id}")
def get_item(item_id: int, db: Session = Depends(get_db)):
    row = crud.get_item(db, item_id)
    if row is None:
        raise HTTPException(status_code=404, detail="Item not found")
    return {"id": row.id, "value": row.value}


@app.post("/items", status_code=status.HTTP_201_CREATED)
def create_item(item: ItemRequest, db: Session = Depends(get_db)):
    row = crud.create_item(db, item)
    return {"id": row.id, "value": row.value}


@app.put("/items/{item_id}")
def replace_item(item_id: int, item: ItemRequest, db: Session = Depends(get_db)):
    row = crud.replace_item(db, item_id, item)
    if row is None:
        raise HTTPException(status_code=404, detail="Item not found")
    return {"id": row.id, "value": row.value}


@app.patch("/items/{item_id}")
def update_item(item_id: int, patch: ItemPatch, db: Session = Depends(get_db)):
    row = crud.update_item(db, item_id, patch)
    if row is None:
        raise HTTPException(status_code=404, detail="Item not found")
    return {"id": row.id, "value": row.value}
```

**Frontend** — `example/7/react/src/App.jsx`, up to PATCH:

```jsx title="example/7/react/src/App.jsx"
import { useEffect, useState } from "react";

const API_URL = "http://127.0.0.1:8000";

export default function App() {
  const [items, setItems] = useState([]);
  const [value, setValue] = useState("");
  const [reached, setReached] = useState(null);
  const [error, setError] = useState(null);

  const [editingId, setEditingId] = useState(null);
  const [editValue, setEditValue] = useState("");

  useEffect(() => {
    loadItems();
  }, []);

  async function loadItems() {
    try {
      const response = await fetch(`${API_URL}/items`);
      if (!response.ok) {
        throw new Error(`Failed to load items (status ${response.status})`);
      }
      setItems(await response.json());
      setError(null);
    } catch (err) {
      setError(err.message);
    }
  }

  async function addItem(event) {
    event.preventDefault();
    if (value.trim() === "") return;

    const response = await fetch(`${API_URL}/items`, {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ value: value }),
    });

    if (!response.ok) {
      setError(`Failed to add item (status ${response.status})`);
      return;
    }

    setValue("");
    await loadItems();
  }

  async function reachItem(id) {
    const response = await fetch(`${API_URL}/items/${id}`);
    if (!response.ok) {
      setError(`Failed to reach id ${id} (status ${response.status})`);
      setReached(null);
      return;
    }
    setReached(await response.json());
    setError(null);
  }

  function startEditing(id, currentValue) {
    setEditingId(id);
    setEditValue(currentValue);
  }

  async function saveEdit(id, method) {
    const response = await fetch(`${API_URL}/items/${id}`, {
      method: method, // "PUT" or "PATCH"
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ value: editValue }),
    });

    if (!response.ok) {
      setError(`Failed to update item (status ${response.status})`);
      return;
    }

    setEditingId(null);
    await loadItems();
  }

  return (
    <main style={{ maxWidth: 560, margin: "3rem auto", fontFamily: "sans-serif" }}>
      <h1>MySQL Store</h1>

      {error && <p style={{ color: "crimson" }}>{error}</p>}

      <form onSubmit={addItem} style={{ display: "flex", gap: "0.5rem" }}>
        <input
          value={value}
          onChange={(event) => setValue(event.target.value)}
          placeholder="Add a value"
          style={{ flex: 1, padding: "0.5rem" }}
        />
        <button type="submit">Add</button>
      </form>

      <ul style={{ listStyle: "none", padding: 0, marginTop: "1.5rem" }}>
        {items.map((item) =>
          editingId === item.id ? (
            <li
              key={item.id}
              style={{ display: "flex", alignItems: "center", gap: "0.5rem", padding: "0.25rem 0" }}
            >
              <span style={{ color: "#888", width: "2rem" }}>#{item.id}</span>
              <input
                value={editValue}
                onChange={(event) => setEditValue(event.target.value)}
                style={{ flex: 1, padding: "0.25rem" }}
              />
              <button onClick={() => saveEdit(item.id, "PUT")}>Save (PUT)</button>
              <button onClick={() => saveEdit(item.id, "PATCH")}>Save (PATCH)</button>
              <button onClick={() => setEditingId(null)}>Cancel</button>
            </li>
          ) : (
            <li
              key={item.id}
              style={{ display: "flex", alignItems: "center", gap: "0.5rem", padding: "0.25rem 0" }}
            >
              <span style={{ color: "#888", width: "2rem" }}>#{item.id}</span>
              <span style={{ flex: 1 }}>{item.value}</span>
              <button onClick={() => reachItem(item.id)}>Reach</button>
              <button onClick={() => startEditing(item.id, item.value)}>Edit</button>
            </li>
          ),
        )}
      </ul>

      {reached && (
        <p style={{ marginTop: "1rem" }}>
          Reached id <strong>#{reached.id}</strong>: <strong>{reached.value}</strong>
        </p>
      )}
    </main>
  );
}
```

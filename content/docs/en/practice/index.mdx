---
title: Practice Exercises
description: Six small drills to build muscle memory before going further.
---

These aren't a new concept — just six quick reps using what you already
know from [First Steps](/en/docs/first-steps) and
[Path Parameters](/en/docs/path-parameters), to get comfortable before
moving on.

Each page in this section is one exercise: the full code, a line-by-line
walkthrough, and the actual output you should see when you try it.

1. [GET: Dynamic Name](/en/docs/practice/get-dynamic-name) — read a value from the URL path.
2. [POST: Dynamic Name](/en/docs/practice/post-dynamic-name) — read the same kind of value from a JSON body instead.
3. [Add Two Numbers](/en/docs/practice/add-two-numbers) — a POST route that does simple math.
4. [Calculator](/en/docs/practice/calculator) — branch on an `operation` field, handle bad input on purpose.
5. [Show, Append & Print](/en/docs/practice/show-append-print) — a tiny in-memory list with GET and POST.
6. [Login Authentication](/en/docs/practice/login-authentication) — the shape of a login check, kept deliberately simple.

Work through them in order, or jump straight to whichever one you need.

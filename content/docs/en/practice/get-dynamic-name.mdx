---
title: "1. GET: Dynamic Name"
description: Read a value straight from the URL path.
---

## The code

```python title="main.py"
from fastapi import FastAPI

app = FastAPI()

@app.get("/hello/{name}")
def say_hello(name: str):
    return {"message": f"Hello, {name}!"}
```

## Line by line

1. `from fastapi import FastAPI` — the one import every app needs.
2. `app = FastAPI()` — creates the application object Uvicorn will run.
3. `@app.get("/hello/{name}")` — registers a route for `GET` requests to
   `/hello/...`. The `{name}` part is a placeholder: whatever text
   appears there in the real URL gets captured.
4. `def say_hello(name: str):` — the parameter name (`name`) must match
   the placeholder in the path exactly. FastAPI reads the URL, pulls out
   that piece, and hands it to you already as a `str`.
5. `return {"message": f"Hello, {name}!"}` — an f-string builds the
   response using whatever value came in. Different URL, different
   output — same function.

## Try it

```bash
cd example/3/a
uvicorn main:app --reload
```

```bash
curl http://127.0.0.1:8000/hello/Alice
```

**Output:**

```json
{"message": "Hello, Alice!"}
```

Visit `/hello/Bob` instead and the output changes to
`{"message": "Hello, Bob!"}` — same route, driven entirely by the URL.

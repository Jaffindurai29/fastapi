---
title: "3. Add Two Numbers"
description: A POST route that takes two numbers and does simple math.
---

## The code

```python title="main.py"
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class AddRequest(BaseModel):
    a: float
    b: float

@app.post("/add")
def add_numbers(request: AddRequest):
    return {"result": request.a + request.b}
```

## Line by line

1. `class AddRequest(BaseModel): a: float, b: float` — two required
   numeric fields. `float` accepts whole numbers too (`5` becomes
   `5.0`), so you don't need a separate `int` version.
2. `@app.post("/add")` — one route, no path parameters.
3. `def add_numbers(request: AddRequest):` — FastAPI parses the JSON
   body into `request`, validating both fields are actually numbers
   before this function runs.
4. `return {"result": request.a + request.b}` — plain Python addition on
   two already-validated numbers.

## Try it

```bash
cd example/3/c
uvicorn main:app --reload
```

```bash
curl -X POST http://127.0.0.1:8000/add -H "Content-Type: application/json" -d "{\"a\": 5, \"b\": 3}"
```

**Output:**

```json
{"result": 8.0}
```

Note it's `8.0`, not `8` — both fields are typed as `float`, so the
result is too.

## Requirements

FastAPI needs Python 3.8 or above. Check what you have installed:

```bash
python --version
```

## Create a virtual environment

It's best practice to keep each project's dependencies isolated in a virtual
environment.

```bash
python -m venv venv
```

Activate it:

```bash title="macOS / Linux"
source venv/bin/activate
```

```bash title="Windows (PowerShell)"
venv\Scripts\Activate.ps1
```

## Install FastAPI and a server

FastAPI itself doesn't include a server. [Uvicorn](https://www.uvicorn.org/)
is the recommended ASGI server for development.

```bash
pip install fastapi uvicorn[standard]
```

- `fastapi` — the framework itself.
- `uvicorn[standard]` — an ASGI server to actually run your app, with extra
  performance and reload dependencies.

## Verify the install

```bash
python -c "import fastapi; print(fastapi.__version__)"
```

If that prints a version number without errors, you're ready for
[First Steps](/en/docs/first-steps).

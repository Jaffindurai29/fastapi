## Backend

```python title="example/5/a/main.py"
@app.get("/items")
def list_items():
    return data


@app.get("/items/{item_index}")
def get_item(item_index: int):
    if item_index < 0 or item_index >= len(data):
        raise HTTPException(status_code=404, detail="Item not found")
    return {"index": item_index, "value": data[item_index]}
```

1. `GET /items` returns the whole array as-is.
2. `GET /items/{item_index}` reaches one entry by its position, with a
   bounds check before indexing.
3. Skipping that bounds check would let an out-of-range index raise
   Python's own `IndexError`, which turns into a generic `500` instead
   of a clean `404`.
4. Nothing here is React-specific — the only addition for this topic
   is `CORSMiddleware`, registered once right after `app = FastAPI()`,
   so the browser is allowed to call these routes at all.

## Frontend

## Load on page open

```jsx
useEffect(() => {
  loadItems();
}, []);

async function loadItems() {
  const response = await fetch(`${API_URL}/items`);
  if (!response.ok) {
    setError(`Failed to load items (status ${response.status})`);
    return;
  }
  setItems(await response.json());
  setError(null);
}
```

`useEffect(..., [])` runs once, right after the first render — that's
what loads the starting list. `loadItems` is also called again after
every create/update/delete below, so the page always reflects what the
server actually has, not just an optimistic guess.

## Reach one item by index

```jsx
async function reachItem(index) {
  const response = await fetch(`${API_URL}/items/${index}`);
  if (!response.ok) {
    setError(`Failed to reach index ${index} (status ${response.status})`);
    setReached(null);
    return;
  }
  setReached(await response.json());
  setError(null);
}
```

Stored in its own `reached` state, separate from `items` — so it's
visibly a fresh fetch, not just re-reading something already on the
page. Wired to a **"Reach"** button next to each row.

## Line by line

1. `useEffect(() => { loadItems(); }, [])` — the empty dependency array
   means this runs exactly once, right after the first render, loading
   the starting list.
2. `loadItems()` calls `GET /items`; on failure it sets `error` instead
   of throwing, so the page shows a message instead of crashing.
3. `loadItems()` runs again after every create/update/delete elsewhere
   in the app, so the page always reflects what the server actually
   has, not just an optimistic guess.
4. `reachItem(index)` calls `GET /items/{index}` and stores the result
   in its own `reached` state, separate from `items` — so it's visibly
   a fresh fetch, not just something already on the page.
5. The **"Reach"** button next to each row calls `reachItem(index)`
   with that row's position.

## Code so far

**Backend** — `example/5/a/main.py`, up to GET:

```python title="example/5/a/main.py"
from fastapi import FastAPI, HTTPException
from fastapi.middleware.cors import CORSMiddleware

app = FastAPI()

app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:5173", "http://127.0.0.1:5173"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)

data = ["first", "second"]


@app.get("/items")
def list_items():
    return data


@app.get("/items/{item_index}")
def get_item(item_index: int):
    if item_index < 0 or item_index >= len(data):
        raise HTTPException(status_code=404, detail="Item not found")
    return {"index": item_index, "value": data[item_index]}
```

**Frontend** — `example/5/react/src/App.jsx`, up to GET:

```jsx title="example/5/react/src/App.jsx"
import { useEffect, useState } from "react";

const API_URL = "http://127.0.0.1:8000";

export default function App() {
  const [items, setItems] = useState([]);
  const [reached, setReached] = useState(null);
  const [error, setError] = useState(null);

  useEffect(() => {
    loadItems();
  }, []);

  async function loadItems() {
    try {
      const response = await fetch(`${API_URL}/items`);
      if (!response.ok) {
        throw new Error(`Failed to load items (status ${response.status})`);
      }
      setItems(await response.json());
      setError(null);
    } catch (err) {
      setError(err.message);
    }
  }

  async function reachItem(index) {
    const response = await fetch(`${API_URL}/items/${index}`);
    if (!response.ok) {
      setError(`Failed to reach index ${index} (status ${response.status})`);
      setReached(null);
      return;
    }
    setReached(await response.json());
    setError(null);
  }

  return (
    <main style={{ maxWidth: 560, margin: "3rem auto", fontFamily: "sans-serif" }}>
      <h1>Array Store</h1>

      {error && <p style={{ color: "crimson" }}>{error}</p>}

      <ul style={{ listStyle: "none", padding: 0, marginTop: "1.5rem" }}>
        {items.map((item, index) => (
          <li
            key={index}
            style={{ display: "flex", alignItems: "center", gap: "0.5rem", padding: "0.25rem 0" }}
          >
            <span style={{ color: "#888", width: "1.5rem" }}>{index}</span>
            <span style={{ flex: 1 }}>{item}</span>
            <button onClick={() => reachItem(index)}>Reach</button>
          </li>
        ))}
      </ul>

      {reached && (
        <p style={{ marginTop: "1rem" }}>
          Reached index <strong>{reached.index}</strong>:{" "}
          <strong>{reached.value}</strong>
        </p>
      )}
    </main>
  );
}
```

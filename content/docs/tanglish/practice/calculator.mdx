## Code

```python title="main.py"
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class CalculateRequest(BaseModel):
    a: float
    b: float
    operation: str

@app.post("/calculate")
def calculate(request: CalculateRequest):
    if request.operation == "add":
        result = request.a + request.b
    elif request.operation == "subtract":
        result = request.a - request.b
    elif request.operation == "multiply":
        result = request.a * request.b
    elif request.operation == "divide":
        if request.b == 0:
            raise HTTPException(status_code=400, detail="Cannot divide by zero")
        result = request.a / request.b
    else:
        raise HTTPException(
            status_code=400,
            detail="operation must be one of: add, subtract, multiply, divide",
        )
    return {"result": result}
```

## Line by line

1. `operation: str` — rendu numbers-oda moonavadhu field, edha
   calculation run pannanum nu vechirukum.
2. `if / elif` chain — `request.operation`-ah expected nalu words-la
   ovonna check pannum, match aana `result`-ah compute pannum.
3. **Zero check dhan important part:** `b: float` `0`-ah easy-a accept
   pannikum — type hint "indha specific value problem" nu catch panna
   mudiyadhu. So code explicit-a check pannudhu, `a / b` try pannuradhukku
   munnadi `HTTPException(400, ...)` raise pannudhu.
4. **Final `else`** expected nalu words-la illama irukra edhavadhum —
   typo, illana client garbage anuppudhu — adha `400`-a catch pannum,
   client-kku enna allowed nu solra message-oda.
5. `return {"result": result}` — mela irukra branches-la edhavadhu oru
   `result`-ah raise pannama set panni irundha mattum dhan reach aagum.

## Try it

```bash
cd example/3/d
uvicorn main:app --reload
```

```bash
curl -X POST http://127.0.0.1:8000/calculate -H "Content-Type: application/json" -d "{\"a\": 5, \"b\": 3, \"operation\": \"multiply\"}"
```

**Output:**

```json
{"result": 15.0}
```

Ippo zero-ah divide pannunga:

```bash
curl -i -X POST http://127.0.0.1:8000/calculate -H "Content-Type: application/json" -d "{\"a\": 5, \"b\": 0, \"operation\": \"divide\"}"
```

**Output:** `400 Bad Request`

```json
{"detail": "Cannot divide by zero"}
```

Mattrum unknown operation:

```bash
curl -i -X POST http://127.0.0.1:8000/calculate -H "Content-Type: application/json" -d "{\"a\": 5, \"b\": 3, \"operation\": \"power\"}"
```

**Output:** `400 Bad Request`

```json
{"detail": "operation must be one of: add, subtract, multiply, divide"}
```

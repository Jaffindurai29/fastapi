title: "1. GET: Dynamic Name"
description: URL path-la irundhu straight-a oru value padikkurathu.
---

## Code

```python title="main.py"
from fastapi import FastAPI

app = FastAPI()

@app.get("/hello/{name}")
def say_hello(name: str):
    return {"message": f"Hello, {name}!"}
```

## Line by line

1. `from fastapi import FastAPI` — ovoru app-kum venum oru import.
2. `app = FastAPI()` — Uvicorn run panra application object-ah create pannudhu.
3. `@app.get("/hello/{name}")` — `/hello/...` ku varra `GET` requests-kku
   route register pannudhu. `{name}` part oru placeholder: real URL-la
   andha idathula edhu irundhalum, adha capture pannikum.
4. `def say_hello(name: str):` — parameter name (`name`) path-la irukra
   placeholder-oda exact-a match aaganum. FastAPI URL-ah padichu, andha
   piece-ah eduthu, already `str`-a unga function-ku kudukkum.
5. `return {"message": f"Hello, {name}!"}` — f-string vandha value
   vachi response-ah build pannum. Different URL, different output —
   same function.

## Try it

```bash
cd example/3/a
uvicorn main:app --reload
```

```bash
curl http://127.0.0.1:8000/hello/Alice
```

**Output:**

```json
{"message": "Hello, Alice!"}
```

`/hello/Bob` visit panna, output `{"message": "Hello, Bob!"}` nu
maarum — same route, URL vachi full-a drive aagudhu.

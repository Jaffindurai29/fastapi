## Code

```python title="main.py"
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class AddRequest(BaseModel):
    a: float
    b: float

@app.post("/add")
def add_numbers(request: AddRequest):
    return {"result": request.a + request.b}
```

## Line by line

1. `class AddRequest(BaseModel): a: float, b: float` — rendu required
   numeric fields. `float` whole numbers-ayum accept pannum (`5`
   `5.0`-a maarum), so separate `int` version venaam.
2. `@app.post("/add")` — oru route, path parameters edhuvum illa.
3. `def add_numbers(request: AddRequest):` — FastAPI JSON body-ah
   `request`-a parse pannum, indha function run aaguradhukku munnadi
   rendu fields-um real numbers-a validate pannikum.
4. `return {"result": request.a + request.b}` — already validate aana
   rendu numbers-la plain Python addition.

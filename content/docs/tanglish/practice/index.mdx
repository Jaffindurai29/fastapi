Idhu oru pudhu concept illa — [First Steps](/tanglish/docs/first-steps)
mattrum [Path Parameters](/tanglish/docs/path-parameters) la neenga
therinjukitta vishayangala vachu dhan aaru quick reps, comfortable-a
irukka.

Indha section-la irukra ovoru page-um oru exercise: full code, line-by-line
walkthrough, mattrum try pannum pothu neenga paakka vendiya actual output.

1. [GET: Dynamic Name](/tanglish/docs/practice/get-dynamic-name) — URL path-la irundhu value padikkurathu.
2. [POST: Dynamic Name](/tanglish/docs/practice/post-dynamic-name) — same kind of value-ah JSON body-la irundhu padikkurathu.
3. [Add Two Numbers](/tanglish/docs/practice/add-two-numbers) — simple math panra POST route.
4. [Calculator](/tanglish/docs/practice/calculator) — `operation` field vachi branch pannurathu, purpose-a bad input handle pannurathu.
5. [Show, Append & Print](/tanglish/docs/practice/show-append-print) — GET mattrum POST vachi oru chinna in-memory list.
6. [Login Authentication](/tanglish/docs/practice/login-authentication) — deliberately simple-a vecha login check-oda shape.

Order-la work pannunga, illana unga ku venum na direct-a edhavadhu onnuku
pogalam.

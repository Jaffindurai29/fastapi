## Backend

```python title="example/5/a/main.py"
@app.get("/items")
def list_items():
    return data


@app.get("/items/{item_index}")
def get_item(item_index: int):
    if item_index < 0 or item_index >= len(data):
        raise HTTPException(status_code=404, detail="Item not found")
    return {"index": item_index, "value": data[item_index]}
```

## Line by line

1. `GET /items` full array-ah adha maadhiri dhan return pannum.
2. `GET /items/{item_index}` oru entry-ah adhoda position vachi reach
   pannum, indexing-ku munnadi bounds check-oda:
   - `item_index < 0` negative numbers-ah block pannum — Python
     lists-ku negative indexing support irukku (`data[-1]` na last
     item), so idha check pannalana `/items/-1` silent-a last item-ah
     return aagum, unknown index maadhiri fail aagadhu.
   - `item_index >= len(data)` array-oda end-ah kadandha edhavadhum
     block pannum.
   - Rendulayum edhavadhu true-na, array-ah index panna munnadi
     `raise HTTPException(status_code=404, detail="Item not found")`
     run aagum.
   - Idha check pannama vittutta, out-of-range index Python-oda own
     `IndexError`-ah raise pannum, adha FastAPI generic `500 Internal
     Server Error`-a maathidum, clean `404`-ku pathila.
3. Inga edhuvum React-ku specific illa — indha topic-ku add aana
   onnu mattum `CORSMiddleware` dhan, `app = FastAPI()` apparam
   odane once register pannirukom, so browser indha routes-ah call
   panna allow pannum.

## Frontend

## Page open aagum pothu load pannurathu

```jsx
useEffect(() => {
  loadItems();
}, []);

async function loadItems() {
  const response = await fetch(`${API_URL}/items`);
  if (!response.ok) {
    setError(`Failed to load items (status ${response.status})`);
    return;
  }
  setItems(await response.json());
  setError(null);
}
```

`useEffect(..., [])` first render aana odane, once dhan run aagum —
idhu dhan starting list-ah load pannudhu. `loadItems` keezha irukra
ovoru create/update/delete-kum apparam-um call aagum, so page eppovum
server-la real-a irukradha dhan reflect pannum.

## Index vachi oru item reach pannurathu

```jsx
async function reachItem(index) {
  const response = await fetch(`${API_URL}/items/${index}`);
  if (!response.ok) {
    setError(`Failed to reach index ${index} (status ${response.status})`);
    setReached(null);
    return;
  }
  setReached(await response.json());
  setError(null);
}
```

`items`-la irundhu separate-a, `reached` state-la store pannirukom —
so idhu clear-a fresh fetch nu therium. Ovoru row-kum irukra
**"Reach"** button-oda wired.

## Line by line

1. `useEffect(() => { loadItems(); }, [])` — empty dependency array
   nu solradhu idhu exact-a oru thadava dhan run aagum, first render
   aana odane, starting list-ah load panna.
2. `loadItems()` `GET /items` call pannum; fail aana `error` set
   pannum, throw pannama — so page crash aagama message kaatum.
3. `loadItems()` keezha irukra ovoru create/update/delete-kum apparam
   thirumba call aagum, so page eppovum server-la real-a irukradha
   dhan reflect pannum.
4. `reachItem(index)` `GET /items/{index}` call pannum, result-ah
   `reached`-nu thani state-la store pannum, `items`-la irundhu
   separate-a — so idhu clear-a fresh fetch nu therium.
5. Ovoru row-kum irukra **"Reach"** button andha row-oda position-oda
   `reachItem(index)`-ah call pannum.

Adutha step: [POST](/tanglish/docs/react/post) — add form.

## Ippo varaikkum code

**Backend** — `example/5/a/main.py`, GET varaikkum:

```python title="example/5/a/main.py"
from fastapi import FastAPI, HTTPException
from fastapi.middleware.cors import CORSMiddleware

app = FastAPI()

app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:5173", "http://127.0.0.1:5173"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)

data = ["first", "second"]


@app.get("/items")
def list_items():
    return data


@app.get("/items/{item_index}")
def get_item(item_index: int):
    if item_index < 0 or item_index >= len(data):
        raise HTTPException(status_code=404, detail="Item not found")
    return {"index": item_index, "value": data[item_index]}
```

**Frontend** — `example/5/react/src/App.jsx`, GET varaikkum:

```jsx title="example/5/react/src/App.jsx"
import { useEffect, useState } from "react";

const API_URL = "http://127.0.0.1:8000";

export default function App() {
  const [items, setItems] = useState([]);
  const [reached, setReached] = useState(null);
  const [error, setError] = useState(null);

  useEffect(() => {
    loadItems();
  }, []);

  async function loadItems() {
    try {
      const response = await fetch(`${API_URL}/items`);
      if (!response.ok) {
        throw new Error(`Failed to load items (status ${response.status})`);
      }
      setItems(await response.json());
      setError(null);
    } catch (err) {
      setError(err.message);
    }
  }

  async function reachItem(index) {
    const response = await fetch(`${API_URL}/items/${index}`);
    if (!response.ok) {
      setError(`Failed to reach index ${index} (status ${response.status})`);
      setReached(null);
      return;
    }
    setReached(await response.json());
    setError(null);
  }

  return (
    <main style={{ maxWidth: 560, margin: "3rem auto", fontFamily: "sans-serif" }}>
      <h1>Array Store</h1>

      {error && <p style={{ color: "crimson" }}>{error}</p>}

      <ul style={{ listStyle: "none", padding: 0, marginTop: "1.5rem" }}>
        {items.map((item, index) => (
          <li
            key={index}
            style={{ display: "flex", alignItems: "center", gap: "0.5rem", padding: "0.25rem 0" }}
          >
            <span style={{ color: "#888", width: "1.5rem" }}>{index}</span>
            <span style={{ flex: 1 }}>{item}</span>
            <button onClick={() => reachItem(index)}>Reach</button>
          </li>
        ))}
      </ul>

      {reached && (
        <p style={{ marginTop: "1rem" }}>
          Reached index <strong>{reached.index}</strong>:{" "}
          <strong>{reached.value}</strong>
        </p>
      )}
    </main>
  );
}
```

Ippozhaikku add/edit/delete UI illa — adhu ovoru adutha page-um adhoda
piece add pannum pothu varum. Adutha page POST add pannum.

## Pudhu item add pannurathu

```jsx
async function addItem(event) {
  event.preventDefault();
  if (value.trim() === "") return;

  const response = await fetch(`${API_URL}/items`, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ value: value }),
  });

  if (!response.ok) {
    setError(`Failed to add item (status ${response.status})`);
    return;
  }

  setValue("");
  await loadItems();
}
```

`event.preventDefault()` form submit aagum pothu browser-oda default
"page reload" behavior-ah stop pannum. `POST` success aana apparam,
input-ah clear pannitu list-ah reload pannum — pudhu item server-oda
response-la irundhu dhan varudhu, guess pannama.

```jsx
<form onSubmit={addItem}>
  <input value={value} onChange={(e) => setValue(e.target.value)} />
  <button type="submit">Add</button>
</form>
```

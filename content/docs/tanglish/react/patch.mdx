## Backend

```python title="example/5/a/main.py"
class ItemPatch(BaseModel):
    value: Optional[str] = None


@app.patch("/items/{item_index}")
def update_item(item_index: int, patch: ItemPatch):
    if item_index < 0 or item_index >= len(data):
        raise HTTPException(status_code=404, detail="Item not found")
    if patch.value is not None:
        data[item_index] = patch.value
    return {"index": item_index, "value": data[item_index]}
```

## Line by line

1. **Index irukka-nu first-a check pannunga** — GET mattrum PUT-la
   irukra same bounds check: `item_index < 0` negative numbers-ah
   reject pannum, `item_index >= len(data)` end-ah kadandha
   edhavadhum reject pannum, rendulayum edhavadhu true-na
   `data[item_index]` touch pannuradhukku munnadi `HTTPException(404)`
   raise aagum.
2. **`ItemPatch`-oda field optional** (`value: Optional[str] = None`)
   — PUT-oda `ItemRequest`-la `value` required, idhu vidhyasam.
   `PUT` vs `PATCH`-oda whole difference idhu dhan: `PUT` full
   representation kekkum, `PATCH` maari irukradha mattum anuppa
   vidum.
3. **`if patch.value is not None:`** client real-a oru value
   anuppina mattum dhan slot-ah overwrite pannum — empty body (`{}`)
   item-ah untouched-a vidum.

## Frontend

## Same function, vera button

Separate-a `savePatch` function edhuvum illa — [`saveEdit`](/tanglish/docs/react/put)
already `method`-ah parameter-a edukkum, so **"Save (PATCH)"** button
adha vera string-oda call pannum mattum dhan:

```jsx
<button onClick={() => saveEdit(index, "PATCH")}>Save (PATCH)</button>
```

Munnadi page-oda PUT button-oda compare pannunga:

```jsx
<button onClick={() => saveEdit(index, "PUT")}>Save (PUT)</button>
```

Same component, same request body, same `axios` call — frontend-la
real difference `"PUT"` vs `"PATCH"` literal string dhan, argument-a
pass pannudhu. Andha oru difference dhan backend-la rendu HTTP
methods-um genuinely exercise pannudhu, oru button-um cosmetic illa nu
kaamikkum.

```jsx
{editingIndex === index && (
  <>
    <button onClick={() => saveEdit(index, "PUT")}>Save (PUT)</button>
    <button onClick={() => saveEdit(index, "PATCH")}>Save (PATCH)</button>
    <button onClick={() => setEditingIndex(null)}>Cancel</button>
  </>
)}
```

## Line by line

1. Separate-a `savePatch` function edhuvum illa — `saveEdit` already
   `method`-ah parameter-a edukkum.
2. **"Save (PATCH)"** button `saveEdit(index, "PATCH")` call pannum
   mattum dhan — same function, same body, vera string.
3. Andha oru string (`"PUT"` vs `"PATCH"`) dhan frontend-la rendu
   buttons-ku vidhyasam — component, request body, `axios` call ellame
   identical.
4. Rendu buttons-um edit mode-la side-by-side irukum, oru
   **"Cancel"** button-oda — adhu save pannama `editingIndex`-ah
   `null`-ku thirumba set pannum.

Adutha step: [DELETE](/tanglish/docs/react/delete) — oru item-ah
remove pannurathu, mattrum full list eppadi render aagum.

## Ippo varaikkum code

**Backend** — `example/5/a/main.py`, PATCH varaikkum:

```python title="example/5/a/main.py"
from typing import Optional

from fastapi import FastAPI, HTTPException, status
from fastapi.middleware.cors import CORSMiddleware
from pydantic import BaseModel

app = FastAPI()

app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:5173", "http://127.0.0.1:5173"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)

data = ["first", "second"]


class ItemRequest(BaseModel):
    value: str


class ItemPatch(BaseModel):
    value: Optional[str] = None


@app.get("/items")
def list_items():
    return data


@app.get("/items/{item_index}")
def get_item(item_index: int):
    if item_index < 0 or item_index >= len(data):
        raise HTTPException(status_code=404, detail="Item not found")
    return {"index": item_index, "value": data[item_index]}


@app.post("/items", status_code=status.HTTP_201_CREATED)
def create_item(item: ItemRequest):
    data.append(item.value)
    return {"index": len(data) - 1, "value": item.value}


@app.put("/items/{item_index}")
def replace_item(item_index: int, item: ItemRequest):
    if item_index < 0 or item_index >= len(data):
        raise HTTPException(status_code=404, detail="Item not found")
    data[item_index] = item.value
    return {"index": item_index, "value": data[item_index]}


@app.patch("/items/{item_index}")
def update_item(item_index: int, patch: ItemPatch):
    if item_index < 0 or item_index >= len(data):
        raise HTTPException(status_code=404, detail="Item not found")
    if patch.value is not None:
        data[item_index] = patch.value
    return {"index": item_index, "value": data[item_index]}
```

**Frontend** — `example/5/react/src/App.jsx`, PATCH varaikkum:

```jsx title="example/5/react/src/App.jsx"
import { useEffect, useState } from "react";
import axios from "axios";

const API_URL = "http://127.0.0.1:8000";

function errorMessage(action, err) {
  const status = err.response?.status;
  return status ? `Failed to ${action} (status ${status})` : `Failed to ${action}: ${err.message}`;
}

export default function App() {
  const [items, setItems] = useState([]);
  const [value, setValue] = useState("");
  const [reached, setReached] = useState(null);
  const [error, setError] = useState(null);

  const [editingIndex, setEditingIndex] = useState(null);
  const [editValue, setEditValue] = useState("");

  useEffect(() => {
    loadItems();
  }, []);

  async function loadItems() {
    try {
      const response = await axios.get(`${API_URL}/items`);
      setItems(response.data);
      setError(null);
    } catch (err) {
      setError(errorMessage("load items", err));
    }
  }

  async function addItem(event) {
    event.preventDefault();
    if (value.trim() === "") return;

    try {
      await axios.post(`${API_URL}/items`, { value: value });
    } catch (err) {
      setError(errorMessage("add item", err));
      return;
    }

    setValue("");
    await loadItems();
  }

  async function reachItem(index) {
    try {
      const response = await axios.get(`${API_URL}/items/${index}`);
      setReached(response.data);
      setError(null);
    } catch (err) {
      setError(errorMessage(`reach index ${index}`, err));
      setReached(null);
    }
  }

  function startEditing(index, currentValue) {
    setEditingIndex(index);
    setEditValue(currentValue);
  }

  async function saveEdit(index, method) {
    try {
      await axios({
        method: method, // "PUT" illana "PATCH"
        url: `${API_URL}/items/${index}`,
        data: { value: editValue },
      });
    } catch (err) {
      setError(errorMessage("update item", err));
      return;
    }

    setEditingIndex(null);
    await loadItems();
  }

  return (
    <main style={{ maxWidth: 560, margin: "3rem auto", fontFamily: "sans-serif" }}>
      <h1>Array Store</h1>

      {error && <p style={{ color: "crimson" }}>{error}</p>}

      <form onSubmit={addItem} style={{ display: "flex", gap: "0.5rem" }}>
        <input
          value={value}
          onChange={(event) => setValue(event.target.value)}
          placeholder="Add a value"
          style={{ flex: 1, padding: "0.5rem" }}
        />
        <button type="submit">Add</button>
      </form>

      <ul style={{ listStyle: "none", padding: 0, marginTop: "1.5rem" }}>
        {items.map((item, index) =>
          editingIndex === index ? (
            <li
              key={index}
              style={{ display: "flex", alignItems: "center", gap: "0.5rem", padding: "0.25rem 0" }}
            >
              <span style={{ color: "#888", width: "1.5rem" }}>{index}</span>
              <input
                value={editValue}
                onChange={(event) => setEditValue(event.target.value)}
                style={{ flex: 1, padding: "0.25rem" }}
              />
              <button onClick={() => saveEdit(index, "PUT")}>Save (PUT)</button>
              <button onClick={() => saveEdit(index, "PATCH")}>Save (PATCH)</button>
              <button onClick={() => setEditingIndex(null)}>Cancel</button>
            </li>
          ) : (
            <li
              key={index}
              style={{ display: "flex", alignItems: "center", gap: "0.5rem", padding: "0.25rem 0" }}
            >
              <span style={{ color: "#888", width: "1.5rem" }}>{index}</span>
              <span style={{ flex: 1 }}>{item}</span>
              <button onClick={() => reachItem(index)}>Reach</button>
              <button onClick={() => startEditing(index, item)}>Edit</button>
            </li>
          ),
        )}
      </ul>

      {reached && (
        <p style={{ marginTop: "1rem" }}>
          Reached index <strong>{reached.index}</strong>:{" "}
          <strong>{reached.value}</strong>
        </p>
      )}
    </main>
  );
}
```

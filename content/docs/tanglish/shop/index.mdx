[Relationships](/tanglish/docs/relationships) mattrum
[Security](/tanglish/docs/security) ovoru page-layum oru idea mattum
kaththukuduthuchu. Indha topic, adhu ellathaiyum orey nerathula use
panra oru real app build pannum: oru chinna online shop. Customers
products paappanga, cart fill pannuvanga, order place pannuvanga.
Admins products, stock, orders, users ellathaiyum manage pannuvanga.
Ovoru rule-um API dhan enforce pannum; React frontend ovoru role-kum
avangaluku allowed-aana pages-ah mattum kaattum.

## Yaaru enna pannalam

| | Customer | Admin |
|---|:-:|:-:|
| Products paakradhu | ✅ | ✅ (hidden products-um theriyum) |
| Order place panradhu, **sontha** orders paakradhu, cancel panradhu | ✅ | — |
| Products add / edit / hide panradhu, stock maathradhu | — | ✅ |
| **Ella** orders-um paakradhu, order status maathradhu | — | ✅ |
| Users list, roles maathradhu | — | ✅ |

Sign up panra ellarum eppovum customer dhan. Mudhal admin seed data-la
irundhu illana oru chinna `create_admin.py` script-la irundhu varum —
API-la irundhu eppovum illa.

## Ovoru idea-um, adhu enga irundhu vandhuchu

| Idea | Kaththukitta page | Inga edhukku use aagudhu |
|---|---|---|
| Password hashing (Argon2) | [Password hashing](/tanglish/docs/security/password-hashing) | Passwords |
| JWT access + refresh tokens | [JWT login](/tanglish/docs/security/jwt-login), [Refresh tokens](/tanglish/docs/security/refresh-tokens) | Login-la irukradhu |
| Roles, `401` vs `403` | [Authorization by role](/tanglish/docs/security/roles) | Customer vs admin routes |
| Ownership | [Authorization by ownership](/tanglish/docs/security/ownership) | "Unga sontha orders mattum" |
| Encryption (Fernet) | [Encrypt/decrypt fields](/tanglish/docs/security/encryption) | Order-la irukra phone, address |
| Public ids (Sqids) | [ID hashing](/tanglish/docs/security/id-hashing) | `/orders/1`-ku badhila `/orders/Xb3kLq9P` |
| One-to-many, nested responses | [One-to-many](/tanglish/docs/relationships/one-to-many), [Nested responses](/tanglish/docs/relationships/nested-responses) | Orders mattrum avanga items |
| Transactions | [Transactions](/tanglish/docs/relationships/transactions) | Order full-a save aagum, illana edhuvume aagaadhu |
| Soft delete | [Soft delete](/tanglish/docs/relationships/soft-delete) | Hidden products; pazhaya orders innum work aagum |
| Axios interceptors | [React login UI](/tanglish/docs/security/react) | Token automatic-a refresh aagum |

Indha topic-la pudhusu: **row locks** (`SELECT ... FOR UPDATE`) — rendu
customers kadaisi item-ah orey nerathula vaanga mudiyaadhu. Apparam
React Router vechu React-la **role-protected routes**.

## Setup

```bash
pip install fastapi "uvicorn[standard]" sqlalchemy pymysql python-dotenv "pwdlib[argon2]" pyjwt cryptography sqids
```

Database [MySQL + CRUD-la irukra maadhiri same](/tanglish/docs/mysql-crud#setup):
`fastapi_learn` database, `MYSQL_*` env vars illana oru `.env`, illana
SQLite-ku `DATABASE_URL`. Shop-ku sontha `minishop_*` tables irukku, so
vera topics-oda data-va touch pannaadhu. `.env.example`-la irukra ovoru
secret-kum oru development default irukku, so zero setup-la run aagum.

## Indha topic-ah eppadi run pannurathu

1. **Backend:**

   ```bash
   cd example/14/a
   uvicorn main:app --reload
   ```

   Mudhal run tables-ah create panni seed pannum:

   | Username | Password | Role |
   |---|---|---|
   | `admin` | `admin-password` | admin |
   | `alice` | `alice-password` | customer |
   | `bob` | `bob-password` | customer |

   ...kooda naalu products. "Sticker pack"-oda stock **1** dhan, so
   adhukku rendaavadhu order fail aagradha neenga paakalam.

2. **Unga sontha admin (optional):**

   ```bash
   python create_admin.py carol
   ```

   `carol` irundha promote pannum; illana password kettu admin-a create
   pannum. Seed data illadha real shop-la, mudhal admin ippadi dhan
   varuvaanga.

3. **Frontend**, rendaavadhu terminal-la:

   ```bash
   cd example/14/react
   npm install
   npm run dev
   ```

   [http://localhost:5173](http://localhost:5173) open pannunga.

## Ella routes-um

| Route | Yaaru | Description |
|---|---|---|
| `POST /register` | yaar venumnaalum | `201`, eppovum role `customer`. Already irundha `409` |
| `POST /login` | yaar venumnaalum | `access_token` + `refresh_token` tharum. Illana `401` |
| `POST /refresh` | yaar venumnaalum | Pudhu access token tharum |
| `GET /me` | login aanavanga | Unga public id, username, role |
| `GET /products` | login aanavanga | Customers: visible products. Admins: ellame |
| `GET /products/{id}` | login aanavanga | Hidden product (customers-ku) illana theriyaadha id-na `404` |
| `POST /products` | admin | Product create. `201` |
| `PATCH /products/{id}` | admin | `name`, `description`, `price`, `is_active` maathalam |
| `PATCH /products/{id}/stock` | admin | `{"change": 10}` illana `{"change": -3}`. 0-ku keezha pona `400` |
| `DELETE /products/{id}` | admin | Product-ah hide pannum. `204` |
| `POST /orders` | customer | Order place. `201`, illana `409` "Only 1 of ... left" |
| `GET /orders/mine` | login aanavanga | Unga orders, pudhusu mudhal-la |
| `GET /orders/{id}` | login aanavanga | Unga order illana `404` (admins ellathaiyum paakalam) |
| `POST /orders/{id}/cancel` | login aanavanga | `pending`-la irukra varaikkum mattum. Stock thirumbi varum |
| `GET /orders` | admin | Ella orders, phone mattrum address decrypt aagi |
| `PATCH /orders/{id}/status` | admin | `pending → shipped → delivered`, illana `pending → cancelled` |
| `GET /users` | admin | Ella users |
| `PATCH /users/{id}/role` | admin | Role maathum. Unga sontha account-na `400` |

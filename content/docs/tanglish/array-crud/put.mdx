## Code

```python title="main.py"
from fastapi import FastAPI, HTTPException

app = FastAPI()

data = ["first", "second"]

@app.put("/items/{item_index}")
def replace_item(item_index: int, value: str):
    if item_index < 0 or item_index >= len(data):
        raise HTTPException(status_code=404, detail="Item not found")
    data[item_index] = value
    return {"index": item_index, "value": data[item_index]}
```

## Line by line

1. **Index irukka nu first check pannunga** — [GET](/tanglish/docs/array-crud/get)-la
   irukra same bounds check dhan:
   - `item_index < 0` negative numbers-ah block pannum, so `/items/-1`
     na Python-oda negative-indexing behaviour vachi silent-a last
     item-ah overwrite pannadhu.
   - `item_index >= len(data)` end-ah kadandha index-ah block pannum.
   - Rendulayum edhavadhu true-na, `data[item_index]` run aaguradhukku
     munnadi `HTTPException(404)` raise aagum — so out-of-range `PUT`
     clean `404 Not Found` return pannum, `IndexError` vandhu `500`-a
     maaradhu.
2. **`data[item_index] = value`** — andha slot-ah full-a
   overwrite pannudhu. `PUT` nu solradhu "idhu dhan indha resource-oda
   complete pudhu representation" — client full value-ah anuppanum,
   maari irukra part mattum illa. `value` inga query parameter dhan
   ([POST](/tanglish/docs/array-crud/post) style-la), JSON body illa.

## Try it

```bash
curl -X PUT "http://127.0.0.1:8000/items/0?value=replaced"
curl -i -X PUT "http://127.0.0.1:8000/items/9?value=x"  # 404
```

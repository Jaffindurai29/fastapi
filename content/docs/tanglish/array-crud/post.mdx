## Code

```python title="main.py"
from fastapi import FastAPI

app = FastAPI()

data = ["first", "second"]

@app.post("/items")
def create_item(value: str):
    data.append(value)
    return {"index": len(data) - 1, "value": value}
```

## Line by line

1. `def create_item(value: str)` — `value` Pydantic model-um illa,
   path parameter-um illa nu, FastAPI adha query parameter-ah
   treat pannum — URL-la irundhu (`?value=third`) read pannum,
   JSON body-la illa.
2. `data.append(value)` — shared array-oda end-la pudhu value
   add pannudhu.
3. `return {"index": len(data) - 1, "value": value}` — pudhu item
   engaya landed aachu nu caller-kku exact-a solradhu, so apparam
   [GET](/tanglish/docs/array-crud/get), [PUT](/tanglish/docs/array-crud/put),
   illana [DELETE](/tanglish/docs/array-crud/delete) panna, edhu index nu
   therium.

## Try it

```bash
curl -i -X POST "http://127.0.0.1:8000/items?value=third"
```

Expected: `200 OK`, `{"index": 2, "value": "third"}`.

Adutha step: [PUT](/tanglish/docs/array-crud/put) — oru item-ah full-a
replace pannurathu.

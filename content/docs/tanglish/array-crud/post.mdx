## Code

```python title="main.py"
from fastapi import FastAPI, status
from pydantic import BaseModel

app = FastAPI()

data = ["first", "second"]

class ItemRequest(BaseModel):
    value: str

@app.post("/items", status_code=status.HTTP_201_CREATED)
def create_item(item: ItemRequest):
    data.append(item.value)
    return {"index": len(data) - 1, "value": item.value}
```

## Line by line

1. Decorator-la `status_code=status.HTTP_201_CREATED` — `POST` routes
   default-a `200`; "pudhu resource create aachu" nu solla `201` dhan
   correct code.
2. `data.append(item.value)` — shared array-oda end-la pudhu value
   add pannudhu.
3. `return {"index": len(data) - 1, "value": item.value}` — pudhu item
   engaya landed aachu nu caller-kku exact-a solradhu, so apparam
   [GET](/tanglish/docs/array-crud/get), [PUT](/tanglish/docs/array-crud/put),
   illana [DELETE](/tanglish/docs/array-crud/delete) panna, edhu index nu
   therium.

## Try it

```bash
curl -i -X POST http://127.0.0.1:8000/items -H "Content-Type: application/json" -d "{\"value\": \"third\"}"
```

Expected: `201 Created`, `{"index": 2, "value": "third"}`.

Adutha step: [PUT](/tanglish/docs/array-crud/put) — oru item-ah full-a
replace pannurathu.

description: Partially update panna oru item — field optional.

## Code

```python title="main.py"
from typing import Optional
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

data = ["first", "second"]

class ItemPatch(BaseModel):
    value: Optional[str] = None

@app.patch("/items/{item_index}")
def update_item(item_index: int, patch: ItemPatch):
    if item_index < 0 or item_index >= len(data):
        raise HTTPException(status_code=404, detail="Item not found")
    if patch.value is not None:
        data[item_index] = patch.value
    return {"index": item_index, "value": data[item_index]}
```

## Line by line

1. **Index irukka nu first check pannunga** — [GET](/tanglish/docs/array-crud/get)
   mattrum [PUT](/tanglish/docs/array-crud/put)-la irukra same bounds
   check: `item_index < 0` negative numbers-ah reject pannum,
   `item_index >= len(data)` end-ah kadandha edhavadhum reject pannum,
   rendulayum edhavadhu true-na `data[item_index]` touch pannuradhukku
   munnadi `HTTPException(404)` raise aagum.
2. **`ItemPatch`-oda field optional** (`value: Optional[str] = None`)
   — [PUT](/tanglish/docs/array-crud/put)-oda `ItemRequest`-la `value`
   required-a irukum, idhu vidhyasam. `PUT` mattrum `PATCH`-kum idhu
   dhan entire difference: `PUT` full representation kekkum, `PATCH`
   maari irukradha mattum anuppa vidum.
3. **`if patch.value is not None:`** — client real-a oru value
   anuppina mattum dhan slot-ah overwrite pannum. Empty body (`{}`)
   item-ah touch pannadhu.

Oru field mattum irukra indha item-ku, `PUT` mattrum `PATCH` almost
same maadhiri dhan work pannum — real difference, resource-la palli
fields irundhu, ovonna mattum change panna vendumna dhan therium.

## Try it

```bash
curl -X PATCH http://127.0.0.1:8000/items/1 -H "Content-Type: application/json" -d "{\"value\": \"patched\"}"
curl -X PATCH http://127.0.0.1:8000/items/0 -H "Content-Type: application/json" -d "{}"
curl -i -X PATCH http://127.0.0.1:8000/items/9 -H "Content-Type: application/json" -d "{}"  # 404
```

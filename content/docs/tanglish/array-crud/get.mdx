## Code

```python title="main.py"
from fastapi import FastAPI, HTTPException

app = FastAPI()

# Rendu items-oda seed pannirukom, so idhu standalone-a testable,
# POST edhuvum munnadi venaam.
data = ["first", "second"]

@app.get("/items")
def list_items():
    return data

@app.get("/items/{item_index}")
def get_item(item_index: int):
    if item_index < 0 or item_index >= len(data):
        raise HTTPException(status_code=404, detail="Item not found")
    return {"index": item_index, "value": data[item_index]}
```

## Line by line

1. `data = ["first", "second"]` — module level-la seed pannirukom,
   edhavadhu route function-ku velila, so ovoru request-um same
   array-ah dhan padikkum.
2. `GET /items` adha maadhiri return pannum — ellame kaamikkum.
3. `GET /items/{item_index}` position vachi oru entry-ah reach pannum,
   index panna munnadi oru bounds check irukku:
   - `item_index < 0` — negative numbers-ah block pannum. Python
     lists-ku negative indexing support irukku (`data[-1]` na last
     item), so idha check pannalana `/items/-1` na silent-ah
     `"second"` return aagum, unknown index maadhiri fail aagadhu.
   - `item_index >= len(data)` — end-ah kadandhu poi enna irundhalum
     block pannum. `data`-la 2 items irukku, `0` mattrum `1` index-la,
     so `len(data)` `2`, adhanaala index `2` already out of range.
   - Rendulayum edhavadhu true-na, `raise HTTPException(status_code=404, ...)`
     function-ah odane stop panni, FastAPI idha HTTP `404 Not Found`
     response-a maathidum, body-la `{"detail": "Item not found"}`
     varum.
   - Idha check pannama vittutta, out-of-range index Python-oda
     sontha `IndexError`-ah raise pannum, adha FastAPI generic
     `500 Internal Server Error`-a maathidum — logic-la correct dhan,
     aana wrong status code, client-ku use aagura message-um illa.

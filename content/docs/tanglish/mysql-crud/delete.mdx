## Code

**`database.py`** — env vars, `engine`/`SessionLocal`/`Base`, mattrum
`get_db()` dependency:

```python title="database.py"
import os

from dotenv import load_dotenv
from sqlalchemy import create_engine
from sqlalchemy.orm import Session, declarative_base, sessionmaker

load_dotenv()

MYSQL_HOST = os.getenv("MYSQL_HOST", "127.0.0.1")
MYSQL_PORT = os.getenv("MYSQL_PORT", "3306")
MYSQL_USER = os.getenv("MYSQL_USER", "root")
MYSQL_PASSWORD = os.getenv("MYSQL_PASSWORD", "")
MYSQL_DB = os.getenv("MYSQL_DB", "fastapi_learn")

# Set DATABASE_URL directly to override everything above (e.g. to point
# at SQLite for a quick local test with no MySQL server at all).
DATABASE_URL = os.getenv(
    "DATABASE_URL",
    f"mysql+pymysql://{MYSQL_USER}:{MYSQL_PASSWORD}@{MYSQL_HOST}:{MYSQL_PORT}/{MYSQL_DB}",
)

engine = create_engine(DATABASE_URL, pool_pre_ping=True)
SessionLocal = sessionmaker(autocommit=False, autoflush=False, bind=engine)
Base = declarative_base()


def get_db():
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()
```

**`models.py`** — `ItemModel` table:

```python title="models.py"
from sqlalchemy import Column, Integer, String

from database import Base


class ItemModel(Base):
    __tablename__ = "items"

    id = Column(Integer, primary_key=True, autoincrement=True)
    value = Column(String(255), nullable=False)
```

Inga `schemas.py` illa — `DELETE`-ku request body edhuvum venaam.

**`crud.py`** — database-oda pesura plain functions, HTTP edhuvum
theriyaadhu:

```python title="crud.py"
from sqlalchemy.orm import Session

from models import ItemModel


def get_item(db: Session, item_id: int) -> ItemModel | None:
    return db.get(ItemModel, item_id)


def delete_item(db: Session, item_id: int) -> bool:
    row = get_item(db, item_id)
    if row is None:
        return False
    db.delete(row)
    db.commit()
    return True


def seed_items(db: Session) -> None:
    if db.query(ItemModel).count() == 0:
        db.add_all([ItemModel(value="first"), ItemModel(value="second")])
        db.commit()
```

**`main.py`** — `FastAPI()` app mattrum route:

```python title="main.py"
from fastapi import Depends, FastAPI, HTTPException, status
from sqlalchemy.orm import Session

import crud
from database import Base, SessionLocal, engine, get_db

Base.metadata.create_all(bind=engine)

with SessionLocal() as db:
    crud.seed_items(db)

app = FastAPI()


@app.delete("/items/{item_id}", status_code=status.HTTP_204_NO_CONTENT)
def delete_item(item_id: int, db: Session = Depends(get_db)):
    deleted = crud.delete_item(db, item_id)
    if not deleted:
        raise HTTPException(status_code=404, detail="Item not found")
```

## Line by line

`database.py`-oda connection/session setup mattrum `models.py`-oda
`ItemModel` table — indha topic-la irukra ella page-um share panra
same pieces dhan, ippo ella verb-kum same `items` table (five thani
tables illa) — adha line-by-line explain panradha
[index page](/tanglish/docs/mysql-crud)-la paarunga. Keezha, indha
page-ku specific-a `crud.py` mattrum `main.py`-la enna irukko adha
mattum paarpom.

**`crud.py`:**

1. `get_item(db, item_id)` — `db.get(ItemModel, item_id)`, indha
   topic-oda ella verb-um use panra same primary-key fetch shortcut:
   andha ID irundha `ItemModel` object return pannum, illa-na `None`
   return pannum, rendu case-layum exception edhuvum raise pannama.
2. `delete_item(db, item_id)`:
   - **`get_item` vachi row-ah first-a look up pannum**. Indha topic
     vera ella verb-oda `crud.py` function mathiri illama, delete
     aana appuram thirumba kudukka oru `row` irukkathu, so miss-ah
     `None`-ku pathila `False` return panni report pannum.
   - **`db.delete(row)` apparam `db.commit()`** — deletion-ah stage
     pannum, apparam write pannum. `POST` route-la `db.add()` mathiri,
     `db.delete()` mattum stage pannudhu; `db.commit()` run aaguradhukku
     munnadi MySQL-la row-ku edhuvum real-a nadakala.
   - Row real-a poi appuram `True` return pannum — `crud.py` innum
     edhuvum raise pannadhu, HTTP status codes gurichi theriyadhu.

**`main.py`:**

3. `db: Session = Depends(get_db)` — indha topic-oda vera ella route
   mathiri same `get_db()` dependency: FastAPI route run aaguradhukku
   munnadi pudhu session-ah kudukkum, apparam automatic-a close
   pannum.
4. `delete_item(item_id, db)` — `crud.delete_item(db, item_id)`-ah
   call pannudhu, `if row is None:`-ku pathila `if not deleted:`
   check pannum, inga check panna `row` edhuvum illainala —
   `crud.delete_item`-oda `False` dhan miss aagirundha andha ore
   signal.
   - `raise HTTPException(status_code=404, ...)` andha miss
     nadakumbodhu clean `404`-ah anuppum.
   - Idha check-ah mudhal-la vittutta, missing ID-ku edhavadhu
     delete aana madhiri silent-a `204 No Content` return aagum,
     `crud.delete_item` already andha miss-ah internal-a handle
     pannirundhu, edhuvum raise pannaama — `main.py`-la irukra check
     dhan andha quiet `False`-ah real `404` response-a maathum.
5. **Array topic-ku vidhyasam-a**, inga oru row-ah delete panna, vera
   edhavadhu row-oda `id` shift aagadhu — MySQL-oda auto-increment `id`
   oru stable identity dhan, list-la position illa. Deletions-ah
   predictable-a survive panna, in-memory array-ku vida database-oda
   real advantage idhu dhan.

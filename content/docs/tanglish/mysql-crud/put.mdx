## Code

```python title="main.py"
from fastapi import Depends, FastAPI, HTTPException
from pydantic import BaseModel
from sqlalchemy.orm import Session

app = FastAPI()

class ItemRequest(BaseModel):
    value: str

@app.put("/items/{item_id}")
def replace_item(item_id: int, item: ItemRequest, db: Session = Depends(get_db)):
    row = db.get(ItemModel, item_id)
    if row is None:
        raise HTTPException(status_code=404, detail="Item not found")
    row.value = item.value
    db.commit()
    db.refresh(row)
    return {"id": row.id, "value": row.value}
```

## Line by line

1. **Row-ah first-a look up pannunga** — `db.get(ItemModel, item_id)`
   SQLAlchemy-oda primary-key-vachi fetch shortcut: andha ID irundha
   `ItemModel` object return pannum, illa-na `None` return pannum,
   rendu case-layum exception edhuvum raise pannama.
   - `if row is None: raise HTTPException(status_code=404, ...)` andha
     `None`-ah edhavadhu vera onnum run aaguradhukku munnadi clean
     `404 Not Found`-a maathum.
   - Idha check pannama `row.value = item.value`-ku neraa poirundha,
     `row` `None`-a irundhaal Python `AttributeError: 'NoneType'
     object has no attribute 'value'`-ah raise pannum — adha FastAPI
     generic `500 Internal Server Error`-a maathidum, missing ID-ku
     venum `404`-ku pathila.
2. **`row.value = item.value`** — plain attribute assignment mathiri
   kaamikkum, idhu dhan adhu. SQLAlchemy-oda ORM change-ah automatic-a
   track pannikum; session-ku thirumba edhuvum add pannanum illa.
3. **`db.commit()`** change-ah write pannum; **`db.refresh(row)`**
   `row` database-la ippo enna irukko adha exact-a reflect pannum-nu
   confirm pannum, return pannuradhukku munnadi.

## Try it

```bash
curl -X PUT http://127.0.0.1:8000/items/1 -H "Content-Type: application/json" -d "{\"value\": \"replaced\"}"
curl -i -X PUT http://127.0.0.1:8000/items/999 -H "Content-Type: application/json" -d "{\"value\": \"x\"}"  # 404
```

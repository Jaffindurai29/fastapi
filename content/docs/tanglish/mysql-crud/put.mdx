## Code

**`database.py`** — env vars, `engine`/`SessionLocal`/`Base`, mattrum
`get_db()` dependency:

```python title="database.py"
import os

from dotenv import load_dotenv
from sqlalchemy import create_engine
from sqlalchemy.orm import Session, declarative_base, sessionmaker

load_dotenv()

MYSQL_HOST = os.getenv("MYSQL_HOST", "127.0.0.1")
MYSQL_PORT = os.getenv("MYSQL_PORT", "3306")
MYSQL_USER = os.getenv("MYSQL_USER", "root")
MYSQL_PASSWORD = os.getenv("MYSQL_PASSWORD", "")
MYSQL_DB = os.getenv("MYSQL_DB", "fastapi_learn")

# Set DATABASE_URL directly to override everything above (e.g. to point
# at SQLite for a quick local test with no MySQL server at all).
DATABASE_URL = os.getenv(
    "DATABASE_URL",
    f"mysql+pymysql://{MYSQL_USER}:{MYSQL_PASSWORD}@{MYSQL_HOST}:{MYSQL_PORT}/{MYSQL_DB}",
)

engine = create_engine(DATABASE_URL, pool_pre_ping=True)
SessionLocal = sessionmaker(autocommit=False, autoflush=False, bind=engine)
Base = declarative_base()


def get_db():
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()
```

**`models.py`** — `ItemModel` table:

```python title="models.py"
from sqlalchemy import Column, Integer, String

from database import Base


class ItemModel(Base):
    __tablename__ = "items"

    id = Column(Integer, primary_key=True, autoincrement=True)
    value = Column(String(255), nullable=False)
```

**`schemas.py`** — [POST](/tanglish/docs/mysql-crud/post) use panra
same request body:

```python title="schemas.py"
from pydantic import BaseModel


class ItemRequest(BaseModel):
    value: str
```

**`crud.py`** — database-oda pesura plain functions, HTTP edhuvum
theriyaadhu:

```python title="crud.py"
from sqlalchemy.orm import Session

from models import ItemModel
from schemas import ItemRequest


def get_item(db: Session, item_id: int) -> ItemModel | None:
    return db.get(ItemModel, item_id)


def replace_item(db: Session, item_id: int, item: ItemRequest) -> ItemModel | None:
    row = get_item(db, item_id)
    if row is None:
        return None
    row.value = item.value
    db.commit()
    db.refresh(row)
    return row


def seed_items(db: Session) -> None:
    if db.query(ItemModel).count() == 0:
        db.add_all([ItemModel(value="first"), ItemModel(value="second")])
        db.commit()
```

**`main.py`** — `FastAPI()` app mattrum route:

```python title="main.py"
from fastapi import Depends, FastAPI, HTTPException
from sqlalchemy.orm import Session

import crud
from database import Base, SessionLocal, engine, get_db
from schemas import ItemRequest

Base.metadata.create_all(bind=engine)

with SessionLocal() as db:
    crud.seed_items(db)

app = FastAPI()


@app.put("/items/{item_id}")
def replace_item(item_id: int, item: ItemRequest, db: Session = Depends(get_db)):
    row = crud.replace_item(db, item_id, item)
    if row is None:
        raise HTTPException(status_code=404, detail="Item not found")
    return {"id": row.id, "value": row.value}
```

## Line by line

`database.py`-oda connection/session setup mattrum `models.py`-oda
`ItemModel` table — indha topic-la irukra ella page-um share panra
same pieces dhan, ippo ella verb-kum same `items` table (five thani
tables illa) — adha line-by-line explain panradha
[index page](/tanglish/docs/mysql-crud)-la paarunga. `schemas.py`-oda
`ItemRequest`, [POST](/tanglish/docs/mysql-crud/post) use panradhu
dhan. Keezha, indha page-ku specific-a `crud.py` mattrum `main.py`-la
enna irukko adha mattum paarpom.

**`crud.py`:**

1. `get_item(db, item_id)` — `db.get(ItemModel, item_id)`
   SQLAlchemy-oda primary-key-vachi fetch shortcut: andha ID irundha
   `ItemModel` object return pannum, illa-na `None` return pannum,
   rendu case-layum exception edhuvum raise pannama.
2. `replace_item(db, item_id, item)`:
   - **`get_item` vachi row-ah first-a look up pannum**, adhu `None`
     return pannina, `replace_item`-um andha `None`-ah adha madhiri
     thirumba kudukkum, edhuvum raise pannama — `crud.py`-ku HTTP
     status codes gurichi onnume theriyaadhu; miss-ah real error-a
     maathradhu adha call panravanukku left.
   - `row.value = item.value` plain attribute assignment mathiri
     kaamikkum, idhu dhan adhu — aana `row`, indha same session-la
     munnadi `get_item`-la irundhu vandhadhu-nala, SQLAlchemy-oda
     "unit of work" andha object-ah already track pannikittu irukku,
     so change-ah automatic-a pick up pannikum. Session-ku thirumba
     edhuvum add pannanum illa (`db.add(row)` inga venaam) —
     [POST](/tanglish/docs/mysql-crud/post)-la irundhu real vidhyasam
     idhu dhan, POST-la `row` pudhu object, session-ku andha object
     gurichi theriyaadhu.
   - `db.commit()` dhan andha tracked in-memory change-ah real
     `UPDATE ... SET value = ... WHERE id = ...` statement-a maathi
     MySQL-ku anuppum — indha line run aaguradhukku munnadi database-ku
     edhuvum pogadhu.
   - `db.refresh(row)` apparam database-la irundhu `row`-ah thirumba
     query pannudhu, so indha function return panra object MySQL-la
     ippo enna irukko adha exact-a reflect pannum — client anuppina
     input-ah mattum echo pannradhukku pathila.

**`main.py`:**

3. `db: Session = Depends(get_db)` — [GET](/tanglish/docs/mysql-crud/get)-la
   paartha same dependency injection dhan: FastAPI `get_db()` vachi
   pudhu session-ah indha route run aaguradhukku munnadi open pannum,
   apparam automatic-a close pannum, route success-a irundhalum
   raise pannalum.
4. `replace_item(item_id, item, db)` — `crud.replace_item(db,
   item_id, item)`-ah call pannudhu, miss-ah real HTTP response-a
   maathura ore idam idhu dhan:
   - `if row is None: raise HTTPException(status_code=404, ...)`
     `crud.replace_item`-oda `None`-ah edhavadhu vera onnum run
     aaguradhukku munnadi clean `404 Not Found`-a maathum.
   - Idha check pannama `{"id": row.id, "value": row.value}`-ku
     neraa poirundha, `row` `None`-a irundhaal Python `AttributeError:
     'NoneType' object has no attribute 'id'`-ah raise pannum — adha
     FastAPI generic `500 Internal Server Error`-a maathidum, missing
     ID-ku venum `404`-ku pathila. Indha check-ah `crud.py`-la illama
     `main.py`-la vachurukradhu dhan, `crud.replace_item`-ah indha oru
     HTTP route-ku mattum illama, engayum reuse panna help pannum.

## Try it

```bash
curl -X PUT http://127.0.0.1:8000/items/1 -H "Content-Type: application/json" -d "{\"value\": \"replaced\"}"

```

## Code

```python title="main.py"
import os
from typing import Optional

from fastapi import Depends, FastAPI, HTTPException
from pydantic import BaseModel
from sqlalchemy import Column, Integer, String, create_engine
from sqlalchemy.orm import Session, declarative_base, sessionmaker

MYSQL_HOST = os.getenv("MYSQL_HOST", "127.0.0.1")
MYSQL_PORT = os.getenv("MYSQL_PORT", "3306")
MYSQL_USER = os.getenv("MYSQL_USER", "root")
MYSQL_PASSWORD = os.getenv("MYSQL_PASSWORD", "")
MYSQL_DB = os.getenv("MYSQL_DB", "fastapi_learn")

DATABASE_URL = os.getenv(
    "DATABASE_URL",
    f"mysql+pymysql://{MYSQL_USER}:{MYSQL_PASSWORD}@{MYSQL_HOST}:{MYSQL_PORT}/{MYSQL_DB}",
)

engine = create_engine(DATABASE_URL, pool_pre_ping=True)
SessionLocal = sessionmaker(autocommit=False, autoflush=False, bind=engine)
Base = declarative_base()


class ItemModel(Base):
    __tablename__ = "crud_patch_items"
    id = Column(Integer, primary_key=True, autoincrement=True)
    value = Column(String(255), nullable=False)


Base.metadata.create_all(bind=engine)

with SessionLocal() as db:
    if db.query(ItemModel).count() == 0:
        db.add_all([ItemModel(value="first"), ItemModel(value="second")])
        db.commit()

app = FastAPI()


def get_db():
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()


class ItemPatch(BaseModel):
    value: Optional[str] = None


@app.patch("/items/{item_id}")
def update_item(item_id: int, patch: ItemPatch, db: Session = Depends(get_db)):
    row = db.get(ItemModel, item_id)
    if row is None:
        raise HTTPException(status_code=404, detail="Item not found")
    if patch.value is not None:
        row.value = patch.value
    db.commit()
    db.refresh(row)
    return {"id": row.id, "value": row.value}
```

## Line by line

Mela irukra `MYSQL_*`/`DATABASE_URL` setup, `engine`/`SessionLocal`/`Base`,
`ItemModel` table, `Base.metadata.create_all(...)`, mattrum seed block —
indha topic-la irukra ella page-um share panra same pieces dhan — adha
line-by-line explain panradha [index page](/tanglish/docs/mysql-crud)-la
paarunga. Keezha, indha page-ku specific-a enna irukko adha mattum
paarpom.

1. `db: Session = Depends(get_db)` — indha topic-oda vera ella route
   mathiri same session-per-request pattern: FastAPI adha `get_db()`
   vachi function run aaguradhukku munnadi kudukkum, function mudinja
   appuram automatic-a close pannum, error vandhalum sari.
2. **Row-ah first-a check pannunga** — `db.get(ItemModel, item_id)`
   andha ID irundha `ItemModel` object return pannum, illa-na `None`
   return pannum.
   - `if row is None: raise HTTPException(status_code=404, ...)`
     function `row`-ah touch panna munnadi clean `404`-ah anuppum.
   - Idha check pannama vittutta, keezha irukra
     `row.value = patch.value` line missing ID-ku `AttributeError:
     'NoneType' object has no attribute 'value'`-ah raise pannum —
     FastAPI adha proper `404`-ku pathila generic `500 Internal Server
     Error`-a maathidum.
3. **`ItemPatch.value` optional** — [PUT](/tanglish/docs/mysql-crud/put)-oda
   `ItemRequest`-la `value` required, idhu vidhyasam. Array topic-oda
   PATCH-la paartha same distinction: `PUT` full representation
   kekkum, `PATCH` maari irukradha mattum anuppa vidum.
4. **`if patch.value is not None: row.value = patch.value`** — client
   real-a oru value anuppina mattum dhan row-ah update pannum.
   [PUT](/tanglish/docs/mysql-crud/put)-la mathiri, andha assignment
   mattum podhum SQLAlchemy notice pannradhukku: `row` indha same
   session-la munnadi `db.get(...)`-la irundhu vandhadhu, so adhoda
   "unit of work" already track pannikittu irukku — change-ah register
   panna `db.add(row)` venaam.
5. **`db.commit()`** — edhavadhu tracked change-ah `UPDATE`
   statement-a flush pannum, transaction-ah commit pannum. Client
   `{}` anuppi, `patch.value` `None`-a irundha, edhuvum assign
   aagalaye, so indha commit-ku pudhusa edhuvum write panna illa —
   harmless no-op.
6. **`db.refresh(row)`** — apparam database-la irundhu `row`-ah
   thirumba query pannudhu, so return pannura `{"id": row.id, "value":
   row.value}` MySQL-la ippo enna irukko adha exact-a reflect pannum,
   indha request edhavadhu maathi irundhalum illainalum.

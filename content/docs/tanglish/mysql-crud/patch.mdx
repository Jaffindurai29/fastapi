## Code

**`database.py`** — env vars, `engine`/`SessionLocal`/`Base`, mattrum
`get_db()` dependency:

```python title="database.py"
import os

from dotenv import load_dotenv
from sqlalchemy import create_engine
from sqlalchemy.orm import Session, declarative_base, sessionmaker

load_dotenv()

MYSQL_HOST = os.getenv("MYSQL_HOST", "127.0.0.1")
MYSQL_PORT = os.getenv("MYSQL_PORT", "3306")
MYSQL_USER = os.getenv("MYSQL_USER", "root")
MYSQL_PASSWORD = os.getenv("MYSQL_PASSWORD", "")
MYSQL_DB = os.getenv("MYSQL_DB", "fastapi_learn")

# Set DATABASE_URL directly to override everything above (e.g. to point
# at SQLite for a quick local test with no MySQL server at all).
DATABASE_URL = os.getenv(
    "DATABASE_URL",
    f"mysql+pymysql://{MYSQL_USER}:{MYSQL_PASSWORD}@{MYSQL_HOST}:{MYSQL_PORT}/{MYSQL_DB}",
)

engine = create_engine(DATABASE_URL, pool_pre_ping=True)
SessionLocal = sessionmaker(autocommit=False, autoflush=False, bind=engine)
Base = declarative_base()


def get_db():
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()
```

**`models.py`** — `ItemModel` table:

```python title="models.py"
from sqlalchemy import Column, Integer, String

from database import Base


class ItemModel(Base):
    __tablename__ = "items"

    id = Column(Integer, primary_key=True, autoincrement=True)
    value = Column(String(255), nullable=False)
```

**`schemas.py`** — request body, field optional-a:

```python title="schemas.py"
from typing import Optional

from pydantic import BaseModel


class ItemPatch(BaseModel):
    value: Optional[str] = None
```

**`crud.py`** — database-oda pesura plain functions, HTTP edhuvum
theriyaadhu:

```python title="crud.py"
from sqlalchemy.orm import Session

from models import ItemModel
from schemas import ItemPatch


def get_item(db: Session, item_id: int) -> ItemModel | None:
    return db.get(ItemModel, item_id)


def update_item(db: Session, item_id: int, patch: ItemPatch) -> ItemModel | None:
    row = get_item(db, item_id)
    if row is None:
        return None
    if patch.value is not None:
        row.value = patch.value
    db.commit()
    db.refresh(row)
    return row


def seed_items(db: Session) -> None:
    if db.query(ItemModel).count() == 0:
        db.add_all([ItemModel(value="first"), ItemModel(value="second")])
        db.commit()
```

**`main.py`** — `FastAPI()` app mattrum route:

```python title="main.py"
from fastapi import Depends, FastAPI, HTTPException
from sqlalchemy.orm import Session

import crud
from database import Base, SessionLocal, engine, get_db
from schemas import ItemPatch

Base.metadata.create_all(bind=engine)

with SessionLocal() as db:
    crud.seed_items(db)

app = FastAPI()


@app.patch("/items/{item_id}")
def update_item(item_id: int, patch: ItemPatch, db: Session = Depends(get_db)):
    row = crud.update_item(db, item_id, patch)
    if row is None:
        raise HTTPException(status_code=404, detail="Item not found")
    return {"id": row.id, "value": row.value}
```

## Line by line

`database.py`-oda connection/session setup mattrum `models.py`-oda
`ItemModel` table — indha topic-la irukra ella page-um share panra
same pieces dhan, ippo ella verb-kum same `items` table (five thani
tables illa) — adha line-by-line explain panradha
[index page](/tanglish/docs/mysql-crud)-la paarunga. Keezha, indha
page-ku specific-a `schemas.py`, `crud.py`, mattrum `main.py`-la enna
irukko adha mattum paarpom.

**`schemas.py`:**

1. **`ItemPatch.value` optional** — [PUT](/tanglish/docs/mysql-crud/put)-oda
   `ItemRequest`-la `value` required, idhu vidhyasam. Array topic-oda
   PATCH-la paartha same distinction: `PUT` full representation
   kekkum, `PATCH` maari irukradha mattum anuppa vidum.

**`crud.py`:**

2. `get_item(db, item_id)` — `db.get(ItemModel, item_id)`, indha
   topic-oda ella verb-um use panra same primary-key fetch shortcut:
   andha ID irundha `ItemModel` object return pannum, illa-na `None`
   return pannum, rendu case-layum exception edhuvum raise pannama.
3. `update_item(db, item_id, patch)`:
   - **`get_item` vachi row-ah first-a look up pannum**, adhu missing
     na `None`-ah adha madhiri thirumba kudukkum — indha topic
     ella idathum use panra same "crud HTTP-agnostic-a irukkum,
     main.py raise pannum" split dhan.
   - **`if patch.value is not None: row.value = patch.value`** —
     client real-a oru value anuppina mattum dhan row-ah update
     pannum. Andha assignment mattum podhum SQLAlchemy notice
     pannradhukku: `row` indha same session-la munnadi `get_item`-la
     irundhu vandhadhu, so adhoda "unit of work" already track
     pannikittu irukku — change-ah register panna `db.add(row)`
     venaam.
   - **`db.commit()`** — edhavadhu tracked change-ah `UPDATE`
     statement-a flush pannum, transaction-ah commit pannum. Client
     `{}` anuppi, `patch.value` `None`-a irundha, edhuvum assign
     aagalaye, so indha commit-ku pudhusa edhuvum write panna illa —
     harmless no-op.
   - **`db.refresh(row)`** — apparam database-la irundhu `row`-ah
     thirumba query pannudhu, so indha function return panra object
     MySQL-la ippo enna irukko adha exact-a reflect pannum, indha
     request edhavadhu maathi irundhalum illainalum.

**`main.py`:**

4. `db: Session = Depends(get_db)` — indha topic-oda vera ella route
   mathiri same session-per-request pattern: FastAPI adha `get_db()`
   vachi function run aaguradhukku munnadi kudukkum, function mudinja
   appuram automatic-a close pannum, error vandhalum sari.
5. `update_item(item_id, patch, db)` — `crud.update_item(db, item_id,
   patch)`-ah call pannudhu:
   - `if row is None: raise HTTPException(status_code=404, ...)`
     `crud.update_item` miss-ah report panna, clean `404`-ah anuppum.
   - Idha check pannama `{"id": row.id, "value": row.value}`-ah
     `None` result-la irundhu neraa return pannina, Python
     `AttributeError: 'NoneType' object has no attribute 'id'`-ah
     missing ID-ku raise pannum — FastAPI adha proper `404`-ku
     pathila generic `500 Internal Server Error`-a maathidum.

## Try it

```bash
curl -X PATCH http://127.0.0.1:8000/items/2 -H "Content-Type: application/json" -d "{\"value\": \"patched\"}"

```

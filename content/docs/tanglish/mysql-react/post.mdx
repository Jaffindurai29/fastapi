Oru verb-la start pannalam: **`POST /items`**. Backend-la ore oru route
dhaan, React page value add panni **message mattum** kaattum
(`Item added: first`) — innum list illa. Adutha page
[GET](/tanglish/docs/mysql-react/get)-la list add pannuvom.

## Backend

**`database.py`** — connection settings mattrum `get_db()` dependency, indha topic-la ella page-layum maaradhu:

```python title="database.py"
import os

from dotenv import load_dotenv
from sqlalchemy import URL, create_engine
from sqlalchemy.orm import Session, declarative_base, sessionmaker

load_dotenv()

# URL.create escapes special characters (like "@") in the password.
# Set DATABASE_URL to override it (e.g. "sqlite:///./test.db").
DATABASE_URL = os.getenv("DATABASE_URL") or URL.create(
    "mysql+pymysql",
    username=os.getenv("MYSQL_USER", "root"),
    password=os.getenv("MYSQL_PASSWORD", ""),
    host=os.getenv("MYSQL_HOST", "127.0.0.1"),
    port=int(os.getenv("MYSQL_PORT", "3306")),
    database=os.getenv("MYSQL_DB", "fastapi_learn"),
)

engine = create_engine(DATABASE_URL, pool_pre_ping=True)
SessionLocal = sessionmaker(autocommit=False, autoflush=False, bind=engine)
Base = declarative_base()


def get_db():
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()
```

**`models.py`** — `ItemModel` table:

```python title="models.py"
from sqlalchemy import Column, Integer, String

from database import Base


class ItemModel(Base):
    __tablename__ = "crud_react_items"

    id = Column(Integer, primary_key=True, autoincrement=True)
    value = Column(String(255), nullable=False)
```

**`schemas.py`** — indha route validate panra request body:

```python title="schemas.py"
class ItemRequest(BaseModel):
    value: str
```

**`crud.py`** — insert function:

```python title="crud.py"
def create_item(db: Session, item: ItemRequest) -> ItemModel:
    row = ItemModel(value=item.value)
    db.add(row)
    db.commit()
    db.refresh(row)
    return row
```

**`main.py`** — CORS, mattrum route:

```python title="main.py"
app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:5173", "http://127.0.0.1:5173", "http://localhost:3000"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)


@app.post("/items", status_code=status.HTTP_201_CREATED)
def create_item(item: ItemRequest, db: Session = Depends(get_db)):
    row = crud.create_item(db, item)
    return {"id": row.id, "value": row.value}
```

## Line by line

`database.py`-oda connection settings, `models.py`-oda `ItemModel`
table, CORS setup — indha topic-la ella page-kum shared,
[index page](/tanglish/docs/mysql-react)-la avatha line by line
paarunga. Keezha indha page-ku specific-a irukradhu: `schemas.py`-oda
`ItemRequest`, `crud.py`-oda `create_item`, adha call panra `main.py`-oda
route.

1. `class ItemRequest(BaseModel):` — Pydantic model, FastAPI incoming
   JSON body-ah validate panna use pannum; `value` illama vandha
   request, wrong type, illa JSON-e illadha body — ellam indha route
   body run aaguradhukku munnadi `422`-a reject aagum.
2. `db: Session = Depends(get_db)` — idhu FastAPI-oda dependency
   injection dhan: route body run aaguradhukku munnadi FastAPI thaan
   `get_db()`-ah call pannum.
   - `get_db` oru generator function — adhula `yield` irukku
     paarunga — so FastAPI adha andha `yield` varaikkum run pannum,
     adhu yield panra value (pudhusa create panna `SessionLocal()`
     instance) dhan inga `db` parameter-ku bind aagum.
   - Route return aana appuram (illa raise pannalum), FastAPI
     `get_db()`-ah `yield`-ku apparam resume pannum, `finally:
     db.close()`-ah run pannum — so session eppovum close aagum,
     success-a irundhalum failure-a irundhalum, indha route-ku thani
     `try`/`finally` venaam.
   - `Depends` illama irundha, ovoru route-um thanoda session-ah
     manually open pannanum, close pannanum-nu ninaichukanum —
     exception vandha appuram `close()` marandhuduna, database
     connection quietly leak aagidum.
3. `row = ItemModel(value=item.value)` — memory-la pudhu ORM object
   build pannudhu; database-la edhuvum ippa write aagala.
4. `db.add(row)` — pudhu object-ah session-oda pending state-la stage
   pannudhu mattum; MySQL-ku edhuvum ippa anuppala.
5. `db.commit()` — andha pending `INSERT`-ah flush pannum,
   transaction-ah commit pannum. Idhu dhan MySQL real-a
   auto-increment `id`-ah assign panra point.
6. `db.refresh(row)` — `row.id` real generated value-ah reflect
   panradhukku, database-la irundhu `row`-ah thirumba query pannudhu.
   Idha skip pannina `row.id` innum stale-a illa `None`-a irukalam —
   SQLAlchemy-ku andha database-generated value thirumba kekkama
   theriyadhu.
7. `main.py`-la, `crud.create_item(db, item)` full `ItemModel` object
   return pannum; route dhaan `row.id` mattrum `row.value` mattum
   plain dict-a reshape pannum, FastAPI JSON-a serialize panradhukku —
   indha topic-oda ella route-um same "database logic" vs "HTTP
   response shape" split dhan.
8. **Innum GET route illa.** Browser-la `http://127.0.0.1:8000/items`
   open pannina adhu GET anuppum, so `405 Method Not Allowed` varum —
   path irukku, andha method illa. Indha page-la adhu expected dhaan.

## Thunder Client-la test pannunga

React ezhudharadhukku munnadi backend-ah thaniya test pannunga.

1. **Oru thadava install:** VS Code → Extensions (`Ctrl+Shift+X`) →
   **Thunder Client** search pannunga → Install. Activity Bar-la ⚡ icon varum.
2. Backend start pannunga:

   ```bash
   cd example/7/a
   uvicorn main:app --reload
   ```

3. ⚡ → **New Request**. Method **POST**, URL
   `http://127.0.0.1:8000/items`.
4. **Body** tab → **JSON** (Text illa, Form illa):

   ```json
   {
     "value": "first"
   }
   ```

5. **Send** pannunga. Expected: **`201 Created`**, mattrum

   ```json
   { "id": 1, "value": "first" }
   ```

   `id` MySQL adutha-a assign panra number — empty table-la `1`,
   adutha row-ku `2`, ippadi.

| Varudhu | Yen | Fix |
|---|---|---|
| `422` — *"Input should be a valid dictionary or object"* | Body Text/Form-a pochu, illa valid JSON illa | Body → **JSON**, double quotes-oda `{"value": "..."}` anuppunga |
| `422` — *"Field required"* | Key `value` illa | Exact-a `value` nu dhaan irukanum |
| `405 Method Not Allowed` | Wrong method, illa running app-la POST route illa | Method dropdown-ah check pannunga, `main.py`-la `@app.post("/items")` irukka-nu paarunga |
| Connection refused | Backend run aagala | Mudhalla `uvicorn` start pannunga |

## Frontend

## Add panni, message kaattu

```jsx title="src/App.js"
const [newValue, setNewValue] = useState('');
const [message, setMessage] = useState('');
const API_URL = 'http://localhost:8000'

async function addItem() {
  const response = await axios.post(`${API_URL}/items`, { value: newValue });
  setMessage(`Item added: ${response.data.value}`);
  setNewValue('');
}
```

```jsx
<input
  value={newValue}
  onChange={(e) => setNewValue(e.target.value)}
  placeholder="New item"
/>
<button onClick={addItem}>
  Add
</button>
{message && <p>{message}</p>}
```

Request [React's POST](/tanglish/docs/react/post)-oda same dhan —
body rendu pakkamum same `{ value }` shape. **Pudhusa irukradhu page
response-ah padikkiradhu:** backend save aana row-ah thirumba
anuppudhu, page adha message-a maathudhu.

## Line by line

1. **State** — innum `items` list illa: input (`newValue`), `message`
   mattum dhaan.
2. `API_URL = 'http://localhost:8000'` — `uvicorn` run aagura idam.
3. `axios.post(...)` with `{ value: newValue }` — axios object-ah JSON-a
   maathi `Content-Type: application/json` set pannum — Thunder
   Client-oda JSON tab-la anuppuna same body dhaan. Vera edhavadhu
   (`` `value` = `first` `` maari plain text) anuppina dhaan `422` varum.
4. `response.data` — backend-oda JSON response, so
   `response.data.value` MySQL ippo save panna value. List-ah refetch
   panna GET illadhadhaala, page adha message-a kaattudhu.
5. `setNewValue('')` — add success aana appuram input-ah clear pannum.
6. `{message && <p>{message}</p>}` — message irundha mattum render
   aagum; ovvoru add-um munnadi irundha message-ah replace pannum.
7. Button `onClick` moolama `addItem`-ah neraa call pannudhu — `<form>`
   illa, so prevent panna page reload-um illa.
8. Request fail aana (backend run aagala, CORS, `422`), axios throw
   pannum, page-la edhuvum maaradhu — browser console (F12) open panni
   error paarunga. [GET](/tanglish/docs/mysql-react/get) page code
   `try`/`catch` add panni error-ah page-la kaattum.
9. Page refresh pannina message pogidum, aana row MySQL-la innum irukku.
   [GET](/tanglish/docs/mysql-react/get) adha thirumba load pannum.

**Run panradhu:** idhu Create React App project (`npx
create-react-app`), `npm start` vachi
[http://localhost:3000](http://localhost:3000)-la run aagum — adhanaala
dhaan `main.py`-oda CORS `allow_origins`-la `http://localhost:3000`
irukku. Indha same `App.js`, `example/7/react`-la irukra Vite app-la
(port `5173`) `App.jsx`-a-vum work aagum.

Adutha step: [GET](/tanglish/docs/mysql-react/get) — rows-ah thirumba load pannurathu.

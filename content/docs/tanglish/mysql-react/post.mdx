## Backend

**`database.py`** mattrum **`models.py`** — [GET](/tanglish/docs/mysql-react/get)-la
paartha same connection, session, `ItemModel` table, inga maaradhu.

**`schemas.py`** — indha route validate panra request body:

```python title="schemas.py"
class ItemRequest(BaseModel):
    value: str
```

**`crud.py`** — insert function:

```python title="crud.py"
def create_item(db: Session, item: ItemRequest) -> ItemModel:
    row = ItemModel(value=item.value)
    db.add(row)
    db.commit()
    db.refresh(row)
    return row
```

**`main.py`** — route:

```python title="main.py"
@app.post("/items", status_code=status.HTTP_201_CREATED)
def create_item(item: ItemRequest, db: Session = Depends(get_db)):
    row = crud.create_item(db, item)
    return {"id": row.id, "value": row.value}
```

## Line by line

`database.py`-oda connection/`get_db()`, `models.py`-oda `ItemModel` —
shared setup, [index page](/tanglish/docs/mysql-react)-la oru thadava
explain pannirukom. Keezha indha page-la pudhusa irukradhu:
`schemas.py`-oda `ItemRequest`, `crud.py`-oda `create_item`, adha
call panra `main.py`-oda route.

1. `class ItemRequest(BaseModel):` — Pydantic model, FastAPI incoming
   JSON body-ah validate panna use pannum; `value` illama vandha
   request, illa wrong type vandhalum, indha route body run aaguradhukku
   munnadi `422`-a reject aagum.
2. `db: Session = Depends(get_db)` — [GET](/tanglish/docs/mysql-react/get)-la
   paartha same dependency injection: indha route body run
   aaguradhukku munnadi FastAPI `get_db()`-ah adhoda `yield`
   varaikkum run pannum, pudhusa create panna session-ah `db`-a
   kudukkum, route mudinja appuram (success-a irundhalum failure-a
   irundhalum) andha session-ah automatic-a close pannum.
3. `row = ItemModel(value=item.value)` — memory-la pudhu ORM object
   build pannudhu; database-la edhuvum ippa write aagala.
4. `db.add(row)` — pudhu object-ah session-oda pending state-la stage
   pannudhu mattum; MySQL-ku edhuvum ippa anuppala.
5. `db.commit()` — andha pending `INSERT`-ah flush pannum,
   transaction-ah commit pannum. Idhu dhan MySQL real-a
   auto-increment `id`-ah assign panra point.
6. `db.refresh(row)` — `row.id` real generated value-ah reflect
   panradhukku, database-la irundhu `row`-ah thirumba query pannudhu.
   Idha skip pannina `row.id` innum stale-a illa `None`-a irukalam —
   SQLAlchemy-ku andha database-generated value thirumba kekkama
   theriyadhu.
7. `main.py`-la, `crud.create_item(db, item)` full `ItemModel` object
   return pannum; route dhaan `row.id` mattrum `row.value` mattum
   plain dict-a reshape pannum, FastAPI JSON-a serialize panradhukku —
   indha topic-oda ella route-um same "database logic" vs "HTTP
   response shape" split dhan.

## Inga vidhyasam illa

```jsx
async function addItem(event) {
  event.preventDefault();
  if (value.trim() === "") return;

  try {
    await axios.post(`${API_URL}/items`, { value: value });
  } catch (err) {
    setError(errorMessage("add item", err));
    return;
  }

  setValue("");
  await loadItems();
}
```

[React's POST](/tanglish/docs/react/post)-oda identical dhan — request
body rendu pakkamum same `{ value }` shape. **Maari irukra oru
vishayam backend-la nadandhuchu, inga illa:** database ippo pudhu
row-ku real `id`-ah assign pannudhu, frontend `items.length`-la
landed aachu-nu assume pannradhukku pathila.

## Line by line

1. `addItem` array version-oda function-oda byte-for-byte identical
   dhan — same `event.preventDefault()`, same empty-value guard, same
   `axios.post` call mattrum body shape. Indha code-la item identity
   (`index` vs `id`) gurichi edhuvum illa, so inga edhuvum maara
   vendiya aavasiyam illa.
2. `event.preventDefault()` innum browser-oda default full-page
   reload-ah submit-la stop pannum — MySQL-oda relation illa, backend
   maarina kooda idhu maaradhu.
3. `if (value.trim() === "") return;` innum empty illa
   whitespace-only input-ku request-ah skip pannum.
4. Success aana appuram, `setValue("")` input-ah clear pannum, apparam
   `await loadItems()` backend-la irundhu full list-ah thirumba fetch
   pannum — inga dhan pudhu row-oda `id` frontend-la varum: idhu indha
   refetch moolama dhan varum, frontend calculate panradhu illa. Array
   version-oda vidhyasam, andha version-la frontend already
   `items.length` dhan pudhu item-oda index-nu guess pannalam.
5. Real-a maari irukra vishayam full-a backend-la dhan irukku: MySQL
   pudhu row-ku real auto-incrementing `id`-ah assign pannudhu,
   frontend computed array position assume pannradhukku pathila.

Adutha step: [PUT](/tanglish/docs/mysql-react/put) — oru row-ah edit
pannurathu, ID vachi address panni.

```python title="database.py"
import os

from dotenv import load_dotenv
from sqlalchemy import create_engine
from sqlalchemy.orm import Session, declarative_base, sessionmaker

load_dotenv()

MYSQL_HOST = os.getenv("MYSQL_HOST", "127.0.0.1")
MYSQL_PORT = os.getenv("MYSQL_PORT", "3306")
MYSQL_USER = os.getenv("MYSQL_USER", "root")
MYSQL_PASSWORD = os.getenv("MYSQL_PASSWORD", "")
MYSQL_DB = os.getenv("MYSQL_DB", "fastapi_learn")

DATABASE_URL = os.getenv(
    "DATABASE_URL",
    f"mysql+pymysql://{MYSQL_USER}:{MYSQL_PASSWORD}@{MYSQL_HOST}:{MYSQL_PORT}/{MYSQL_DB}",
)

engine = create_engine(DATABASE_URL, pool_pre_ping=True)
SessionLocal = sessionmaker(autocommit=False, autoflush=False, bind=engine)
Base = declarative_base()


def get_db():
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()
```

```python title="models.py"
from sqlalchemy import Column, Integer, String

from database import Base


class ItemModel(Base):
    __tablename__ = "crud_react_items"

    id = Column(Integer, primary_key=True, autoincrement=True)
    value = Column(String(255), nullable=False)
```

```python title="schemas.py"
from pydantic import BaseModel


class ItemRequest(BaseModel):
    value: str
```

```python title="crud.py"
from sqlalchemy.orm import Session

from models import ItemModel
from schemas import ItemRequest


def get_items(db: Session) -> list[ItemModel]:
    return db.query(ItemModel).order_by(ItemModel.id).all()


def get_item(db: Session, item_id: int) -> ItemModel | None:
    return db.get(ItemModel, item_id)


def create_item(db: Session, item: ItemRequest) -> ItemModel:
    row = ItemModel(value=item.value)
    db.add(row)
    db.commit()
    db.refresh(row)
    return row
```

```python title="main.py"
from fastapi import Depends, FastAPI, HTTPException, status
from fastapi.middleware.cors import CORSMiddleware
from sqlalchemy.orm import Session

import crud
from database import Base, SessionLocal, engine, get_db
from schemas import ItemRequest

Base.metadata.create_all(bind=engine)

with SessionLocal() as db:
    crud.seed_items(db)

app = FastAPI()

app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:5173", "http://127.0.0.1:5173"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)


@app.get("/items")
def list_items(db: Session = Depends(get_db)):
    return [{"id": row.id, "value": row.value} for row in crud.get_items(db)]


@app.get("/items/{item_id}")
def get_item(item_id: int, db: Session = Depends(get_db)):
    row = crud.get_item(db, item_id)
    if row is None:
        raise HTTPException(status_code=404, detail="Item not found")
    return {"id": row.id, "value": row.value}


@app.post("/items", status_code=status.HTTP_201_CREATED)
def create_item(item: ItemRequest, db: Session = Depends(get_db)):
    row = crud.create_item(db, item)
    return {"id": row.id, "value": row.value}
```

**Frontend** — `example/7/react/src/App.jsx`, POST varaikkum:

```jsx title="example/7/react/src/App.jsx"
import { useEffect, useState } from "react";
import axios from "axios";

const API_URL = "http://127.0.0.1:8000";

function errorMessage(action, err) {
  const status = err.response?.status;
  return status ? `Failed to ${action} (status ${status})` : `Failed to ${action}: ${err.message}`;
}

export default function App() {
  const [items, setItems] = useState([]);
  const [value, setValue] = useState("");
  const [reached, setReached] = useState(null);
  const [error, setError] = useState(null);

  useEffect(() => {
    loadItems();
  }, []);

  async function loadItems() {
    try {
      const response = await axios.get(`${API_URL}/items`);
      setItems(response.data);
      setError(null);
    } catch (err) {
      setError(errorMessage("load items", err));
    }
  }

  async function addItem(event) {
    event.preventDefault();
    if (value.trim() === "") return;

    try {
      await axios.post(`${API_URL}/items`, { value: value });
    } catch (err) {
      setError(errorMessage("add item", err));
      return;
    }

    setValue("");
    await loadItems();
  }

  async function reachItem(id) {
    try {
      const response = await axios.get(`${API_URL}/items/${id}`);
      setReached(response.data);
      setError(null);
    } catch (err) {
      setError(errorMessage(`reach id ${id}`, err));
      setReached(null);
    }
  }

  return (
    <main style={{ maxWidth: 560, margin: "3rem auto", fontFamily: "sans-serif" }}>
      <h1>MySQL Store</h1>

      {error && <p style={{ color: "crimson" }}>{error}</p>}

      <form onSubmit={addItem} style={{ display: "flex", gap: "0.5rem" }}>
        <input
          value={value}
          onChange={(event) => setValue(event.target.value)}
          placeholder="Add a value"
          style={{ flex: 1, padding: "0.5rem" }}
        />
        <button type="submit">Add</button>
      </form>

      <ul style={{ listStyle: "none", padding: 0, marginTop: "1.5rem" }}>
        {items.map((item) => (
          <li
            key={item.id}
            style={{ display: "flex", alignItems: "center", gap: "0.5rem", padding: "0.25rem 0" }}
          >
            <span style={{ color: "#888", width: "2rem" }}>#{item.id}</span>
            <span style={{ flex: 1 }}>{item.value}</span>
            <button onClick={() => reachItem(item.id)}>Reach</button>
          </li>
        ))}
      </ul>

      {reached && (
        <p style={{ marginTop: "1rem" }}>
          Reached id <strong>#{reached.id}</strong>: <strong>{reached.value}</strong>
        </p>
      )}
    </main>
  );
}
```

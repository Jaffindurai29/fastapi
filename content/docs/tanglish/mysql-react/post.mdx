## Inga vidhyasam illa

```jsx
async function addItem(event) {
  event.preventDefault();
  if (value.trim() === "") return;

  const response = await fetch(`${API_URL}/items`, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ value: value }),
  });

  if (!response.ok) {
    setError(`Failed to add item (status ${response.status})`);
    return;
  }

  setValue("");
  await loadItems();
}
```

[React's POST](/tanglish/docs/react/post)-oda identical dhan — request
body rendu pakkamum same `{ value }` shape. **Maari irukra oru
vishayam backend-la nadandhuchu, inga illa:** database ippo pudhu
row-ku real `id`-ah assign pannudhu, frontend `items.length`-la
landed aachu-nu assume pannradhukku pathila.

Adutha step: [PUT](/tanglish/docs/mysql-react/put) — oru row-ah edit
pannurathu, ID vachi address panni.

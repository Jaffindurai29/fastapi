[POST](/tanglish/docs/mysql-react/post)-la rows add panni message mattum
kaatta mudinjudhu. Indha page rendu GET routes add pannudhu — page ella
rows-ayum list pannalam, ID vachi oru row-ah reach pannalam.

## Backend

**`database.py`**, **`models.py`**, **`schemas.py`** — [POST](/tanglish/docs/mysql-react/post)-la
paartha same connection, session, `ItemModel` table, `ItemRequest`, inga maaradhu.

**`crud.py`** — rendu read functions, HTTP-agnostic-a:

```python title="crud.py"
def get_items(db: Session) -> list[ItemModel]:
    return db.query(ItemModel).order_by(ItemModel.id).all()


def get_item(db: Session, item_id: int) -> ItemModel | None:
    return db.get(ItemModel, item_id)
```

**`main.py`** — rendu routes, `crud.py`-ah call pannudhu:

```python title="main.py"
@app.get("/items")
def list_items(db: Session = Depends(get_db)):
    return [{"id": row.id, "value": row.value} for row in crud.get_items(db)]


@app.get("/items/{item_id}")
def get_item(item_id: int, db: Session = Depends(get_db)):
    row = crud.get_item(db, item_id)
    if row is None:
        raise HTTPException(status_code=404, detail="Item not found")
    return {"id": row.id, "value": row.value}
```

## Line by line

`database.py`-oda connection settings mattrum `get_db()` dependency,
`models.py`-oda `ItemModel` table — indha topic-la ella page-layum
same, [index page](/tanglish/docs/mysql-react)-la avatha line by
line paarunga. Keezha indha page-ku specific-a irukradhu: `crud.py`-oda
rendu read functions, adha call panra `main.py`-oda routes.

1. `db: Session = Depends(get_db)` — [POST](/tanglish/docs/mysql-react/post)-la
   paartha same dependency injection dhan: route body run aaguradhukku
   munnadi FastAPI `get_db()` vachi pudhu session open pannum, route
   mudinja appuram (success-a irundhalum failure-a irundhalum) close pannum.
2. `crud.get_items(db)` `db.query(ItemModel).order_by(ItemModel.id).all()`-ah
   run pannum — moonu thani steps chain aagi irukku, kadaisi step
   varaikkum MySQL-ku edhuvum pogadhu:
   - `db.query(ItemModel)` — `ItemModel` map panra table-ku scoped-a
     oru SELECT build pannum.
   - `.order_by(ItemModel.id)` — `ORDER BY id` add pannum, so rows
     stable-a, predictable order-la varum — idha skip pannina, MySQL
     rows-ah edho oru order-la return pannalam, request-ku request
     shuffle aagalam.
   - `.all()` dhan real-a query-ah execute pannum, match aana ella
     row-um `ItemModel` objects list-a memory-ku load pannum.
   - `main.py`-la, `crud.get_items(db)`-ah suthi irukra
     `{"id": row.id, "value": row.value}` comprehension, ovoru ORM
     object-ayum plain dict-a convert pannum — FastAPI-oda JSON encoder
     plain Python types-ah dhan serialize pannum, `ItemModel`
     instance-ah neraa pannadhu. Indha reshaping `main.py`-la irukku,
     `crud.py`-la illa — so `crud.py` HTTP/JSON-agnostic-a irukkum,
     ORM objects mattum thirumba kudukkum.
3. `crud.get_item(db, item_id)` `db.get(ItemModel, item_id)`-ah run
   pannum — SQLAlchemy-oda "primary key vachi fetch pannu" shortcut.
   Andha ID-oda row irundha `ItemModel` object return pannum, illa-na
   `None` return pannum — miss aana exception edhuvum raise pannadhu.
   - `main.py`-la, `if row is None: raise
     HTTPException(status_code=404, ...)` dhan andha `None`-ah real
     HTTP `404 Not Found` response-a maathum — munnadi topic-oda same
     404-if-missing pattern.
   - Idha check pannama `row.value`-ku neraa poirundha, missing ID
     Python `AttributeError: 'NoneType' object has no attribute
     'value'`-ah raise pannum, adha FastAPI generic `500 Internal
     Server Error`-a maathidum.
4. `GET /items` POST-oda same path, vera method. FastAPI **method +
   path** vachi match pannum — adhanaala dhaan POST page-la `/items`-ku
   GET anuppuna `404` illa, `405 Method Not Allowed` vandhuchu (path
   irundhuchu, method illa).

## Thunder Client-la test pannunga

`uvicorn --reload` run aagitu irundha restart venaam — `main.py` save
pannina adhuve reload aagum.

**Request 1 — ella rows-um GET:**

1. ⚡ → **New Request**, method **GET**, URL `http://127.0.0.1:8000/items`.
2. Body venam — Body tab-ah empty-a vidunga.
3. **Send** → `200 OK`, ippo varaikkum irukra ella rows-um — udharanathukku
   POST page-la add panna `first`, plus innonnu:

   ```json
   [
     { "id": 1, "value": "first" },
     { "id": 2, "value": "second" }
   ]
   ```

**Request 2 — ID vachi oru row GET:**

1. **New Request**, **GET**, `http://127.0.0.1:8000/items/1`.
2. **Send** → `200 OK`, `{"id": 1, "value": "first"}`.
3. Illadha ID-ku URL maathunga, e.g. `/items/999` →
   `404 Not Found`, `{"detail": "Item not found"}`.

**Tip:** Thunder Client → **Collections** → **New Collection** (e.g.
`mysql-react`) → POST, GET requests-ah adhula save pannunga, appuram
ovvonnayum oru click-la thirumba run pannalam.

## Frontend

## Load mattrum reach, ID vachi

```jsx
async function loadItems() {
  const response = await axios.get(`${API_URL}/items`);
  // ...array version-ku identical
  setItems(response.data);
}

async function reachItem(id) {
  const response = await axios.get(`${API_URL}/items/${id}`);
  // ...array version-oda same dhan, `index`-ku pathila `id` nu peru
  setReached(response.data);
}
```

[POST](/tanglish/docs/mysql-react/post)-oda `addItem`-um maarudhu: ippo
call panna GET irukradhaala, message kaattradhukku pathila list-ah
refetch pannum — pudhu row adhoda `id`-oda list-la varum:

```jsx
try {
  await axios.post(`${API_URL}/items`, { value: value });
} catch (err) {
  setError(errorMessage("add item", err));
  return;
}

setValue("");
await loadItems();
```

**[React's GET](/tanglish/docs/react/get)-oda vidhyasam:** URL innum
`/items/<something>` dhan — andha something enna **meaning** pannudho
adhu mattum maari irukku. Munnadi, "array-la 3rd item" nu irundhuchu.
Inga, "database ID indha number-oda irukra row" nu — list-la ippo enga
irukku nu paakadha. `loadItems` idhu maari maaradhu — backend plain
string-ku pathila objects return pannudhu, aana indha function
vandha JSON-ah adha maadhiri dhan store pannum.

## Line by line

1. `loadItems()` page open aagumbodhu oru thadava run aagum
   (`useEffect(..., [])` moolama), vandha JSON-ah store pannum — inga
   `{ id, value }` objects.
2. `addItem` ippo `setMessage(...)`-ku pathila `await loadItems()`-la
   mudiyudhu — pudhu row-oda `id` indha refetch moolama, matha ella
   rows-oda serndhu varum.
3. `reachItem(id)` array version-oda `reachItem(index)` dhan,
   `index`-ku pathila `id` engum rename pannirukom — URL, error
   message, mattrum parameter.
4. URL pattern `/items/<something>` maaradhu; andha `<something>`
   enna identify pannudho adhu mattum maarudhu — array position-ku
   pathila database ID.

Adutha step: [PUT](/tanglish/docs/mysql-react/put) — oru row-ah edit
pannurathu, ID vachi address panni.

## Ippo varaikkum code

**Backend** — `example/7/a`, GET varaikkum:

```python title="database.py"
import os

from dotenv import load_dotenv
from sqlalchemy import URL, create_engine
from sqlalchemy.orm import Session, declarative_base, sessionmaker

load_dotenv()

# URL.create escapes special characters (like "@") in the password.
# Set DATABASE_URL to override it (e.g. "sqlite:///./test.db").
DATABASE_URL = os.getenv("DATABASE_URL") or URL.create(
    "mysql+pymysql",
    username=os.getenv("MYSQL_USER", "root"),
    password=os.getenv("MYSQL_PASSWORD", ""),
    host=os.getenv("MYSQL_HOST", "127.0.0.1"),
    port=int(os.getenv("MYSQL_PORT", "3306")),
    database=os.getenv("MYSQL_DB", "fastapi_learn"),
)

engine = create_engine(DATABASE_URL, pool_pre_ping=True)
SessionLocal = sessionmaker(autocommit=False, autoflush=False, bind=engine)
Base = declarative_base()


def get_db():
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()
```

```python title="models.py"
from sqlalchemy import Column, Integer, String

from database import Base


class ItemModel(Base):
    __tablename__ = "crud_react_items"

    id = Column(Integer, primary_key=True, autoincrement=True)
    value = Column(String(255), nullable=False)
```

```python title="schemas.py"
from pydantic import BaseModel


class ItemRequest(BaseModel):
    value: str
```

```python title="crud.py"
from sqlalchemy.orm import Session

from models import ItemModel
from schemas import ItemRequest


def get_items(db: Session) -> list[ItemModel]:
    return db.query(ItemModel).order_by(ItemModel.id).all()


def get_item(db: Session, item_id: int) -> ItemModel | None:
    return db.get(ItemModel, item_id)


def create_item(db: Session, item: ItemRequest) -> ItemModel:
    row = ItemModel(value=item.value)
    db.add(row)
    db.commit()
    db.refresh(row)
    return row


def seed_items(db: Session) -> None:
    if db.query(ItemModel).count() == 0:
        db.add_all([ItemModel(value="first"), ItemModel(value="second")])
        db.commit()
```

```python title="main.py"
from fastapi import Depends, FastAPI, HTTPException, status
from fastapi.middleware.cors import CORSMiddleware
from sqlalchemy.orm import Session

import crud
from database import Base, SessionLocal, engine, get_db
from schemas import ItemRequest

Base.metadata.create_all(bind=engine)

with SessionLocal() as db:
    crud.seed_items(db)

app = FastAPI()

app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:5173", "http://127.0.0.1:5173", "http://localhost:3000"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)


@app.get("/items")
def list_items(db: Session = Depends(get_db)):
    return [{"id": row.id, "value": row.value} for row in crud.get_items(db)]


@app.get("/items/{item_id}")
def get_item(item_id: int, db: Session = Depends(get_db)):
    row = crud.get_item(db, item_id)
    if row is None:
        raise HTTPException(status_code=404, detail="Item not found")
    return {"id": row.id, "value": row.value}


@app.post("/items", status_code=status.HTTP_201_CREATED)
def create_item(item: ItemRequest, db: Session = Depends(get_db)):
    row = crud.create_item(db, item)
    return {"id": row.id, "value": row.value}
```

`seed_items` GET-oda serndhu varudhu: startup-la table empty-a irundha
rendu starter rows add pannum, so page first time open pannumbodhu list
blank-a irukadhu. POST page-la already rows add pannirundha, edhuvum pannadhu.

**Frontend** — `example/7/react/src/App.jsx`, GET varaikkum:

```jsx title="example/7/react/src/App.jsx"
import { useEffect, useState } from "react";
import axios from "axios";

const API_URL = "http://127.0.0.1:8000";

function errorMessage(action, err) {
  const status = err.response?.status;
  return status ? `Failed to ${action} (status ${status})` : `Failed to ${action}: ${err.message}`;
}

export default function App() {
  const [items, setItems] = useState([]);
  const [value, setValue] = useState("");
  const [reached, setReached] = useState(null);
  const [error, setError] = useState(null);

  useEffect(() => {
    loadItems();
  }, []);

  async function loadItems() {
    try {
      const response = await axios.get(`${API_URL}/items`);
      setItems(response.data);
      setError(null);
    } catch (err) {
      setError(errorMessage("load items", err));
    }
  }

  async function addItem(event) {
    event.preventDefault();
    if (value.trim() === "") return;

    try {
      await axios.post(`${API_URL}/items`, { value: value });
    } catch (err) {
      setError(errorMessage("add item", err));
      return;
    }

    setValue("");
    await loadItems();
  }

  async function reachItem(id) {
    try {
      const response = await axios.get(`${API_URL}/items/${id}`);
      setReached(response.data);
      setError(null);
    } catch (err) {
      setError(errorMessage(`reach id ${id}`, err));
      setReached(null);
    }
  }

  return (
    <main style={{ maxWidth: 560, margin: "3rem auto", fontFamily: "sans-serif" }}>
      <h1>MySQL Store</h1>

      {error && <p style={{ color: "crimson" }}>{error}</p>}

      <form onSubmit={addItem} style={{ display: "flex", gap: "0.5rem" }}>
        <input
          value={value}
          onChange={(event) => setValue(event.target.value)}
          placeholder="Add a value"
          style={{ flex: 1, padding: "0.5rem" }}
        />
        <button type="submit">Add</button>
      </form>

      <ul style={{ listStyle: "none", padding: 0, marginTop: "1.5rem" }}>
        {items.map((item) => (
          <li
            key={item.id}
            style={{ display: "flex", alignItems: "center", gap: "0.5rem", padding: "0.25rem 0" }}
          >
            <span style={{ color: "#888", width: "2rem" }}>#{item.id}</span>
            <span style={{ flex: 1 }}>{item.value}</span>
            <button onClick={() => reachItem(item.id)}>Reach</button>
          </li>
        ))}
      </ul>

      {reached && (
        <p style={{ marginTop: "1rem" }}>
          Reached id <strong>#{reached.id}</strong>: <strong>{reached.value}</strong>
        </p>
      )}
    </main>
  );
}
```

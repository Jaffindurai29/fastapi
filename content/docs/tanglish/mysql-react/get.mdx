## Backend

```python title="example/7/a/main.py"
@app.get("/items")
def list_items(db: Session = Depends(get_db)):
    rows = db.query(ItemModel).order_by(ItemModel.id).all()
    return [{"id": row.id, "value": row.value} for row in rows]


@app.get("/items/{item_id}")
def get_item(item_id: int, db: Session = Depends(get_db)):
    row = db.get(ItemModel, item_id)
    if row is None:
        raise HTTPException(status_code=404, detail="Item not found")
    return {"id": row.id, "value": row.value}
```

## Line by line

1. `db: Session = Depends(get_db)` — idhu FastAPI-oda dependency
   injection dhan: route body run aaguradhukku munnadi FastAPI thaan
   `get_db()`-ah call pannum.
   - `get_db` oru generator function — adhula `yield` irukku
     paarunga — so FastAPI adha andha `yield` varaikkum run pannum,
     adhu yield panra value (pudhusa create panna `SessionLocal()`
     instance) dhan inga `db` parameter-ku bind aagum.
   - Route return aana appuram (illa raise pannalum), FastAPI
     `get_db()`-ah `yield`-ku apparam resume pannum, `finally:
     db.close()`-ah run pannum — so session eppovum close aagum,
     success-a irundhalum failure-a irundhalum, indha route-ku thani
     `try`/`finally` venaam.
   - `Depends` illama irundha, ovoru route-um thanoda session-ah
     manually open pannanum, close pannanum-nu ninaichukanum —
     exception vandha appuram `close()` marandhuduna, database
     connection quietly leak aagidum.
2. `db.query(ItemModel).order_by(ItemModel.id).all()` — moonu thani
   steps chain aagi irukku, kadaisi step varaikkum MySQL-ku edhuvum
   pogadhu:
   - `db.query(ItemModel)` — `ItemModel` map panra table-ku scoped-a
     oru SELECT build pannum.
   - `.order_by(ItemModel.id)` — `ORDER BY id` add pannum, so rows
     stable-a, predictable order-la varum — idha skip pannina, MySQL
     rows-ah edho oru order-la return pannalam, request-ku request
     shuffle aagalam.
   - `.all()` dhan real-a query-ah execute pannum, match aana ella
     row-um `ItemModel` objects list-a memory-ku load pannum.
   - Idha suthi irukra `{"id": row.id, "value": row.value}`
     comprehension, ovoru ORM object-ayum plain dict-a convert pannum —
     FastAPI-oda JSON encoder plain Python types-ah dhan serialize
     pannum, `ItemModel` instance-ah neraa pannadhu.
3. `db.get(ItemModel, item_id)` — SQLAlchemy-oda "primary key vachi
   fetch pannu" shortcut. Andha ID-oda row irundha `ItemModel` object
   return pannum, illa-na `None` return pannum — miss aana exception
   edhuvum raise pannadhu.
   - `if row is None: raise HTTPException(status_code=404, ...)` dhan
     andha `None`-ah real HTTP `404 Not Found` response-a maathum —
     array version-oda same 404-if-missing pattern.
   - Idha check pannama `row.value`-ku neraa poirundha, missing ID
     Python `AttributeError: 'NoneType' object has no attribute
     'value'`-ah raise pannum, adha FastAPI generic `500 Internal
     Server Error`-a maathidum.

## Frontend

## Load mattrum reach, ID vachi

```jsx
async function loadItems() {
  const response = await fetch(`${API_URL}/items`);
  // ...array version-ku identical
  setItems(await response.json());
}

async function reachItem(id) {
  const response = await fetch(`${API_URL}/items/${id}`);
  // ...array version-oda same dhan, `index`-ku pathila `id` nu peru
  setReached(await response.json());
}
```

**[React's GET](/tanglish/docs/react/get)-oda vidhyasam:** URL innum
`/items/<something>` dhan — andha something enna **meaning** pannudho
adhu mattum maari irukku. Munnadi, "array-la 3rd item" nu irundhuchu.
Inga, "database ID indha number-oda irukra row" nu — list-la ippo enga
irukku nu paakadha. `loadItems` idhu maari maaradhu — backend plain
string-ku pathila objects return pannudhu, aana indha function
vandha JSON-ah adha maadhiri dhan store pannum.

## Line by line

1. `reachItem(id)` array version-oda `reachItem(index)` dhan,
   `index`-ku pathila `id` engum rename pannirukom — URL, error
   message, mattrum parameter.
2. `loadItems()` maaradhu — vandha JSON edhuvaagilum (plain strings
   illana `{ id, value }` objects) adha maadhiri dhan store pannum.
3. URL pattern `/items/<something>` maaradhu; andha `<something>`
   enna identify pannudho adhu mattum maarudhu — array position-ku
   pathila database ID.

## Ippo varaikkum code

**Backend** — `example/7/a/main.py`, GET varaikkum:

```python title="example/7/a/main.py"
import os

from fastapi import Depends, FastAPI, HTTPException
from fastapi.middleware.cors import CORSMiddleware
from sqlalchemy import Column, Integer, String, create_engine
from sqlalchemy.orm import Session, declarative_base, sessionmaker

MYSQL_HOST = os.getenv("MYSQL_HOST", "127.0.0.1")
MYSQL_PORT = os.getenv("MYSQL_PORT", "3306")
MYSQL_USER = os.getenv("MYSQL_USER", "root")
MYSQL_PASSWORD = os.getenv("MYSQL_PASSWORD", "")
MYSQL_DB = os.getenv("MYSQL_DB", "fastapi_learn")

DATABASE_URL = os.getenv(
    "DATABASE_URL",
    f"mysql+pymysql://{MYSQL_USER}:{MYSQL_PASSWORD}@{MYSQL_HOST}:{MYSQL_PORT}/{MYSQL_DB}",
)

engine = create_engine(DATABASE_URL, pool_pre_ping=True)
SessionLocal = sessionmaker(autocommit=False, autoflush=False, bind=engine)
Base = declarative_base()


class ItemModel(Base):
    __tablename__ = "crud_react_items"
    id = Column(Integer, primary_key=True, autoincrement=True)
    value = Column(String(255), nullable=False)


Base.metadata.create_all(bind=engine)

with SessionLocal() as db:
    if db.query(ItemModel).count() == 0:
        db.add_all([ItemModel(value="first"), ItemModel(value="second")])
        db.commit()

app = FastAPI()

app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:5173", "http://127.0.0.1:5173"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)


def get_db():
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()


@app.get("/items")
def list_items(db: Session = Depends(get_db)):
    rows = db.query(ItemModel).order_by(ItemModel.id).all()
    return [{"id": row.id, "value": row.value} for row in rows]


@app.get("/items/{item_id}")
def get_item(item_id: int, db: Session = Depends(get_db)):
    row = db.get(ItemModel, item_id)
    if row is None:
        raise HTTPException(status_code=404, detail="Item not found")
    return {"id": row.id, "value": row.value}
```

**Frontend** — `example/7/react/src/App.jsx`, GET varaikkum:

```jsx title="example/7/react/src/App.jsx"
import { useEffect, useState } from "react";

const API_URL = "http://127.0.0.1:8000";

export default function App() {
  const [items, setItems] = useState([]);
  const [reached, setReached] = useState(null);
  const [error, setError] = useState(null);

  useEffect(() => {
    loadItems();
  }, []);

  async function loadItems() {
    try {
      const response = await fetch(`${API_URL}/items`);
      if (!response.ok) {
        throw new Error(`Failed to load items (status ${response.status})`);
      }
      setItems(await response.json());
      setError(null);
    } catch (err) {
      setError(err.message);
    }
  }

  async function reachItem(id) {
    const response = await fetch(`${API_URL}/items/${id}`);
    if (!response.ok) {
      setError(`Failed to reach id ${id} (status ${response.status})`);
      setReached(null);
      return;
    }
    setReached(await response.json());
    setError(null);
  }

  return (
    <main style={{ maxWidth: 560, margin: "3rem auto", fontFamily: "sans-serif" }}>
      <h1>MySQL Store</h1>

      {error && <p style={{ color: "crimson" }}>{error}</p>}

      <ul style={{ listStyle: "none", padding: 0, marginTop: "1.5rem" }}>
        {items.map((item) => (
          <li
            key={item.id}
            style={{ display: "flex", alignItems: "center", gap: "0.5rem", padding: "0.25rem 0" }}
          >
            <span style={{ color: "#888", width: "2rem" }}>#{item.id}</span>
            <span style={{ flex: 1 }}>{item.value}</span>
            <button onClick={() => reachItem(item.id)}>Reach</button>
          </li>
        ))}
      </ul>

      {reached && (
        <p style={{ marginTop: "1rem" }}>
          Reached id <strong>#{reached.id}</strong>: <strong>{reached.value}</strong>
        </p>
      )}
    </main>
  );
}
```

## Backend

**`database.py`** mattrum **`models.py`** — [GET](/tanglish/docs/mysql-react/get)-la
paartha same connection, session, `ItemModel` table, inga maaradhu.

**`schemas.py`** — `ItemPatch`, [PUT](/tanglish/docs/mysql-react/put)-oda
`ItemRequest`-oda pakkathula:

```python title="schemas.py"
class ItemPatch(BaseModel):
    value: Optional[str] = None
```

**`crud.py`** — partial-update function:

```python title="crud.py"
def update_item(db: Session, item_id: int, patch: ItemPatch) -> ItemModel | None:
    row = get_item(db, item_id)
    if row is None:
        return None
    if patch.value is not None:
        row.value = patch.value
    db.commit()
    db.refresh(row)
    return row
```

**`main.py`** — route:

```python title="main.py"
@app.patch("/items/{item_id}")
def update_item(item_id: int, patch: ItemPatch, db: Session = Depends(get_db)):
    row = crud.update_item(db, item_id, patch)
    if row is None:
        raise HTTPException(status_code=404, detail="Item not found")
    return {"id": row.id, "value": row.value}
```

## Line by line

`database.py`-oda connection/`get_db()`, `models.py`-oda `ItemModel` —
shared setup, [index page](/tanglish/docs/mysql-react)-la oru thadava
explain pannirukom. Keezha indha page-la pudhusa irukradhu:
`schemas.py`-oda `ItemPatch`, `crud.py`-oda `update_item`, adha call
panra `main.py`-oda route.

1. `db: Session = Depends(get_db)` — indha topic-oda vera ella route
   mathiri same session-per-request pattern: FastAPI adha `get_db()`
   vachi function run aaguradhukku munnadi kudukkum, function mudinja
   appuram automatic-a close pannum, error vandhalum sari.
2. **`update_item` row-ah first-a check pannum** —
   `get_item(db, item_id)` andha ID irundha `ItemModel` object return
   pannum, illa-na `None` return pannum.
   - `main.py`-la, `if row is None: raise
     HTTPException(status_code=404, ...)` response `row`-ah touch
     panna munnadi clean `404`-ah anuppum.
   - `crud.update_item` idha check pannama vittutta, keezha irukra
     `row.value = patch.value` line missing ID-ku `AttributeError:
     'NoneType' object has no attribute 'value'`-ah raise pannum —
     FastAPI adha proper `404`-ku pathila generic `500 Internal Server
     Error`-a maathidum.
3. **`ItemPatch.value` optional** — PUT-oda `ItemRequest`-la
   `value` required, idhu vidhyasam.
4. **`if patch.value is not None: row.value = patch.value`** —
   client real-a oru value anuppina mattum dhan row-ah update
   pannum. [PUT](/tanglish/docs/mysql-react/put)-oda `replace_item`
   mathiri, andha assignment mattum podhum SQLAlchemy notice
   pannradhukku: `row` indha same session-la munnadi `get_item(...)`-la
   irundhu vandhadhu, so adhoda "unit of work" already track
   pannikittu irukku — change-ah register panna `db.add(row)` venaam.
5. **`db.commit()`** — edhavadhu tracked change-ah `UPDATE`
   statement-a flush pannum, transaction-ah commit pannum. Client
   `{}` anuppi, `patch.value` `None`-a irundha, edhuvum assign
   aagalaye, so indha commit-ku pudhusa edhuvum write panna illa —
   harmless no-op.
6. **`db.refresh(row)`** — apparam database-la irundhu `row`-ah
   thirumba query pannudhu, so `main.py` return panra `{"id": row.id,
   "value": row.value}` MySQL-la ippo enna irukko adha exact-a
   reflect pannum, indha request edhavadhu maathi irundhalum
   illainalum.

## Frontend

## Array version-oda same story

```jsx
<button onClick={() => saveEdit(item.id, "PATCH")}>Save (PATCH)</button>
```

[PUT](/tanglish/docs/mysql-react/put)-oda button-oda compare pannunga:

```jsx
<button onClick={() => saveEdit(item.id, "PUT")}>Save (PUT)</button>
```

[React's PATCH](/tanglish/docs/react/patch)-oda exact same
relationship — oru shared `saveEdit` function, oru string argument
HTTP method-ah decide pannum. Array version-ku vidhyasam mattum,
`index`-ku pathila `item.id` first argument-a irukradhu.

## Line by line

1. Inga kooda thani `savePatch` function edhuvum illa — `saveEdit`
   already `method`-ah parameter-a edukkum, array version mathiri dhan.
2. **"Save (PATCH)"** button `saveEdit(item.id, "PATCH")` call
   pannum — same function, same request body, HTTP method string
   mattum vidhyasam. Array version-ku vidhyasam, `item.id`-ah row
   object-la irundhu neraa edukkuradhu, `.map()` loop index-ah anuppa
   pathila.
3. Andha oru string (`"PUT"` vs `"PATCH"`) dhan rendu button-ku
   idaiyila real vidhyasam — component, request body, `saveEdit`-oda
   `fetch` call ellame rendu pakkamum same dhan.
4. Rendu button-um edit mode-la side-by-side irukkum, **"Cancel"**
   button-oda pakkathula — save pannama `editingId`-ah `null`-ku
   reset pannum — array version-oda same layout dhan, `editingIndex`,
   `editingId`-a rename aachu.

Adutha step: [DELETE](/tanglish/docs/mysql-react/delete) — oru row-ah
remove pannurathu, mattrum IDs yeandhukku shift aagadhu.

from dotenv import load_dotenv

load_dotenv()

MYSQL_USER = os.getenv("MYSQL_USER", "root")

MYSQL_DB = os.getenv("MYSQL_DB", "fastapi_learn")

DATABASE_URL = os.getenv(
    "DATABASE_URL",
    f"mysql+pymysql://{MYSQL_USER}:{MYSQL_PASSWORD}@{MYSQL_HOST}:{MYSQL_PORT}/{MYSQL_DB}",
)

engine = create_engine(DATABASE_URL, pool_pre_ping=True)
SessionLocal = sessionmaker(autocommit=False, autoflush=False, bind=engine)
Base = declarative_base()


def get_db():
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()

from database import Base


class ItemModel(Base):

    id = Column(Integer, primary_key=True, autoincrement=True)

```python title="schemas.py"
from typing import Optional

from pydantic import BaseModel


class ItemRequest(BaseModel):
    value: str


class ItemPatch(BaseModel):
    value: Optional[str] = None
```

```python title="crud.py"
from sqlalchemy.orm import Session

from models import ItemModel
from schemas import ItemPatch, ItemRequest


def get_items(db: Session) -> list[ItemModel]:
    return db.query(ItemModel).order_by(ItemModel.id).all()


def get_item(db: Session, item_id: int) -> ItemModel | None:
    return db.get(ItemModel, item_id)


def create_item(db: Session, item: ItemRequest) -> ItemModel:
    row = ItemModel(value=item.value)
    db.add(row)
    db.commit()
    db.refresh(row)
    return row


def replace_item(db: Session, item_id: int, item: ItemRequest) -> ItemModel | None:
    row = get_item(db, item_id)
    if row is None:
        return None
    row.value = item.value
    db.commit()
    db.refresh(row)
    return row


def update_item(db: Session, item_id: int, patch: ItemPatch) -> ItemModel | None:
    row = get_item(db, item_id)
    if row is None:
        return None
    if patch.value is not None:
        row.value = patch.value
    db.commit()
    db.refresh(row)
    return row
```

```python title="main.py"
from fastapi import Depends, FastAPI, HTTPException, status
from fastapi.middleware.cors import CORSMiddleware
from sqlalchemy.orm import Session

import crud
from database import Base, SessionLocal, engine, get_db
from schemas import ItemPatch, ItemRequest

Base.metadata.create_all(bind=engine)

with SessionLocal() as db:
    crud.seed_items(db)

app = FastAPI()

app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:5173", "http://127.0.0.1:5173"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)


@app.get("/items")
def list_items(db: Session = Depends(get_db)):
    return [{"id": row.id, "value": row.value} for row in crud.get_items(db)]


@app.get("/items/{item_id}")
def get_item(item_id: int, db: Session = Depends(get_db)):
    row = crud.get_item(db, item_id)
    if row is None:
        raise HTTPException(status_code=404, detail="Item not found")
    return {"id": row.id, "value": row.value}


@app.post("/items", status_code=status.HTTP_201_CREATED)
def create_item(item: ItemRequest, db: Session = Depends(get_db)):
    row = crud.create_item(db, item)
    return {"id": row.id, "value": row.value}


@app.put("/items/{item_id}")
def replace_item(item_id: int, item: ItemRequest, db: Session = Depends(get_db)):
    row = crud.replace_item(db, item_id, item)
    if row is None:
        raise HTTPException(status_code=404, detail="Item not found")
    return {"id": row.id, "value": row.value}


@app.patch("/items/{item_id}")
def update_item(item_id: int, patch: ItemPatch, db: Session = Depends(get_db)):
    row = crud.update_item(db, item_id, patch)
    if row is None:
        raise HTTPException(status_code=404, detail="Item not found")
    return {"id": row.id, "value": row.value}
```

**Frontend** — `example/7/react/src/App.jsx`, PATCH varaikkum:

```jsx title="example/7/react/src/App.jsx"
import { useEffect, useState } from "react";

const API_URL = "http://127.0.0.1:8000";

export default function App() {
  const [items, setItems] = useState([]);
  const [value, setValue] = useState("");
  const [reached, setReached] = useState(null);
  const [error, setError] = useState(null);

  const [editingId, setEditingId] = useState(null);
  const [editValue, setEditValue] = useState("");

  useEffect(() => {
    loadItems();
  }, []);

  async function loadItems() {
    try {
      const response = await fetch(`${API_URL}/items`);
      if (!response.ok) {
        throw new Error(`Failed to load items (status ${response.status})`);
      }
      setItems(await response.json());
      setError(null);
    } catch (err) {
      setError(err.message);
    }
  }

  async function addItem(event) {
    event.preventDefault();
    if (value.trim() === "") return;

    const response = await fetch(`${API_URL}/items`, {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ value: value }),
    });

    if (!response.ok) {
      setError(`Failed to add item (status ${response.status})`);
      return;
    }

    setValue("");
    await loadItems();
  }

  async function reachItem(id) {
    const response = await fetch(`${API_URL}/items/${id}`);
    if (!response.ok) {
      setError(`Failed to reach id ${id} (status ${response.status})`);
      setReached(null);
      return;
    }
    setReached(await response.json());
    setError(null);
  }

  function startEditing(id, currentValue) {
    setEditingId(id);
    setEditValue(currentValue);
  }

  async function saveEdit(id, method) {
    const response = await fetch(`${API_URL}/items/${id}`, {
      method: method, // "PUT" illana "PATCH"
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ value: editValue }),
    });

    if (!response.ok) {
      setError(`Failed to update item (status ${response.status})`);
      return;
    }

    setEditingId(null);
    await loadItems();
  }

  return (
    <main style={{ maxWidth: 560, margin: "3rem auto", fontFamily: "sans-serif" }}>
      <h1>MySQL Store</h1>

      {error && <p style={{ color: "crimson" }}>{error}</p>}

      <form onSubmit={addItem} style={{ display: "flex", gap: "0.5rem" }}>
        <input
          value={value}
          onChange={(event) => setValue(event.target.value)}
          placeholder="Add a value"
          style={{ flex: 1, padding: "0.5rem" }}
        />
        <button type="submit">Add</button>
      </form>

      <ul style={{ listStyle: "none", padding: 0, marginTop: "1.5rem" }}>
        {items.map((item) =>
          editingId === item.id ? (
            <li
              key={item.id}
              style={{ display: "flex", alignItems: "center", gap: "0.5rem", padding: "0.25rem 0" }}
            >
              <span style={{ color: "#888", width: "2rem" }}>#{item.id}</span>
              <input
                value={editValue}
                onChange={(event) => setEditValue(event.target.value)}
                style={{ flex: 1, padding: "0.25rem" }}
              />
              <button onClick={() => saveEdit(item.id, "PUT")}>Save (PUT)</button>
              <button onClick={() => saveEdit(item.id, "PATCH")}>Save (PATCH)</button>
              <button onClick={() => setEditingId(null)}>Cancel</button>
            </li>
          ) : (
            <li
              key={item.id}
              style={{ display: "flex", alignItems: "center", gap: "0.5rem", padding: "0.25rem 0" }}
            >
              <span style={{ color: "#888", width: "2rem" }}>#{item.id}</span>
              <span style={{ flex: 1 }}>{item.value}</span>
              <button onClick={() => reachItem(item.id)}>Reach</button>
              <button onClick={() => startEditing(item.id, item.value)}>Edit</button>
            </li>
          ),
        )}
      </ul>

      {reached && (
        <p style={{ marginTop: "1rem" }}>
          Reached id <strong>#{reached.id}</strong>: <strong>{reached.value}</strong>
        </p>
      )}
    </main>
  );
}
```

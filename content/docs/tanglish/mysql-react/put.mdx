## Backend

**`database.py`** mattrum **`models.py`** — [GET](/tanglish/docs/mysql-react/get)-la
paartha same connection, session, `ItemModel` table, inga maaradhu.

**`schemas.py`** — `ItemRequest`, [POST](/tanglish/docs/mysql-react/post)
already validate panra same request body; PUT-um adha reuse pannudhu,
oru row-oda value-ah replace panna, create panra shape dhan venum.

**`crud.py`** — replace function:

```python title="crud.py"
def replace_item(db: Session, item_id: int, item: ItemRequest) -> ItemModel | None:
    row = get_item(db, item_id)
    if row is None:
        return None
    row.value = item.value
    db.commit()
    db.refresh(row)
    return row
```

**`main.py`** — route:

```python title="main.py"
@app.put("/items/{item_id}")
def replace_item(item_id: int, item: ItemRequest, db: Session = Depends(get_db)):
    row = crud.replace_item(db, item_id, item)
    if row is None:
        raise HTTPException(status_code=404, detail="Item not found")
    return {"id": row.id, "value": row.value}
```

## Line by line

`database.py`-oda connection/`get_db()`, `models.py`-oda `ItemModel` —
shared setup, [index page](/tanglish/docs/mysql-react)-la oru thadava
explain pannirukom. Keezha indha page-la pudhusa irukradhu:
`crud.py`-oda `replace_item`, adha call panra `main.py`-oda route.

1. `db: Session = Depends(get_db)` — [GET](/tanglish/docs/mysql-react/get)-la
   paartha same dependency injection dhan: FastAPI `get_db()` vachi
   pudhu session-ah indha route run aaguradhukku munnadi open pannum,
   apparam automatic-a close pannum, route success-a irundhalum
   raise pannalum.
2. **`replace_item` row-ah first-a look up pannum** —
   `get_item(db, item_id)` dhan `crud.py`-oda sontha
   `db.get(ItemModel, item_id)` wrapper: andha ID irundha `ItemModel`
   object return pannum, illa-na `None` return pannum, rendu
   case-layum exception edhuvum raise pannama.
   - `main.py`-la, `if row is None: raise
     HTTPException(status_code=404, ...)` andha `None`-ah edhavadhu
     vera onnum run aaguradhukku munnadi clean `404` return pannum.
   - `crud.replace_item` idha check pannama `row.value = item.value`-ku
     neraa poirundha, `row` `None`-a irundhaal Python
     `AttributeError: 'NoneType' object has no attribute 'value'`-ah
     raise pannum — adha FastAPI generic `500 Internal Server
     Error`-a maathidum, clean `404`-ku pathila.
3. **`row.value = item.value`** plain attribute assignment mathiri
   kaamikkum, idhu dhan adhu — aana `row`, indha same session-la
   munnadi `get_item(...)`-la irundhu vandhadhu-nala, SQLAlchemy-oda
   "unit of work" andha object-ah already track pannikittu irukku, so
   change-ah automatic-a pick up pannikum.
   - Session-ku thirumba edhuvum add pannanum illa (`db.add(row)`
     inga venaam) — `create_item`-la irundhu real vidhyasam idhu
     dhan, andha function-la `row` pudhu object, session-ku andha
     object gurichi theriyaadhu.
4. **`db.commit()`** dhan andha tracked in-memory change-ah real
   `UPDATE ... SET value = ... WHERE id = ...` statement-a maathi
   MySQL-ku anuppum — indha line run aaguradhukku munnadi database-ku
   edhuvum pogadhu.
5. **`db.refresh(row)`** apparam database-la irundhu `row`-ah
   thirumba query pannudhu, so `main.py` return panra `{"id": row.id,
   "value": row.value}` MySQL-la ippo enna irukko adha exact-a
   reflect pannum — client anuppina input-ah mattum echo
   pannradhukku pathila.

## Edit mode-ku poradhu, ID vachi

```jsx
function startEditing(id, currentValue) {
  setEditingId(id);
  setEditValue(currentValue);
}
```

**[React's PUT](/tanglish/docs/react/put)-oda vidhyasam:**
`setEditingIndex` → `setEditingId` — [index page](/tanglish/docs/mysql-react)-la
paartha same rename.

## PUT vachi save pannurathu

```jsx
async function saveEdit(id, method) {
  const response = await fetch(`${API_URL}/items/${id}`, {
    method: method, // "PUT" illana "PATCH"
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ value: editValue }),
  });

  if (!response.ok) {
    setError(`Failed to update item (status ${response.status})`);
    return;
  }

  setEditingId(null);
  await loadItems();
}
```

```jsx
<button onClick={() => saveEdit(item.id, "PUT")}>Save (PUT)</button>
```

Array version-oda same function, same idea — `index` engum `id`-a
maari, vera edhuvum maaradhu.

## Line by line

1. `startEditing(id, currentValue)` — `setEditingIndex`,
   `setEditingId`-a rename aagirukku, position-ku pathila database id
   store pannudhu.
2. `saveEdit(id, method)` — array version-oda same function shape,
   `index`-ku pathila `id` vachi address panni.
3. **"Save (PUT)"** button ippo `saveEdit(item.id, "PUT")` call
   pannum — loop index-ku pathila item object-la irundhu `id` edukkum.

Adutha step: [PATCH](/tanglish/docs/mysql-react/patch) — same
function, vera verb-oda call pannudhu.

```python title="database.py"
import os

from dotenv import load_dotenv
from sqlalchemy import create_engine
from sqlalchemy.orm import Session, declarative_base, sessionmaker

load_dotenv()

MYSQL_HOST = os.getenv("MYSQL_HOST", "127.0.0.1")
MYSQL_PORT = os.getenv("MYSQL_PORT", "3306")
MYSQL_USER = os.getenv("MYSQL_USER", "root")
MYSQL_PASSWORD = os.getenv("MYSQL_PASSWORD", "")
MYSQL_DB = os.getenv("MYSQL_DB", "fastapi_learn")

DATABASE_URL = os.getenv(
    "DATABASE_URL",
    f"mysql+pymysql://{MYSQL_USER}:{MYSQL_PASSWORD}@{MYSQL_HOST}:{MYSQL_PORT}/{MYSQL_DB}",
)

engine = create_engine(DATABASE_URL, pool_pre_ping=True)
SessionLocal = sessionmaker(autocommit=False, autoflush=False, bind=engine)
Base = declarative_base()


def get_db():
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()
```

```python title="models.py"
from sqlalchemy import Column, Integer, String

from database import Base


class ItemModel(Base):
    __tablename__ = "crud_react_items"

    id = Column(Integer, primary_key=True, autoincrement=True)
    value = Column(String(255), nullable=False)
```

```python title="schemas.py"
from pydantic import BaseModel


class ItemRequest(BaseModel):
    value: str
```

```python title="crud.py"
from sqlalchemy.orm import Session

from models import ItemModel
from schemas import ItemRequest


def get_items(db: Session) -> list[ItemModel]:
    return db.query(ItemModel).order_by(ItemModel.id).all()


def get_item(db: Session, item_id: int) -> ItemModel | None:
    return db.get(ItemModel, item_id)


def create_item(db: Session, item: ItemRequest) -> ItemModel:
    row = ItemModel(value=item.value)
    db.add(row)
    db.commit()
    db.refresh(row)
    return row


def replace_item(db: Session, item_id: int, item: ItemRequest) -> ItemModel | None:
    row = get_item(db, item_id)
    if row is None:
        return None
    row.value = item.value
    db.commit()
    db.refresh(row)
    return row
```

```python title="main.py"
from fastapi import Depends, FastAPI, HTTPException, status
from fastapi.middleware.cors import CORSMiddleware
from sqlalchemy.orm import Session

import crud
from database import Base, SessionLocal, engine, get_db
from schemas import ItemRequest

Base.metadata.create_all(bind=engine)

with SessionLocal() as db:
    crud.seed_items(db)

app = FastAPI()

app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:5173", "http://127.0.0.1:5173"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)


@app.get("/items")
def list_items(db: Session = Depends(get_db)):
    return [{"id": row.id, "value": row.value} for row in crud.get_items(db)]


@app.get("/items/{item_id}")
def get_item(item_id: int, db: Session = Depends(get_db)):
    row = crud.get_item(db, item_id)
    if row is None:
        raise HTTPException(status_code=404, detail="Item not found")
    return {"id": row.id, "value": row.value}


@app.post("/items", status_code=status.HTTP_201_CREATED)
def create_item(item: ItemRequest, db: Session = Depends(get_db)):
    row = crud.create_item(db, item)
    return {"id": row.id, "value": row.value}


@app.put("/items/{item_id}")
def replace_item(item_id: int, item: ItemRequest, db: Session = Depends(get_db)):
    row = crud.replace_item(db, item_id, item)
    if row is None:
        raise HTTPException(status_code=404, detail="Item not found")
    return {"id": row.id, "value": row.value}
```

**Frontend** — `example/7/react/src/App.jsx`, PUT varaikkum:

```jsx title="example/7/react/src/App.jsx"
import { useEffect, useState } from "react";

const API_URL = "http://127.0.0.1:8000";

export default function App() {
  const [items, setItems] = useState([]);
  const [value, setValue] = useState("");
  const [reached, setReached] = useState(null);
  const [error, setError] = useState(null);

  const [editingId, setEditingId] = useState(null);
  const [editValue, setEditValue] = useState("");

  useEffect(() => {
    loadItems();
  }, []);

  async function loadItems() {
    try {
      const response = await fetch(`${API_URL}/items`);
      if (!response.ok) {
        throw new Error(`Failed to load items (status ${response.status})`);
      }
      setItems(await response.json());
      setError(null);
    } catch (err) {
      setError(err.message);
    }
  }

  async function addItem(event) {
    event.preventDefault();
    if (value.trim() === "") return;

    const response = await fetch(`${API_URL}/items`, {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ value: value }),
    });

    if (!response.ok) {
      setError(`Failed to add item (status ${response.status})`);
      return;
    }

    setValue("");
    await loadItems();
  }

  async function reachItem(id) {
    const response = await fetch(`${API_URL}/items/${id}`);
    if (!response.ok) {
      setError(`Failed to reach id ${id} (status ${response.status})`);
      setReached(null);
      return;
    }
    setReached(await response.json());
    setError(null);
  }

  function startEditing(id, currentValue) {
    setEditingId(id);
    setEditValue(currentValue);
  }

  async function saveEdit(id, method) {
    const response = await fetch(`${API_URL}/items/${id}`, {
      method: method,
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ value: editValue }),
    });

    if (!response.ok) {
      setError(`Failed to update item (status ${response.status})`);
      return;
    }

    setEditingId(null);
    await loadItems();
  }

  return (
    <main style={{ maxWidth: 560, margin: "3rem auto", fontFamily: "sans-serif" }}>
      <h1>MySQL Store</h1>

      {error && <p style={{ color: "crimson" }}>{error}</p>}

      <form onSubmit={addItem} style={{ display: "flex", gap: "0.5rem" }}>
        <input
          value={value}
          onChange={(event) => setValue(event.target.value)}
          placeholder="Add a value"
          style={{ flex: 1, padding: "0.5rem" }}
        />
        <button type="submit">Add</button>
      </form>

      <ul style={{ listStyle: "none", padding: 0, marginTop: "1.5rem" }}>
        {items.map((item) =>
          editingId === item.id ? (
            <li
              key={item.id}
              style={{ display: "flex", alignItems: "center", gap: "0.5rem", padding: "0.25rem 0" }}
            >
              <span style={{ color: "#888", width: "2rem" }}>#{item.id}</span>
              <input
                value={editValue}
                onChange={(event) => setEditValue(event.target.value)}
                style={{ flex: 1, padding: "0.25rem" }}
              />
              <button onClick={() => saveEdit(item.id, "PUT")}>Save (PUT)</button>
              <button onClick={() => setEditingId(null)}>Cancel</button>
            </li>
          ) : (
            <li
              key={item.id}
              style={{ display: "flex", alignItems: "center", gap: "0.5rem", padding: "0.25rem 0" }}
            >
              <span style={{ color: "#888", width: "2rem" }}>#{item.id}</span>
              <span style={{ flex: 1 }}>{item.value}</span>
              <button onClick={() => reachItem(item.id)}>Reach</button>
              <button onClick={() => startEditing(item.id, item.value)}>Edit</button>
            </li>
          ),
        )}
      </ul>

      {reached && (
        <p style={{ marginTop: "1rem" }}>
          Reached id <strong>#{reached.id}</strong>: <strong>{reached.value}</strong>
        </p>
      )}
    </main>
  );
}
```

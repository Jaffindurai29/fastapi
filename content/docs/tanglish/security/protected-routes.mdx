<GithubLink path="example/12/c" />

[JWT login](/tanglish/docs/security/jwt-login)-la vandha token-ah use
panrom. Oru dependency, `get_current_active_user`,
`Authorization: Bearer ...` header-ah read panni, token-ah verify panni,
user-ah load pannum. Adha kekra endha route-um lock aagidum: token
illana, garbage token-na, expired token-na `401`, deactivated
account-na `403`. Compare panna `/public` open-a irukkum.

| Route | Description |
|---|---|
| `POST /token` | Form login → access token (15 min); thappu-na `401` |
| `GET /public` | Token venaam |
| `GET /users/me` | Login aana user; valid token illana `401`, deactivated-na `403` |
| `GET /items` | Demo item list; `/users/me`-oda same rules |

Table: `sec_users`, 12/b, 12/d, 12/i-oda share aagudhu. Seeded users:
`alice`, `bob`, `admin` (password `<name>-password`), mattrum `carol` /
`carol-password`, ava deactivated.

## Code

`config.py`, `database.py`, `models.py`, `schemas.py`, `security.py`,
`crud.py` ellam [JWT login](/tanglish/docs/security/jwt-login)-la
irukra adhe dhan; page thaniya puriyanum-nu ellathaiyum inga
pottirukkom. Pudhu file `dependencies.py`.

**`security.py`:**

```python title="security.py"
from datetime import datetime, timedelta, timezone

import jwt
from pwdlib import PasswordHash

from config import ACCESS_TOKEN_EXPIRE_MINUTES, ALGORITHM, SECRET_KEY

# Argon2, exactly as in 12/a.
password_hash = PasswordHash.recommended()


def hash_password(password: str) -> str:
    return password_hash.hash(password)


def verify_password(password: str, hashed: str) -> bool:
    return password_hash.verify(password, hashed)


def create_access_token(username: str, expires_delta: timedelta | None = None) -> str:
    if expires_delta is None:
        expires_delta = timedelta(minutes=ACCESS_TOKEN_EXPIRE_MINUTES)
    payload = {
        "sub": username,  # who the token is about (the "subject")
        "exp": datetime.now(timezone.utc) + expires_delta,  # stored as a Unix timestamp
        "type": "access",
    }
    return jwt.encode(payload, SECRET_KEY, algorithm=ALGORITHM)


def decode_token(token: str) -> dict:
    # Checks the signature AND the exp claim. Raises jwt.InvalidTokenError
    # (or its subclass jwt.ExpiredSignatureError) if either fails.
    # algorithms= is a whitelist: never let the token pick its own.
    return jwt.decode(token, SECRET_KEY, algorithms=[ALGORITHM])
```

**`crud.py`:**

```python title="crud.py"
from sqlalchemy.orm import Session

from models import UserModel
from security import hash_password, verify_password


def get_user_by_username(db: Session, username: str) -> UserModel | None:
    return db.query(UserModel).filter(UserModel.username == username).first()


def authenticate(db: Session, username: str, password: str) -> UserModel | None:
    user = get_user_by_username(db, username)
    if user is None or not verify_password(password, user.hashed_password):
        return None
    return user


def seed_users(db: Session) -> None:
    if db.query(UserModel).count() == 0:
        db.add_all(
            [
                UserModel(username="alice", hashed_password=hash_password("alice-password")),
                UserModel(username="bob", hashed_password=hash_password("bob-password")),
                UserModel(username="admin", hashed_password=hash_password("admin-password")),
                # Deactivated account: can log in, but the protected
                # routes from 12/c on turn it away with 403.
                UserModel(username="carol", hashed_password=hash_password("carol-password"), is_active=False),
            ]
        )
        db.commit()
```

**`dependencies.py`** — lock:

```python title="dependencies.py"
import jwt
from fastapi import Depends, HTTPException, status
from fastapi.security import OAuth2PasswordBearer
from sqlalchemy.orm import Session

import crud
from database import get_db
from models import UserModel
from security import decode_token

# Reads "Authorization: Bearer <token>" and hands the <token> part to
# the route. No header at all -> 401 "Not authenticated" automatically.
# tokenUrl tells /docs where the "Authorize" button should log in.
oauth2_scheme = OAuth2PasswordBearer(tokenUrl="token")


def credentials_error(detail: str = "Could not validate credentials") -> HTTPException:
    return HTTPException(
        status_code=status.HTTP_401_UNAUTHORIZED,
        detail=detail,
        headers={"WWW-Authenticate": "Bearer"},
    )


def get_current_user(token: str = Depends(oauth2_scheme), db: Session = Depends(get_db)) -> UserModel:
    try:
        payload = decode_token(token)
    except jwt.ExpiredSignatureError:  # subclass, so it must come first
        raise credentials_error("Token has expired")
    except jwt.InvalidTokenError:  # bad signature, garbage, wrong algorithm...
        raise credentials_error()

    if payload.get("type") != "access":
        raise credentials_error()

    username = payload.get("sub")
    user = crud.get_user_by_username(db, username) if username else None
    if user is None:  # valid token, but the account was deleted since
        raise credentials_error()
    return user


# Builds on get_current_user: authenticated AND allowed in.
def get_current_active_user(user: UserModel = Depends(get_current_user)) -> UserModel:
    if not user.is_active:
        # 403, not 401: we know exactly who this is, and the answer is no.
        raise HTTPException(status_code=status.HTTP_403_FORBIDDEN, detail="Inactive user")
    return user
```

**`main.py`** — oru open route, rendu locked routes:

```python title="main.py"
from fastapi import Depends, FastAPI, HTTPException, status
from fastapi.security import OAuth2PasswordRequestForm
from sqlalchemy.orm import Session

import crud
from database import Base, SessionLocal, engine, get_db
from dependencies import get_current_active_user
from models import UserModel
from schemas import Token, UserOut
from security import create_access_token

Base.metadata.create_all(bind=engine)

with SessionLocal() as db:
    crud.seed_users(db)

app = FastAPI()

# Demo data, kept in memory: this lesson is about the lock, not the data.
ITEMS = [
    {"id": 1, "name": "Laptop"},
    {"id": 2, "name": "Mouse"},
    {"id": 3, "name": "Monitor"},
]

AUTH_ERRORS = {
    401: {"description": "Missing, invalid or expired token"},
    403: {"description": "Inactive user"},
}


@app.post("/token", response_model=Token,
          responses={401: {"description": "Incorrect username or password"}})
def login(form_data: OAuth2PasswordRequestForm = Depends(), db: Session = Depends(get_db)):
    user = crud.authenticate(db, form_data.username, form_data.password)
    if user is None:
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED,
            detail="Incorrect username or password",
            headers={"WWW-Authenticate": "Bearer"},
        )
    return {"access_token": create_access_token(user.username), "token_type": "bearer"}


# No dependency: anyone can call it.
@app.get("/public")
def public():
    return {"message": "Anyone can see this"}


# The route never touches the token. If the dependency returns, the
# user is real, active, and their token is valid.
@app.get("/users/me", response_model=UserOut, responses=AUTH_ERRORS)
def read_me(current_user: UserModel = Depends(get_current_active_user)):
    return current_user


@app.get("/items", responses=AUTH_ERRORS)
def list_items(current_user: UserModel = Depends(get_current_active_user)):
    return ITEMS
```

## Line by line

**Client token-ah eppadi anuppudhu:**

1. Locked route-ku pogra ovoru request-um oru header carry pannum:

   ```
   Authorization: Bearer eyJhbGciOiJIUzI1NiIs...
   ```

   "Bearer" na "indha token-ah vachirukra (bear panra) yaar-a irundhaalum
   ulla vidu" — adhanaala dhan thirudina token, expire aagura varaikkum
   thirudina password-ku samam.

**`dependencies.py`:**

2. `oauth2_scheme = OAuth2PasswordBearer(tokenUrl="token")` — dependency-a
   use pannumbodhu, `Bearer `-ku appuram irukra part-ah return pannum.
   Header missing-na (illa `Basic` maadhiri vera scheme-na), unga code
   run aaguradhukku munnadiye thaanaave `401 Not authenticated` sollum.
   `tokenUrl="token"` edhaiyum check pannadhu; **Authorize** button
   username, password-ah enga anuppanum-nu `/docs`-ku solludhu.
   Adhanaala dhan login `POST /token`-la oru OAuth2 form-a irukkanum.
3. `credentials_error(...)` — `WWW-Authenticate: Bearer`-oda `401`-ah
   build panra chinna helper; `401`-oda HTTP spec ethirpaakra header
   adhu. Oru idam, so ella failure-um same maadhiri irukkum.
4. `get_current_user` — token-la irundhu user row varaikkum, order-la
   naalu checks:
   - **Signature + expiry**: last page-oda `decode_token`.
     `jwt.ExpiredSignatureError` `jwt.InvalidTokenError`-oda *subclass*,
     so adha **first** catch pannanum — general `except` first vandha,
     expired case-aiyum adhe vizhungidum.
   - **Type**: `"access"` tokens mattum dhan kadhava thirakkum. Adutha
     page-la oru long-lived refresh token inga work aaga koodadhu.
   - **`sub`**: oru token perfect-a sign aagirundhaalum, ippo illadha
     oru user-ah (login-ku appuram delete aanavar) name pannalaam.
   - Database-la irundhu **user-ah load** pannum, so routes-ku token-la
     irukra stale copy illa, fresh data-oda real row kidaikkum.

   Ella failure-um same `401`. Token *yen* bad-nu solradhu users-ah
   vida attackers-ku dhan adhigama help pannum, so distinct message
   `"Token has expired"` mattum dhan — adhu honest client-ku "thirumba
   login pannu" nu sollum.
5. `get_current_active_user` — oru dependency mela innoru dependency.
   Adhu `get_current_user`-ah kekkudhu, so FastAPI adha first run
   pannum; adhu return aana user real, apparam idhu `is_active` check
   pannum.

**401 vs 403:**

6. `401 Unauthorized` real-a *unauthenticated* nu artham: "neenga
   yaaru-nu theriyala, valid credentials anuppunga". `403 Forbidden` na
   "neenga yaaru-nu theriyum, aana allowed illa". `carol`-oda token
   perfect-a valid — ava yaaru-nu exact-a theriyum — so thirumba login
   pannaalum help aagadhu. Adhu `403`. (Official FastAPI tutorial inga
   `400` use pannudhu; `403` innum precise.) Check-ah rendu
   dependencies-a pirichadhaala, deactivated users-ah accept panna
   vendiya oru route ("en account-ah reactivate pannu" maadhiri)
   `get_current_user`-ah depend pannikkalaam.

**`main.py`:**

7. Oru route-ah lock panna oru parameter podhum:
   `current_user: UserModel = Depends(get_current_active_user)`.
   Dependency raise pannina, route body run-e aagadhu. Return pannina,
   `current_user` valid token-oda oru real, active user.
8. `list_items` `current_user`-ah use kooda pannala — kettaale route
   lock aagidum. `/public`-ku andha parameter illa, so open-a irukkum.
9. `response_model=UserOut` `/users/me`-la irundhu `hashed_password`-ah
   veliya vidaadhu, [Password hashing](/tanglish/docs/security/password-hashing)-la
   maadhiri.
10. `AUTH_ERRORS` — documentation mattum dhan: indha routes-ku `/docs`-la
    `401`, `403`-ah list pannum.
11. **Yen `/users/me`, `/users/{user_id}` illa.** Neenga yaaru-nu token
    already solludhu. `/users/{user_id}` route-na id token-oda match
    aagudha-nu check pannanum, andha check-ah marakradhu oru classic bug
    (login aana endha user-um yaaroda data-vaiyum read pannalaam —
    [Authorization by ownership](/tanglish/docs/security/ownership)
    paarunga). "Naan" aa act panra routes user-ah token-la irundhu
    edukkanum, URL-la irundhu eppovum illa.
12. **Failure paths-ah test panradhu.** `create_access_token`
    `expires_delta` edukkum, so oru test already expire aana token-ah
    mint pannalaam:

    ```python
    expired = security.create_access_token("alice", timedelta(minutes=-1))
    c.get("/users/me", headers={"Authorization": f"Bearer {expired}"})  # 401 Token has expired
    ```

13. **Enna missing: logged in-a irukradhu.** 15 nimishathukku appuram
    token saagum, user thirumba password type pannanum. Token-ah oru
    vaaram vaazha vechaa adhu fix aagum, aana thirudina token-um oru
    vaaram work aagum. Adutha page oru rendaavadhu, long-lived refresh
    token vachi idha solve pannum.

## Try it

Login pannunga, apparam response-la irundhu `access_token`-ah copy panni
adutha commands-la podunga:

```bash
curl -X POST http://127.0.0.1:8000/token -d "username=alice&password=alice-password"
curl http://127.0.0.1:8000/users/me -H "Authorization: Bearer <paste token>"
curl http://127.0.0.1:8000/items -H "Authorization: Bearer <paste token>"
curl http://127.0.0.1:8000/public
```

Fail aagura vazhigal:

```bash
curl -i http://127.0.0.1:8000/users/me  # 401 Not authenticated
curl -i http://127.0.0.1:8000/users/me -H "Authorization: Bearer garbage"  # 401 Could not validate credentials
curl -X POST http://127.0.0.1:8000/token -d "username=carol&password=carol-password"
curl -i http://127.0.0.1:8000/users/me -H "Authorization: Bearer <paste carol token>"  # 403 Inactive user
```

| Neenga anuppradhu | Status | `detail` |
|---|---|---|
| `Authorization` header illa | `401` | `Not authenticated` |
| Valid illadha token (garbage, edit pannadhu, wrong key) | `401` | `Could not validate credentials` |
| Expired token | `401` | `Token has expired` |
| `carol`-ku (deactivated) valid token | `403` | `Inactive user` |

**Idhaiyum try pannunga:** 15 nimisham wait pannaama expired token
paakka, `.env`-la `ACCESS_TOKEN_EXPIRE_MINUTES=1` pottu, restart panni,
login panni, oru nimisham wait panni, `/users/me`-ah thirumba call
pannunga.

**/docs:** **Authorize** (top right) click panni, `alice` /
`alice-password` podunga, ippo lock aana ovoru route-um (padlock-oda)
token-ah ungalukkaaga anuppum. Adhe dialog-la **Logout** click panni
token illama try pannunga.

Adutha step: [Refresh tokens](/tanglish/docs/security/refresh-tokens) —
long-lived access tokens illama logged in-a irukradhu.

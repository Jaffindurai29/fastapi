`/items/1`, `/items/2`, `/items/3` maadhiri URLs, ungakitta evlo rows
irukku nu ulagathukke solludhu, adutha number-ah try panna
koopidudhu. Inga database innum plain integer ids dhan use pannudhu,
aana API eppovum `igPHZLIU` maadhiri chinna, non-sequential **public
id**-ah mattum dhan kaattum, [sqids](https://sqids.org/python) vachi
panninadhu. `/items/1` ippo `404`. Indha lesson-la login illa.

## `/items/1`-la enna problem?

Sequential ids information leak pannum:

- **Counting.** Sign up panni, oru item create panni, id `5231`
  kidaichaa: site-la kitta 5,000 items irukku. Adutha maasam
  thirumba pannina adhoda growth rate theriyum. Competitors-ku idhu
  romba pidikkum.
- **Enumeration.** `/items/41` irundha, `40`-um `42`-um irukku. 1 to
  100,000 oru loop pottaa ellathaiyum scrape pannidalaam.

Sqids ovoru integer-ayum random-a *theriyura* oru chinna string-a
maathum: 1 → `igPHZLIU`, 2 → `uclL2dH9`. Database adhoda fast integer
primary key-ah vachukkum. API-la id eppadi theriyudhu nu mattum dhan
maarudhu.

**`database.py`** — env vars, `engine`/`SessionLocal`/`Base`, mattrum `get_db()`:

```python title="database.py"
import os

from dotenv import load_dotenv
from sqlalchemy import create_engine
from sqlalchemy.orm import Session, declarative_base, sessionmaker

load_dotenv()

MYSQL_HOST = os.getenv("MYSQL_HOST", "127.0.0.1")
MYSQL_PORT = os.getenv("MYSQL_PORT", "3306")
MYSQL_USER = os.getenv("MYSQL_USER", "root")
MYSQL_PASSWORD = os.getenv("MYSQL_PASSWORD", "")
MYSQL_DB = os.getenv("MYSQL_DB", "fastapi_learn")

# Set DATABASE_URL directly to override everything above (e.g. to point
# at SQLite for a quick local test with no MySQL server at all).
DATABASE_URL = os.getenv(
    "DATABASE_URL",
    f"mysql+pymysql://{MYSQL_USER}:{MYSQL_PASSWORD}@{MYSQL_HOST}:{MYSQL_PORT}/{MYSQL_DB}",
)

engine = create_engine(DATABASE_URL, pool_pre_ping=True)
SessionLocal = sessionmaker(autocommit=False, autoflush=False, bind=engine)
Base = declarative_base()


def get_db():
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()
```

**`ids.py`** — `encode_id()` mattrum `decode_id()`:

```python title="ids.py"
from sqids import Sqids

from config import SQIDS_ALPHABET, SQIDS_MIN_LENGTH

sqids = Sqids(alphabet=SQIDS_ALPHABET, min_length=SQIDS_MIN_LENGTH)


def encode_id(n: int) -> str:
    """Database id (int) -> public id (str), e.g. 1 -> 'igPHZLIU'."""
    return sqids.encode([n])


def decode_id(public_id: str) -> int | None:
    """Public id -> database id, or None if it isn't one we'd ever hand out."""
    numbers = sqids.decode(public_id)  # [] for characters not in the alphabet
    if len(numbers) != 1:  # garbage, or several numbers packed into one id
        return None
    # sqids can decode several different strings to the same number. Only
    # accept the one string encode_id would produce, so every row has
    # exactly ONE valid public id.
    if encode_id(numbers[0]) != public_id:
        return None
    return numbers[0]
```

**`models.py`** — innum plain auto-increment integer primary key dhan:

```python title="models.py"
from sqlalchemy import Column, Float, Integer, String

from database import Base


class ItemModel(Base):
    __tablename__ = "public_id_items"

    # Still a plain auto-increment integer. Public ids are computed from
    # it on the way out; nothing extra is stored.
    id = Column(Integer, primary_key=True, autoincrement=True)
    name = Column(String(50), nullable=False)
    price = Column(Float, nullable=False)
```

**`schemas.py`** — `ItemOut.id` oru `str`, `from_row()` build pannudhu:

```python title="schemas.py"
from pydantic import BaseModel, Field

from ids import encode_id
from models import ItemModel


class ItemCreate(BaseModel):
    name: str = Field(min_length=1, max_length=50)
    price: float = Field(gt=0)


class ItemOut(BaseModel):
    id: str  # the PUBLIC id, never the database integer
    name: str
    price: float

    # Built explicitly instead of from_attributes: row.id is an int and
    # must be encoded first. One obvious place where that happens.
    @classmethod
    def from_row(cls, row: ItemModel) -> "ItemOut":
        return cls(id=encode_id(row.id), name=row.name, price=row.price)
```

**`crud.py`** — real integer ids-ah mattum dhan paarkum:

```python title="crud.py"
from sqlalchemy.orm import Session

from models import ItemModel
from schemas import ItemCreate


# crud.py only ever deals with real integer ids. Encoding/decoding
# public ids is the route's job (main.py).

def get_items(db: Session) -> list[ItemModel]:
    return db.query(ItemModel).order_by(ItemModel.id).all()


def get_item(db: Session, item_id: int) -> ItemModel | None:
    return db.get(ItemModel, item_id)


def create_item(db: Session, item: ItemCreate) -> ItemModel:
    row = ItemModel(**item.model_dump())
    db.add(row)
    db.commit()
    db.refresh(row)
    return row


def delete_item(db: Session, row: ItemModel) -> None:
    db.delete(row)
    db.commit()


def seed_items(db: Session) -> None:
    if db.query(ItemModel).count() == 0:
        db.add_all(
            [
                ItemModel(name="Laptop", price=999.99),
                ItemModel(name="Mouse", price=19.99),
                ItemModel(name="Keyboard", price=49.5),
            ]
        )
        db.commit()
```

**`main.py`** — edge-la decode pannudhu, thappaana edhukkum `404`:

```python title="main.py"
from fastapi import Depends, FastAPI, HTTPException, status
from sqlalchemy.orm import Session

import crud
from database import Base, SessionLocal, engine, get_db
from ids import decode_id
from models import ItemModel
from schemas import ItemCreate, ItemOut

Base.metadata.create_all(bind=engine)

with SessionLocal() as db:
    crud.seed_items(db)

app = FastAPI()

NOT_FOUND = {404: {"description": "Item not found"}}


# public id -> row, or 404. An invalid public id and an unknown one get
# the SAME answer, so the client can't tell which it was.
def get_item_or_404(db: Session, public_id: str) -> ItemModel:
    item_id = decode_id(public_id)
    row = crud.get_item(db, item_id) if item_id is not None else None
    if row is None:
        raise HTTPException(status_code=404, detail="Item not found")
    return row


@app.get("/items", response_model=list[ItemOut])
def list_items(db: Session = Depends(get_db)):
    return [ItemOut.from_row(row) for row in crud.get_items(db)]


# public_id: str, not int. "/items/1" is now just an unknown string -> 404.
@app.get("/items/{public_id}", response_model=ItemOut, responses=NOT_FOUND)
def get_item(public_id: str, db: Session = Depends(get_db)):
    return ItemOut.from_row(get_item_or_404(db, public_id))


@app.post("/items", response_model=ItemOut, status_code=status.HTTP_201_CREATED)
def create_item(item: ItemCreate, db: Session = Depends(get_db)):
    return ItemOut.from_row(crud.create_item(db, item))


@app.delete("/items/{public_id}", status_code=status.HTTP_204_NO_CONTENT, responses=NOT_FOUND)
def delete_item(public_id: str, db: Session = Depends(get_db)):
    crud.delete_item(db, get_item_or_404(db, public_id))
```

## Line by line

**`config.py` — alphabet oru salt maadhiri work pannum:**

1. **`SQIDS_ALPHABET`** — a-z, A-Z, 0-9 nu 62 characters, shuffle
   panna order-la. Sqids-oda default alphabet-na, yaar venaalum oru
   line Python-la unga ids-ah decode pannidalaam. Shuffle panna alphabet
   andha mapping-ah ungaludhaa aakkum. Aanaalum idhu obscurity mattum
   dhan, real secret illa (step 9 paarunga).
2. **Oru thadava mattum pick pannunga.** Alphabet-ah maathina ella
   public id-um maarum, so bookmark panna illa share panna ella link-um
   break aagum. Launch-ku munnadi ungaludhu generate pannunga:
   `python -c "import random,string; a=list(string.ascii_letters+string.digits); random.shuffle(a); print(''.join(a))"`.
3. **`SQIDS_MIN_LENGTH = 8`** — chinna numbers-ah pad pannudhu, so
   first rows 1-2 character ids-oda thani-a theriyaadhu.

**`ids.py`:**

4. **`encode_id(n)`** — sqids numbers-oda oru *list*-ah oru string-a
   encode pannum; naama eppovum onnu dhan anuppurom. Edhuvum store
   aagala: public id ovoru thadavaiyum integer-la irundhu thirumba
   calculate aagudhu, so existing rows-ku free-a kidaikkum, sync-la
   vekka extra column-um illa.
5. **`decode_id(public_id)`** integer-ah return pannum, illa naama
   kudukkaadha edhukkum `None`:
   - Alphabet-la illaadha characters-ku `sqids.decode()` `[]` return
     pannum, string-la onnukku mela numbers pack aagirundha pala numbers
     return pannum. `len(numbers) != 1` rendaiyum reject pannudhu.
   - **Re-encode check mukkiyam.** Default alphabet-la `igPHZLIU`,
     `igPHZLI`, `ig` kooda — **ellame** `1`-a decode aagum. Check
     illana, oru row-ku pala valid URLs irukkum: caches-um "indha id-ah
     munnadi paathirukkena?" logic-um confuse aagum, attacker-ku
     encoding-ah probe panna vazhi-um kidaikkum. Number-ah thirumba
     encode panni input-oda compare pannradhu, ovoru row-kum exact-a
     oru canonical id mattum irukka vaikkum.

**`schemas.py`:**

6. **`id: str`** — public id, eppovum database integer illa.
7. **`from_attributes=True`-ku pathila `from_row()`.** `from_attributes`
   `row.id`-ah (oru int) `id: str`-la copy panni fail aagum. Pydantic-la
   vera options irukku (`@field_serializer("id")` illa
   `@computed_field`), aana adhu conversion-ah model-kulla
   maraichidum. Oru explicit `from_row` adha obvious-a vaikkum:
   **ovoru** response-um adhu vazhiya dhan pogum, so integer accident-a
   kooda leak aagaadhu.

**`crud.py` mattrum `main.py`:**

8. **`crud.py` public id-ah paakkave paakkaadhu.** Adhu integers-oda
   mattum dhan work pannum; conversion routes-la mattum, app-oda
   edge-la dhan nadakkum.
9. **`get_item_or_404(db, public_id)`** — decode, apparam look up.
   Path parameter `public_id: str`, `int` illa, so `/items/1` ippo
   `422` illa: adhu valid public id illaadha oru string, so `404`.
   Invalid id-kum valid-aa irundhu delete aana id-kum **same**
   `404 Item not found` dhan, so andha difference-la irundhu client
   edhuvum kathukka mudiyaadhu.
10. **Ovoru route-um `ItemOut.from_row(...)` return pannudhu** — list,
    get one, create. `DELETE` body illama `204` return pannum, so encode
    panna edhuvum illa.

## Sqids enna ILLA

- **Encryption illa.** Ids design-laye reversible, unga alphabet-ah
  (adhu unga code-layum `.env`-layum irukku) therinjukkura yaar venaalum
  decode pannalam. Adhula secrets podaadheenga, guess panna mudiyaadhu
  nu nambaadheenga.
- **Access control illa.** Bob-oda note-oda id therinjaale Alice adha
  paakka mudiyum-na, id-ah maraikkradhu aval-ah konjam slow mattum dhan
  pannum. Ovoru route-layum [Ownership](/tanglish/docs/security/ownership)-la
  irukra ownership check innum venum. Public ids leak aagradha
  kuraikkum; yaarukku allowed nu adhu decide pannaadhu.

## Alternatives

| | Pros | Cons |
|---|---|---|
| **Sqids** (indha page) | Chinna, URL-friendly, extra column illa, integer PK appadiye | Obscurity mattum, alphabet eppovum maara koodadhu |
| **UUID4** column (`uuid.uuid4()`) | Real-a random, secret-a vekka edhuvum illa | 36 chars, innoru indexed column (illa periya, slow PK) |
| **UUID7** | Random **and** time-ordered, nalla index aagum | Create aana time-ah reveal pannum, innum neelam |
| Random token column (`secrets.token_urlsafe(8)`) | Chinna, real-a random | Store pannanum, (rare) collisions handle pannanum |

Ids thaane guess panna mudiyaadha-a irukkanum-na (e.g. "link irukra
yaar venaalum paakkalam") UUID use pannunga. Row counts-um sequences-um
advertise panna vendaam nu mattum-na sqids use pannunga.

## Routes

| Route | Description |
|---|---|
| `GET /items` | Ella items-um, ovonnum adhoda public `id`-oda |
| `GET /items/{public_id}` | Oru item; id invalid **illa** unknown-na `404` |
| `POST /items` | `name` mattrum `price` oda body; `201`, pudhu public id return pannum |
| `DELETE /items/{public_id}` | `204`; invalid illa unknown-na `404` |

`config.py`-la irukra default alphabet-la, seed aana items-ku indha ids
kidaikkum (neenga ungaludhu `SQIDS_ALPHABET` set pannirundha vera
maadhiri irukkum, so `GET /items`-la irundhu copy pannunga):

| Database id | Public id |
|---|---|
| 1 | `igPHZLIU` |
| 2 | `uclL2dH9` |
| 3 | `z67LIUj6` |

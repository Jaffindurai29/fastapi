## Pydantic vachu data shape define pannurathu

Request **body** nu solradhu client anuppura data (usually JSON). Idha
declare panna, Pydantic-oda `BaseModel`-la irundhu oru class create
pannunga:

```python
from fastapi import FastAPI
from pydantic import BaseModel

class Item(BaseModel):
    name: str
    description: str | None = None
    price: float
    tax: float | None = None

app = FastAPI()

@app.post("/items")
def create_item(item: Item):
    return item
```

FastAPI enna pannum:

1. Request body-ah JSON-a read pannum.
2. Matching types-ku convert pannum (validate pannikittu).
3. `item` parameter-a data-ah full-a typed-a tharum.
4. `Item`-ku JSON Schema generate panni, interactive docs-la kaamikkum.

## Parse aana model use pannurathu

`item` real Pydantic instance nala, attribute access mattrum autocomplete
free-a kidaikkum:

```python
@app.post("/items")
def create_item(item: Item):
    item_dict = item.dict()
    if item.tax is not None:
        item_dict["price_with_tax"] = item.price + item.tax
    return item_dict
```

## Body, path, query — moonu ah sernthu

Path parameters, query parameters, request body — ellathayum same
function-la declare pannalam. Evvalo declare panniringalo, adha vachu dhan
FastAPI each-ah recognize pannum:

```python
@app.put("/items/{item_id}")
def update_item(item_id: int, item: Item, q: str | None = None):
    result = {"item_id": item_id, **item.dict()}
    if q:
        result.update({"q": q})
    return result
```

Inga, `item_id` path-la irundhu, `q` optional query parameter, `item` —
Pydantic model-a irukra karanathala — request body-la irundhu vandhirukku.

[Response & Status Codes](/tanglish/docs/response-and-status-codes)
paakalam.
